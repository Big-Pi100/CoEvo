# 科普内容集成方案：hover 气泡提示

> **问题**：页面已较长（约7屏），再新增科普区块会过头  
> **方案**：不新增区块，将科普内容以 hover 气泡形式嵌入现有教学流程卡片

---

## 1. 改动内容

在现有的4张教学流程卡片中，为3张需要科普的卡片添加一个 **hover 展开/收起按钮**，点击后展开科普详情。

| 卡片 | 科普内容 | 来源 |
|------|---------|------|
| **卡1：AI 费曼教学** | 费曼学习法的核心思路：通过"教别人"来检验自己是否真懂。AI 模拟学生角色让学生讲解，发现漏洞即时引导。 | CTA区 ◈ AI 费曼教学，一对一 |
| **卡3：FSRS 科学复习** | 传统艾宾浩斯遗忘曲线用固定间隔复习，FSRS 根据你的每次作答自动调整下次复习时间。会的少复习，不会的多复习。 | Hero区 + CTA区已有品牌提及 |
| **卡4：游戏化成就体系** | 连续学习天数🔥 / 阶段成就奖章 / 即时批改反馈。不做排行榜不制造焦虑，只激励"想继续"。 | FAQ区有提及，animation有成就展示 |

## 2. 实现方式

每张卡片底部增加一个「💡 了解更多」按钮，点击后原地展开科普详情。

```
┌──────────────────────┐
│ ① AI 费曼教学        │
│ 你告诉 AI 想学什么... │
│                      │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─  │
│  💡 了解更多          │  ← 点击展开
│ ┌──────────────────┐ │
│ │ 费曼学习法核心...  │ │  ← 展开后的科普内容
│ │ AI 模拟学生角色... │ │
│ └──────────────────┘ │
└──────────────────────┘
```

## 3. 效果

| 指标 | 预期 |
|------|------|
| 页面长度 | **无增加**（保持在~7屏） |
| 新增SEO内容 | ~600字（藏在HTML中但百度可爬） |
| 用户体验 | 不感兴趣的直接跳过，感兴趣的点击了解更多 |
| 移动端适配 | 同样支持点击展开 |

## 4. 改动范围

- 仅修改 `landing/index.html` 中 `#how-it-works` 区块内的3张卡片
- 追加少量 CSS（按钮样式 + 展开动画）
- 追加少量 JS（切换显示）
- 不需新增区块、不需改结构
