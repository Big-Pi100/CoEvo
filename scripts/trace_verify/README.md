# 痕迹验收（`scripts/trace_verify/`）

## 为什么存在

「痕迹」是产品的**视觉签名**（spec §一），它有两类问题，**性质完全不同**：

| 类 | 例子 | 能不能自动抓 |
|---|---|---|
| ① **切分错了** | 丢字、重叠、越界、同起点结果不稳定 | ✅ **能** —— 纯逻辑 |
| ② **样子不对** | 三态不可辨、「已掌握」态干扰阅读 | ❌ **不能** —— 只能肉眼 |

把①交给脚本、把②留给肉眼 —— **两类问题混在一起时，出了错根本不知道该往哪查**。

## 用法

```bash
cd scripts/trace_verify
DART=/d/flutter/bin/cache/dart-sdk/bin/dart.exe    # 官方版 Dart 3.11.0

$DART run bin/verify_trace.dart
```

- **退出码 0 = 全过；1 = 有失败** → 可挂 CI / pre-commit

## 为什么是「零依赖」脚本

`trace_segmenter.dart` 与 `coevo_tokens.dart` 都是**纯 Dart**（不 import Flutter），
所以本脚本 `pubspec.yaml` **不拉任何包**。

理由同 `tokens_verify` / `fsrs_verify`：本机 Flutter 是鸿蒙定制版、
`flutter analyze` 会因 Windows 管道耗尽崩溃，**只有纯 Dart 才能本地独立验证**。

🔑 **这条约束反过来影响了架构**：为了让切分逻辑可验证，
它必须**不碰 Flutter** —— 于是「切分」与「渲染」被强制分成两个文件
（`trace_segmenter.dart` / `trace_text.dart`）。**可验证性促成了更好的分层。**

## 七组断言（82 项）

| 组 | 内容 |
|---|---|
| 【1】**边界行为** | 空文本 / 无标记 / 覆盖全文 / 相邻相接 / `start>=end` / 越界截断 / 整段越界 / 部分重叠 / 完全被覆盖 / 乱序输入 |
| 【2】**确定性与策略** | 同起点「短区间优先」；同区间重复标注按输入顺序；**同输入 20 次结果逐字节一致** |
| 【3】**核心不变量** | 手写用例 + **2,000 组随机输入**（含越界/空/反向）→ `spans` 必须**覆盖全文、首尾相接、无空洞、无重叠** |
| 【4】token **完整性** | 三档 × 三态，每态 5 项齐备（spec §1.1 硬要求） |
| 【5】token **读法递减** | 墨 bg alpha · 格线宽 · 夜亮度，各自递减；夜还要求「暖 → 冷」 |
| 【6】**三档语法互不相同** | wash / underline / glow 两两不同 |
| 【7】`forReps` 映射 | 含 **`lapses != 0` 时必须退回复习中**（曾错过的关键条件） |

## 能力边界（重要）

| 能查 | 不能查 |
|---|---|
| ✅ 切分的全部逻辑边界与不变量 | ❌ **三态在 15/18/24px 下是否真的可辨** |
| ✅ 三档 × 三态 token 的完整性与递减性 | ❌ **「已掌握」态是否真的不干扰阅读** |
| ✅ `forReps` 的映射规则 | ❌ **墨档「无圆角 / 无 padding」的视觉偏差**（Flutter API 限制） |

后四项**只能真机肉眼**（spec §八 明确要求）。
⚠️ 脚本末尾会主动打出这行提醒 —— **避免「跑绿了就当视觉没问题」**。

## 两条被断言锁住的关键细节（写下来防止回退）

### ① Dart 的 `List.sort` **不是稳定排序**

同起点的多个标记，若不加 tie-breaker，处理顺序会**随排序算法的内部实现漂移** ——
同样的输入可能出不同结果。【2】组的「同输入 20 次逐字节一致」就是防这个。

实现里用 `(start, 长度, 原始下标)` 三级比较，让顺序由**输入顺序**决定，而不是由算法决定。

### ② 相邻相接**不合并**

`A.end == B.start` 时各自成段 —— 因为相邻两段的样式可能不同
（如「复习中」紧邻「已掌握」）。合并会强制二者同色。
CSS 里相邻 `span` 也是各自独立的，行为一致。

## 断言的期望值怎么来的（一条教训）

首次跑出 **8 项失败**，实际输出是 `[_0-10]` 而我写的期望是 `[_-0-10]`。

🔑 **判据：先看数据是否自相矛盾** —— 实际输出 `[_0-2, T2-6, T6-8, _8-10]`
区间连续覆盖 0–10、样式分布正确，**实现是对的**，是我的期望字符串多打了一个 `-`。
→ **失败先分清「实现错」还是「断言错」**，不要见红就改实现。
