# 魔法书语言学习 App — 简单 PRD

## 项目信息

| 字段 | 值 |
|------|----|
| Language | 中文 |
| Programming Language | Flutter + Flame (2D游戏引擎) + flutter_pretext (文本动态引擎) |
| 项目名称 | `magic_book` |
| 目标平台 | iOS + Android |
| 原始需求 | 从 CoEvo 项目独立，构建两个语言学习 App：「英语魔法书」(教英语) 和 「Chinese Magic Book」(教汉语)。核心玩法为「拼字即施法」——以课文驱动、逐词激活、拼写闯关的学习体验，取代传统的选择题式学习。 |
| 架构方案 | **纯 Flutter**，零 Rust 后端。词库以 JSON 打包在 assets 中，FSRS 用 Dart 重写，用户数据存本地 SQLite，AI 对话直接调 API |
| TTS/STT 方案 | **腾讯云**为主（质量优先），**系统原生 TTS 作为 fallback**（离线/弱网降级） |
| 课文来源 | 复用 CoEvo 现有课文卡 + **RSS 新闻订阅**（按水平自动适配） + **公版经典文章**（无版权，如童话、名著节选） |

## 产品定义

### 产品目标

> **打造以「课文驱动 + 拼字闯关」为核心的语言学习体验，让每个生词的掌握过程像施法一样充满仪式感和成就感。**
>
> 详细说明：区别于 Duolingo 的孤立选择题模式，Magic Book 通过完整课文阅读 → 词龙激活 → TTS 跟读 → 拼写/问答施法 → 金色特效反馈的闭环，让学习者在沉浸式的魔法书世界中，逐个击破生词。同时集成 AI 教学对话（非课后对话）作为"学"的环节，对话学完后触发"考"（拼写/问答即玩法），FSRS 间隔复习体系确保长期记忆。

### 已确认决策（2026-07-19）

| # | 问题 | 决策 |
|---|------|------|
| 1 | TTS 方案 | **腾讯云为主** + 系统原生 TTS **fallback**。英语和汉语都用腾讯云 |
| 2 | 课文来源 | 复用 CoEvo 现有课文卡 + **RSS 新闻订阅**（按水平自动适配级别） + **公版经典文章**（童话、名著节选等无版权内容） |
| 3 | CoEvo 对话集成 | **教学对话**，非课后对话。核心流程：对话学习课文 → 学完触发考试 → 考试即拼字/问答玩法 |
| 4 | RPG 美术资源 | 使用公开 **CC0 免费库**（Kenney.nl、SummerEngine、freepixel.art、Google Fonts 中世纪书法字体），羊皮卷简笔画风格 |
| 5 | 架构方案 | **纯 Flutter**，不用 Rust 后端。词库 JSON 打包 assets，FSRS 纯 Dart 重写，sqflite 本地存储 |
| 6 | 语言扩展 | 保留**母语-目标语言**架构，设计时预留多语言扩展点，逐步扩展 |
| 7 | GDPR/COPPA | **提前规划**，架构层集成数据最小化、用户删除权、隐私政策框架 |

### Product Goals

1. **课文驱动的沉浸式学习**：用户通过阅读完整课文（英语/汉语文章）进入学习场景，而非孤立句子，提升语境理解力
2. **拼字即施法的核心玩法**：生词以「词龙」动画激活，用户通过拼写或快问快答「施法」成功获得即时正反馈（金色浮动特效），失败则循环复练
3. **科学复习 + 成长体系**：FSRS 间隔复习确保长期记忆，魔法书成长/RPG 元素提供持续动力

### User Stories

#### 首次打开 & 入门

1. **As a** 新用户, **I want** 首次打开 App 时看到一本华丽的魔法书封面，通过点击进入
   **so that** 我立即感受到魔法世界的沉浸感，明确这是一款与众不同的学习 App

2. **As a** 新用户, **I want** 完成语言水平测试（或直接跳转到第一课）
   **so that** 系统能推荐适合我水平的课文和词库

#### 核心学习循环

3. **As a** 学习者, **I want** 翻开魔法书看到课文页面（羊皮卷风格、手写字体），逐句阅读
   **so that** 我能在完整的语境中理解新语言，而不是孤立的句子

4. **As a** 学习者, **I want** 课文中每个生词像一条龙一样盘旋环绕激活（Pretext 动画），同时 TTS 快速跟读发音
   **so that** 生词以视听结合的方式突出，吸引我的注意力，帮助建立音形联系

5. **As a** 学习者, **I want** 生词激活后进入拼写测试或快问快答，拼写正确即「施法成功」
   **so that** 我通过主动回忆（active recall）来巩固记忆，而不是被动选择

6. **As a** 学习者, **I want** 拼写正确后看到生词变成金光灿灿的浮动文字特效（Pretext gold floating text）
   **so that** 我能获得强烈的即时成就感，强化学习动机

7. **As a** 学习者, **I want** 拼写错误时生词留在队列中继续循环（TTS + 拼写），直到拼写正确
   **so that** 我不会带着错误记忆过关，确保每个生词真正掌握

#### 复习与成长

8. **As a** 学习者, **I want** FSRS 在恰当时间提醒我复习已学生词
   **so that** 我能科学地巩固长期记忆，不会遗忘已学内容

9. **As a** 学习者, **I want** 完成课程后看到魔法书封面逐渐成长变化（如增加符文、变色、升级），解锁新配饰/主题
   **so that** 长期学习的成就感可视化，激励我持续学习

10. **As a** 学习者, **I want** 在多课之间查看学习进度统计（学了多少词、多少课、连续学习天数）
    **so that** 我能量化自己的进步，保持动力

## 技术规范

### Requirements Pool

#### P0 — 核心玩法循环（Must have）

| # | 需求 | 说明 |
|---|------|------|
| P0-1 | 魔法书封面页 | 华丽魔法书封面，点击翻开进入课程选择；两个 App 各自独立主题配色 |
| P0-2 | 羊皮卷课文阅读 | parchment 风格背景，calligraphy 手写体字体，逐句展示课文 |
| P0-3 | 词龙激活动画 | 生词逐个以 Pretext 几何环绕动画在课文中高亮并「窜动」，按 task 渐进激活 |
| P0-4 | TTS 跟读 | 生词激活时同步 TTS 朗读，可重复播放 |
| P0-5 | 拼写验证 | 用户输入拼写，系统验证正误；支持大小写/标点容错 |
| P0-6 | 快问快答 | 除拼写外，支持选择题式快问快答（翻译/释义/选词等），问题预生成 |
| P0-7 | 成功反馈特效 | 拼写正确 → Pretext 金色浮动文字特效（gold floating text） |
| P0-8 | 失败循环机制 | 拼写错误 → 生词留在队列，继续 TTS + 拼写循环 |
| P0-9 | 预生成题库 | 每篇课文的拼写/问答数据在学习前预生成完毕，不实时调用 AI |

## 隐私合规规划 (GDPR / COPPA)

Chinese Magic Book 面向海外汉语学习者，英语魔法书也可能被未成年人使用，因此需要在架构层提前规划隐私合规。

### 什么是 GDPR 和 COPPA？

| 法规 | 全称 | 管辖范围 | 核心要求 |
|------|------|---------|---------|
| **GDPR** | General Data Protection Regulation（欧盟通用数据保护条例） | 保护欧盟居民个人数据 | 用户知情同意、数据可删除权、数据可迁移、隐私设计（Privacy by Design）、泄露 72h 内通知 |
| **COPPA** | Children's Online Privacy Protection Act（美国儿童在线隐私保护法） | 保护 13 岁以下儿童 | 父母同意方可收集数据、数据最小化、清晰的隐私政策、不可诱导分享个人信息 |

### 架构层需提前规划的事项

| # | 措施 | 说明 |
|---|------|------|
| 1 | **数据最小化** | 仅收集必要数据（学习进度、词汇掌握量、连续天数）。不收集位置、通讯录、相册等无关数据 |
| 2 | **本地优先存储** | 用户学习数据存储在**本地 SQLite**，不上传云端。无需用户注册即可使用（无账号模式） |
| 3 | **可选云同步** | 如后续增加多设备同步，需用端到端加密，且明确告知用户同步的数据范围 |
| 4 | **隐私政策** | 发布前准备中英双语隐私政策，明确数据收集范围、存储方式、第三方服务（腾讯云 TTS/AI API） |
| 5 | **用户数据删除** | 架构层预留「删除全部数据」入口，一键清除所有本地学习记录 |
| 6 | **年龄门控** | 首次使用时询问年龄段。<13 岁的用户不请求额外权限、不启用分析追踪 |
| 7 | **第三方 API 合规** | 腾讯云 TTS 和 AI API 调用时，仅传必要的文本内容，不传用户身份信息 |
| 8 | **数据加密** | 本地 SQLite 数据库使用加密存储（sqflite 支持加密扩展） |
