## 🔴 粘贴时注意三件事

### ① 变量必须**原样保留** `{{code}}`

我们的模板里只有一个变量：**`{{code}}`** —— 它会被替换成实际的 6 位验证码。

- ❌ 不要把它改成 `{code}` / `${code}` / `CODE` —— 只有 `{{双花括号}}` 是腾讯云的变量语法
- ❌ 不要自己填一个假验证码进去（那会变成所有人收到同一个假码）

后端发信时会带 `TemplateData`：
```json
{"code":"482913"}
```
对应模板里 `{{code}}` 的位置。

### ② **不要**把 HTML 文件里的注释也粘进去

本目录的 `verification-code.html` **刻意不含任何 HTML 注释**（`<!-- -->`）——
因为那些注释会**跟着一起进模板**（用户看不见，但会增大体积、也可能让审核多一个疑问点）。
⇒ 要写说明就写在**本 README**（这个文件不会被粘贴），不要写进 HTML。

### ③ 主题（Subject）**不在模板里**

腾讯云的 `Subject` 是**发信时传的参数**（后端已实现），不是模板字段。
我们后端传的是：**`记住一切 验证码`**

## ✅ 提交前自查（对照腾讯云的审核规范）

腾讯云模板审核有几条**硬性禁项**，我们的模板已避开 —— 但你若**改过**模板，请逐条对一遍：

| # | 规范（腾讯云原文/实务） | 本模板 |
|---|---|---|
| 1 | 🔴 **禁止出现「加 QQ / 加微信 / 加群」等内容** | ✅ 完全没有<br>⚠️ 注意：App 的「关于」页有**共读群入口**，但**邮件模板里绝不能提** |
| 2 | **不能包含外部文件的 CSS** | ✅ 全部**内联 style**，无 `<link>` / `@import` / `<style>` 标签 |
| 3 | **必须体现实际业务** | ✅ 明确写「你的记住一切验证码是」+ 有效期 + 非本人操作提示 |
| 4 | **变量与文字比例不超过 1:5** | ✅ 只有 `{{code}}` 一个变量，文字远超 5 倍 |
| 5 | **URL 必须确定** | ✅ **没有任何 URL**（只有 `mailto:` 邮箱链接）—— 因为我们是 6 位码方案，不需要跳网页 |
| 6 | 触发类邮件无字数要求 | ✅ 属用户操作触发的「触发类」 |
| 7 | 不允许含二维码图片 | ✅ 无图片（见下） |

### 🔑 为什么模板里**一张图片都没有**

不是省事，是**刻意的**：

| 原因 | 说明 |
|---|---|
| 图片要**外链 URL** | 而外链要么放我们服务器（增加可用性依赖），要么用第三方的（**数据出境**风险） |
| **很多客户端默认不加载图片** | 用户打开会看到一块空白 —— 比没有图更糟（「这封邮件是不是坏了？」） |
| 加图片就多一个**审核变量** | 腾讯云对图片内容有额外要求 |

⇒ 品牌只靠**文字**（`记住一切` + 朱砂色 `#B4432C`）表达。
这既符合「验证码邮件」应有的**克制**，也少三个风险点。

## 📐 HTML 的技术取舍（改的时候别踩回去）

邮件 HTML **不是网页 HTML** —— 它的渲染引擎分三类，兼容性差异极大：

| 取舍 | 为什么 |
|---|---|
| 🔴 **用 `<table role="presentation">` 而不是 `div` + flex/grid** | Outlook 用 **Word 的渲染引擎**，**不认 flex/grid** ⇒ 用现代布局在 Outlook 里会错版 |
| 🔴 **全部**内联 `style`**，不用 `<style>` 标签** | 腾讯云明确要求「不含外部 CSS」；且 Gmail 会**剥离** `<style>` 里的部分规则 |
| 🔴 **不用 `background-image`** | Outlook 不支持 ⇒ 关键信息（如验证码）绝不放背景图 |
| **宽度：外层 `width="100%"` + 内层 `max-width:520px`** | 520px 是邮件正文的常见舒适宽度；移动端靠外层百分比自适应 |
| **字号 ≥13px、行高 ≥1.6** | 邮件客户端不会像浏览器那样「放大到可读」 |
| **验证码块用 `padding:16px 8px 16px 20px`（左右不对称）** | `letter-spacing` 会在**最后一个字符右侧**也加间距 ⇒ 左边多给 12px 才能视觉居中（否则看着偏左） |
| **深色模式不做特殊适配** | 硬适配深色模式要靠 `@media (prefers-color-scheme)`，而那需要 `<style>` 标签（与第 2 条冲突）；且各客户端反色策略不同 ⇒ **保持浅色设计的一致性**更稳 |

⚠️ **改模板后必须重新走一遍审核**（腾讯云模板是「审核通过才能用」的）。
