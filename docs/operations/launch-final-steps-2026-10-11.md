## 1. 【你做 · 现在】更新腾讯云 SES 的邮件模板正文

**为什么**：邮件正文里还写着「CoEvo」，而我们产品已改名「记忆之书」。

**路径**：腾讯云控制台 → **邮件推送** → **发信模板** → 找到 **TemplateID `221378`** → 编辑 → 替换下面两个字段 → **提交**

| 控制台字段 | 粘贴哪个文件（**全文**，本仓库内） |
|---|---|
| 正文（**HTML 富文本**） | `docs/operations/email-templates/verification-code.html` |
| 纯文本（**Text**） | `docs/operations/email-templates/verification-code.txt` |

**改完长这样**（关键 4 处）：

```
品牌行：  记忆之书
正文句：  你的记忆之书验证码是：
落款：    记忆之书团队
网页标题：记忆之书 验证码
```

### 🔴 粘贴时四条注意

| # | 注意 |
|---|---|
| 1 | **变量 `{{code}}` 必须原样保留双花括号** —— 改成 `{code}` 用户会看到字面的 `{code}` |
| 2 | **别把文件里的注释一起粘** —— 该 HTML 刻意**不含任何注释**（注释会跟着进模板） |
| 3 | **主题不在模板里** —— 主题由后端发信时传（已是 `记忆之书 验证码`），控制台若问「摘要/分类」填通知类即可 |
| 4 | 🔴 **改内容 ⇒ 要重新提交审核（1 个工作日）** —— 审核通过前线上仍是旧正文；**TemplateID 不变**（改的是内容不是新建） |

**顺手做（若有该字段）**：发信地址的**发件人别名**改成 `记忆之书`。
（路径：邮件推送 → 发信地址 → 编辑。⚠️ 若报「发件人不合法」，就留空 —— 实测当前服务器配的是**纯邮箱**、无显示名。）

**判据**：审核通过后，去 App 点「忘记密码」，收到的信里应写「你的**记忆之书**验证码是」。

## 2. 【你做 · 现在】跑后端构建（构建只能在你的终端）

WSL 在 agent 沙箱里被安全策略封禁（Program Blacklist）⇒ **必须你跑**。

```bash
LANG=C wsl.exe -d Ubuntu-22.04 -- bash -lc "tr -d '\r' < /mnt/e/CoEvo/scripts/deploy/build_linux_in_wsl.sh | bash"
```

| 检查点 | 说明 |
|---|---|
| 路径是 `scripts/**deploy**/build_linux_in_wsl.sh` | 写成 `scripts/build_…` 会报 `No such file`，而 `%TEMP%\coevo_deploy\` 里留着的是**上一次**的包（极易误传）|
| 末尾 **5/5 自检**必须全绿 | ① 新鲜度（产物比源码新）② 常驻功能标记 |
| 产物在 `%TEMP%\coevo_deploy\` | `coevo_backend` + `cefr_catalog.json` + `prompts/` |

**跑完跟我说一声**（贴个尾巴就行）—— 上传 / 替换 / 重启 / 验证**我来做**，见 §3。
