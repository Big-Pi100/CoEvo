// 方案：不再将 domain 硬编码为 conversation_id

//    plan_handler.rs:244-246 改为:

    subject

    String::new() // 或 "general"

// 2. 读取端：build_plan_context 继续读取 domain 做展示，无需改

| 风险等级 | 🔴 高 |
