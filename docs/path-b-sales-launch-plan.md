## 二、核心商业模式："合伙人"前置

### 为什么是"合伙人"而不是"免费试用"

```
传统SaaS模式：
  免费试用 → 浅层体验 → 用户不珍惜 → 试用结束不转化 → 白烧钱

CoEvo 模式：
  合伙人（¥1,288终身）→ 用户有承诺 → 深度投入 → 看到深度价值 → 口碑推荐

核心理念：
  付了钱的人，才会认真用。
  认真用了，才会看到真正的价值。
  看到了价值，才会留下来，才会推荐给别人。
```

## 三、双用户价值主张

### 对家长说的（购买理由）

```
一句话：
  这不是一个对话机器人——这是一个有学习计划、主动教学、边教边考、
  发现薄弱点就停下来攻克、掌握了才推进的AI特级教师。
  你每天看30秒进度就够了。

三个卖点（按优先级）：

1️⃣ AI主动教学，不用孩子自己"找"学什么
  普通学习App：孩子打开不知道干什么，没人管 → 吃灰
  CoEvo：家长设定目标后，AI自动生成计划，每天主动教
        "今天我们来学习移项变号……" 像特级教师上课一样
        打开App就有老师在等着，不需要孩子主动"找"学习

2️⃣ 边教边考，实时抓薄弱点
  普通辅导班：老师讲完了，布置作业，下次上课检查
             中间隔了几天，错了也不知道
  CoEvo：讲完一个知识点立刻出题
        答对了 → 继续推进
        答错了 → 换种方式再讲，直到真懂
        同一个点连续错 → AI停下来深挖，不赶进度
        确认真掌握了才进入下一个知识点

3️⃣ 精确到每个知识点的家长报告
  不是老师说"表现不错"
  是你自己看到：今天学了9个知识点、掌握率78%、
  薄弱点是"移项变号"——AI已安排额外复习
```

### 对孩子说的（使用动力）

```
"打开App，AI老师已经准备好教你了。学完就考你，答对了有勋章🔥"
```

孩子的体验路径：
```
打开App → AI已经在等着了：
          "今天我们继续学一元一次方程……"
       → AI讲解新知识点
       → 讲完立刻出题考核
       → 答对了 → AI说"很好，下一个知识点"
       → 答错了 → AI换种方式再讲一遍
       → 同时穿插之前学过的知识点的复习考核
       → 全部完成后 → "今天完成了！" ✅ → 连续天数+1 🔥
```

## 五、冷启动：第一个月的获客行动日历

### 整体策略：先服务合伙人，再裂变

不是"免费试用→转化"，而是 **"合伙人（¥1,288终身）→ 深度服务 → 见证效果 → 口碑裂变"**。

信任构建的顺序：
```
熟人关系 → 学习报告样张 → 合伙人邀约 → 亲自Onboarding → 每天跟进 → 收集数据 → 请求推荐
  (已有)      (展示数据)    (限时限量)    (降低使用门槛)   (确保留存)   (积累案例)   (裂变)
```

### Week 1（本周）：找到你的前 3 位合伙人

| 天 | 行动 | 产出 |
|:--|:--|:--|
| **Day 1** | 列出认识的所有有学龄孩子的朋友/同事/亲戚 | **10 人名单**（标注：孩子年级、信任度排序） |
| **Day 1** | 准备学习报告样张（docs/sample-learning-report.md） | **1 份样张** ✅ 已完成 |
| **Day 2** | 私聊前 3 位（按信任度最高排序），使用"锚点→报告→邀约"话术 | **至少 1 位有意向** |
| **Day 3** | 帮第 1 位合伙人完成 Onboarding（注册+设定目标+首日引导） | **第 1 个家庭已激活** |
| **Day 4** | 私聊第 4-5 位 + 帮第 2 位 Onboarding | **累计 2 个家庭** |
| **Day 5** | 跟进所有已激活家庭的 Day 1-2 使用情况 | **使用反馈** |
| **Day 6-7** | 观察 Day 3-4 留存数据 + 跟进未成交的意向用户 | **首批数据 + 复盘** |

**第一周关键指标**：
- ✅ 至少 2 个家庭已激活使用（已付¥1,288）
- ✅ 第 2 天跟进时，至少有 1 个孩子第 2 天继续用了
- ✅ 记录每一个家长的原始反馈（他们怎么向朋友介绍？）

## 七、定价与信任机制

### 为什么不做免费试用

| 免费试用的常见问题 | CoEvo 的解决方案 |
|:--|:--|
| 用户不珍惜，浅尝辄止 | **付了钱的人才会深度使用** |
| 免费用户转化率通常 < 5% | **合伙人模式，第一步就是付费用户** |
| 免费阶段的客服成本高 | **合伙人数量可控，服务质量有保证** |
| 免费用户不会推荐 | **付费用户满意了才会真心推荐** |

### "全额退款"作为信任兜底

合伙人政策：
- **30 天内不满意，¥1,288 全额退款**
- 不需要理由，退就退
- 这等价于"深度免费体验30天"——但用户的心态完全不同

> 用户心理：付了¥1,288 → 我要用回本来 → 深度使用 → 发现价值 → 留下
> vs
> 用户心理：免费试用 → 随便看看 → 没深入 → 过期不续
