## 一、核心原则（读三遍再背话术）

1. **你不是在卖一个产品——你是在邀约合伙人加入一个教育革新**
   - 话术里用"合伙人"而不是"用户"、"客户"、"会员"
   - 传达的是"一起做好这件事"而不是"我把东西卖给你"

2. **你的产品不是"AI对话+制卡工具"——是"AI特级教师主动教学"**
   - 它不是孩子问问题它才回答——它有学习计划，主动教、主动考、主动追薄弱点
   - 这不是一个工具，这是一个有课程大纲、教学方法、考核标准的 AI 教师

3. **¥1,288 不是"贵"，是"便宜得不像真的"**
   - 请一个特级教师多少钱？¥500-1,000/小时
   - CoEvo ¥1,288 终身 = 特级教师两节课的钱，用一辈子

4. **不打价格战，打认知战**
   - 不是"便宜所以买"，是"这个模式才是未来，你现在参与是占便宜"

5. **信任桥接而非推销**
   - 展示样张 → 让数据说话 → 让家长自己得出结论
   - 你不需要说服，你只需要展示

## 二、场景 A：微信私聊 → 成交

### 第 1 步：暖场开场（不要上来就提产品）

```
[目标：重新建立联系 + 自然过渡到教育话题]

❌ 错误："在吗？我有一个AI学习产品你要不要？"
✅ 正确：

你家小宝现在上几年级了？学习方面还顺利吗？"

> 等对方回复后再进入第2步。如果对方说"挺顺利的"，可以用：
> "那挺好的。我最近做一个东西，发现很多家长都有个共同的烦恼……"

```
[目标：让家长意识到传统方式的问题，认可"这件事需要被改变"]


"我最近一直在想一个问题：你发现没有？
给孩子报辅导班，一个月几千块，接送累、孩子也累。

我在想：这个事应该可以用AI来解决——

> **停顿，等对方回应。** 对方大概率会说"真的是这样""太对了"。
> 这时候你已经建立了共鸣，接下来你的方案就自然成为"解法"而不是"推销"。

> 今天该学什么、讲完了立刻出题考核、发现哪里不会就停下来换种方式再讲、

### 第 6 步：成交收尾

```
[目标：降低最后一步的心理摩擦]


"那我现在帮你在后台注册合伙人账号？
大概10分钟就能配置好。
或者你方便的话，我们语音说一下你想让孩子学什么，

> ❌ "你觉得怎么样？" → 对方容易说"我再想想"  
> ✅ "我帮你注册，10分钟搞定" → 自然的行动引导

## 三、场景 B：见面聊 → 成交

### 流程（15-20分钟）

```
┌─────────────────────────────────────────────────┐
│ 见面聊流程（控制在15-20分钟）                      │
│                                                   │
│  0-2 min   寒暄 → 聊孩子最近学习情况                │
│  2-5 min   "你发现没有，现在辅导班最大的问题是..."   │
│  5-10 min  打开手机展示学习报告样张，逐项讲解         │
│            "你看这个"移项变号连续答错"→ 系统自动标记" │
│  10-12 min 打开App（如果孩子也在场，让孩子试一次对话）│
│  12-15 min 合伙人邀约 + 处理异议                     │
│  15-20 min 现场注册 + 设定第一个学习目标              │
└─────────────────────────────────────────────────┘
```

### 见面聊话术要点

**展示App而非截图**：
> "我给你看看实际界面……"
> （打开App → 对话页面 → 发起一次对话）
> 如果是和孩子一起见面，直接把手机给孩子：
> "你试试跟AI聊一个你最近在学的东西。"

**当面定价的效果更好**：
> 辅导班一个月¥3,000-8,000，你孩子一科一年多少钱？"
> "这个……一科一年大概3-4万吧。"
> "那CoEvo是¥1,288 终身。你自己算这个账。"

**现场成交率高**：
> 见面时直接在手机上帮他注册 → 设定学习目标 → 第一周计划就出来了
> 完成这步，成交概率大幅提升，因为"已经开始用了"

## 六、最后提醒

### 不要做这些事

❌ 群发广告文案  
❌ 在朋友圈发"¥1,288抢购"  
❌ 对陌生人上来就推合伙人  
❌ 贬低辅导班老师（家长可能正在辅导班投了钱）  
❌ 承诺"保证提分"  

### 一定要做这些事

✅ **每一单都亲自做 onboarding** — 帮家长设定学习目标  
✅ **前 7 天每天跟进** — 让孩子真正进入使用习惯  
✅ **收集每一个家长的原话** — 这是你下一个版本话术的素材  
✅ **计算"使用 vs 放弃"比率** — 如果放弃率高，先调整Onboarding再继续卖  
✅ **享受第一批用户的反馈** — 他们是帮你把产品做好的最佳伙伴
