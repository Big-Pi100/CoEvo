## 为什么归档

这 4 份文档曾放在**仓库根目录**，是 **K12 多学科时代**（2026 上半年）的产出。
项目后来收缩为「**RSS 英语阅读 + 划词查词 + FSRS 复习**（仅 iOS · 个人主体 · 订阅制）」，
它们描述的架构**已大面积失效**，留在根目录会**误导后来者**（第一眼看到的就是过期设计）。

> 🔴 **不要把它们当实现依据** —— 现行权威文档见仓库根 `README.md`。
