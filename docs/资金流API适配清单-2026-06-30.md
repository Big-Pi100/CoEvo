# 资金流 API 适配清单

**目标**：前端所有资金流 API 调用适配新表结构（`distribution_expenses` 替代 `distribution_withdrawals` + `settlement_batches`）
**状态**：2026-06-30 19:15 — **全部完成** ✅

---

## 后端变更清单

| Handler | 旧表 | 新表 | 变更 |
|:--------|:-----|:-----|:-----|
| `list_batches` | `settlement_batches` | `distribution_expenses GROUP BY batch_no` | 响应去掉 `id`/`total_amount`/`item_count` |
| `get_batch` | `settlement_batches` + `commissions.batch_id` | `distribution_expenses WHERE batch_no` | 响应字段简化 |
| `export_batch` | `commissions JOIN orders` | `distribution_expenses` | 输出字段变化 |
| `mark_paid` | `settlement_batches` + `commissions` | `UPDATE distribution_expenses SET paid` | 按 `batch_no` 更新 |
| `create_batch` | `settlement_batches` + `UPDATE commissions` | `INSERT distribution_expenses` | ✅ 不再修改佣金记录 |
| `user_withdraw` | `distribution_withdrawals` | `INSERT distribution_expenses(type=withdrawal)` | 无 |
| `user_withdrawals` | `distribution_withdrawals` | `distribution_expenses(type=withdrawal)` | 无 |
| `list_withdrawals` | `distribution_withdrawals` | `distribution_expenses(type=withdrawal)` | 无 |
| `approve_withdrawal` | `distribution_withdrawals` + `settlement_batches` | `UPDATE distribution_expenses` | status `approved`→`confirmed` |
| `reject_withdrawal` | `distribution_withdrawals` | `UPDATE distribution_expenses` | 无 |
| `admin_stats` | `distribution_withdrawals` | `distribution_expenses(type=withdrawal)` | ✅ 已迁移 |
