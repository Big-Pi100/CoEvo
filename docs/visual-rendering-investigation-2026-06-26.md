# 对话中绘图渲染效果调查 — 2026-06-26

## 一、当前渲染能力

| 工具 | 用途 | 限制 |
|:-----|:-----|:-----|
| `show_widget` (SVG) | 流程图、结构图、示意图 | 扁平设计，无阴影无渐变，固定色板，680px 固定宽 |
| `show_widget` (HTML) | 交互式控件、Chart.js 图表 | 仅限 CDN allowlist 加载资源 |
| `show_widget` (Chart.js) | 柱/线/饼/散点图 | Canvas 渲染但受 Chat UI 容器宽度限制 |
| D3 地图 | 地理拓扑图 | 仅限 3 个固定拓扑源，CSP 限制严格 |

## 二、风格限制根因

当前渲染引擎（Visualizer Design System）的设计哲学是 **"无缝融入宿主 UI"**——即图表看起来像是聊天界面原生的，而不是"弹出来一张图"。这导致了：

### 2.1 色彩单调
- 只有 9 色调色板，每色 7 级深浅
- 禁止渐变色（仅在 illustrative diagram 中允许 1 个 linearGradient）
- 禁止阴影、发光、霓虹效果

### 2.2 排版受限
- 只用两种字重：400 和 500（无 600/700 粗体）
- 字号上限 15px
- 无 emoji，用 CSS 图形替代

### 2.3 布局约束
- SVG 固定 680px 宽，超出聊天容器宽度的部分会被截断或缩放
- 盒状图宽度按字符数公式计算，偏移生硬
- 复杂图表（大量节点）会被风格指南限制简化

## 三、可改善的方向

### 方向 A：在现有框架内优化（零安装，立即见效）

| 改进 | 方案 | 效果 |
|:-----|:-----|:-----|
| 改用 Chart.js 替代 SVG 手绘图表 | 数据可视化用 HTML canvas 渲染，色彩更丰富，交互更平滑 | **显著** |
| 增加轴标签旋转、网格线细化 | Chart.js options 调优 | **中等** |
| 用 HTML card 布局替代 SVG 盒状图 | 流式布局自适应宽度，排版更灵活 | **中等** |
| 流程图改用 HTML 卡片+flex 布局 | 响应式，白色卡片带边框，视觉更清晰 | **显著** |
| 自定配色 | 在现有 9 色调色板中选用饱和度更高的组合 | **轻微** |

### 方向 B：增加外部渲染资源（需安装技能/加载 CDN）

| 方案 | 依赖 | 风险 |
|:-----|:------|:-----|
| Mermaid.js | `cdn.jsdelivr.net` ✅ 已在 allowlist | 对复杂图很好，但对话中增加一次 HTTP 加载 |
| ECharts | `cdn.jsdelivr.net` ✅ 在 allowlist | 比 Chart.js 更丰富，但包体积大 |
| D3.js + 自定义配色 | `cdnjs.cloudflare.com` ✅ 在 allowlist | 灵活但代码量大 |
| Three.js 3D 渲染 | 需要新增 CDN host | ❌ CSP 不通过 |

### 方向 C：改用 `ImageGen` 生成图片（不通过 SVG/HTML 渲染）

| 方式 | 优点 | 缺点 |
|:-----|:-----|:-----|
| `ImageGen` 文生图 | 视觉质量高，可指定风格 | 无法保证精确的图表/数据可视化 |
| `多模态内容生成` 技能 | 支持视频/3D | 不支持文生图 |

## 四、推荐方案

### 短期（立即能用）
1. **数据图表一律用 Chart.js**，不走 SVG 手绘 — 分辨率高、颜色丰富、交互流畅
2. **流程图/架构图改用 HTML 卡片布局** — 不再受 SVG 680px 宽度限制，自适应容器宽度
3. **利用现有 9 色调色板的高饱和度端**（400-600 级）增加视觉对比度

### 中期（需一次代码调整）
1. 在 `read_me` 加载时注入 Mermaid.js 渲染器，ER 图和流程图用 Mermaid 语法
2. 为特定类型图表（时序图、类图）预设 Mermaid 模板

### 不推荐
- Three.js / 3D 渲染：CSP 限制，且对话场景不需要
- 外部图片生成 API：延迟高，且数据可视化场景不适合文生图

## 五、当前 dialog 中渲染质量差的根因总结

```
root cause: Visualizer 的设计目标是"无缝融入 UI"，不是"好看显眼"
  ├─ 色彩被限制在 9 色调色板内
  ├─ 禁止阴影/渐变/粗体 → 视觉扁平
  ├─ SVG 固定 680px → 复杂图被压缩
  └─ 仅用 text 标签排版 → 对齐生硬

improvement lever:
  ├─ Chart.js 代替 SVG 数据图 → 立即见效
  ├─ HTML card 布局代替 SVG 盒状图 → 更灵活
  └─ 配色用 400-600 级增加对比度 → 不改变架构
```
