# CoEvo 用户流程测试计划

> 基于真实用户操作路径，逐场景验证功能完整性，标记缺失和体验障碍

---

## 总览：用户流程 → 页面映射

```
流程步骤                   对应页面          核心功能点
─────────────────────────────────────────────────────────────
1. 注册/登录               auth_screen       用户名+密码+Token持久化
2. 浏览首页                home_screen       13科目网格+自由对话+历史对话
3. 选择科目+年级           home_screen       科目卡片+年级弹窗
4. 进入对话               chat_screen       WS连接+计划加载+模式识别
5. 教学对话               chat_screen       消息收发+计划更新+概念提取
6. 阅读模式(语)           reading_full_text  课文全文+赏析+手法+主题
7. 复习卡片               review_screen     待复习队列+翻转+AI出题+判题+FSRS
8. 卡片管理               card_list_screen   全部卡片+筛选+删除
9. 查看进度               profile_screen     ⚠️ 缺计划进度+复习统计
10. 历史对话              conversation_list  对话列表+恢复
11. 跳过管理              skipped_list_screen 已跳过概念+取消跳过
12. 管理后台              admin_screen       用户管理+数据查看
13. 家长端                guardian_screen    学习报告
```

## 场景 3：选择科目 → 进入对话

| 步骤 | 操作 | 期望结果 | 当前状态 |
|:----|:-----|:---------|:--------:|
| 3.1 | 点击任意科目卡片 | 弹出年级选择对话框 | ✅ |
| 3.2 | 选择年级 | 调用后端 k12Init/k12ReadingInit API | ✅ |
| 3.3 | API 返回 conversation_id | 跳转到 `/chat?convId=xxx` | ✅ |
| 3.4 | 聊天页面加载 | 骨架屏 → 显示欢迎消息 | ✅ |
| 3.5 | 学习计划面板 | 显示当前学习计划（折叠状态） | ✅ |
| 3.6 | 如是语文 | 额外加载课文卡片 | ✅ |
| 3.7 | 如是语文且阅读模式 | 显示"查看课文全文"入口 | ✅ |

**测试**：
```
选数学 → g7-9 → 聊天页 → 检查计划面板是否存在
选语文 → g1-2 → 聊天页 → 检查阅读卡片是否存在
选"开始对话" → 聊天页 → 检查模式是否为 free
```

**用户体验障碍**：
- 🔴 **选科目 → 弹年级 → 跳聊天**，中间没有确认提示。用户选了"数学+g7-9"，进入聊天后只看到骨架屏，无法确认"我确实是进了数学初中对话"
- 🟡 语文阅读模式和其他科目的结构化模式，在聊天界面上**无任何视觉标识区分**
- 🟡 年级选择对话框只有列表，没有"为什么我要选年级？"的解释

## 场景 4：教学对话

| 步骤 | 操作 | 期望结果 | 当前状态 |
|:----|:-----|:---------|:--------:|
| 4.1 | 输入学习问题 | 消息气泡出现（发送中状态） | ✅ |
| 4.2 | LLM 回复 | 回复气泡显示 | ✅ |
| 4.3 | 计划更新（如有） | 计划面板刷新 | ✅ |
| 4.4 | 概念提取（如有） | 概念确认弹窗出现 | ✅ 但有时无故消失 |
| 4.5 | 有未读概念 | 消息气泡尾部有概念图标 | ✅ |
| 4.6 | 滚动查看历史消息 | 自动滚动到底部 | ✅ |
| 4.7 | 输入长消息 | 输入框自适应高度 | ✅ |
| 4.8 | 点击删除对话 | 对话被删除 | ✅ |
| 4.9 | 发送后等待回复 | 等待动画 | ✅ |

**测试**：
```
发送 "什么是勾股定理？" → 等待回复 → 检查气泡 → 检查计划
发送 "继续讲解" → 检查上下文是否连贯 → 检查 WS 是否正常
（通过 admin 后台检查日志确认 WS 指标日志已输出）
```

**用户体验障碍**：
- 🔴 **WS 断连无提示** — 若服务器重启或网络波动，消息发不出去但用户无感知
- 🔴 **概念提取弹窗经常闪退** — 弹窗出现后很快自动关闭，用户来不及确认
- 🟡 **无消息时间戳** — 多轮对话分不清每轮的时间
- 🟡 **无"正在输入"状态** — LLM 生成回复期间，用户不知道 AI 是否在工作

## 场景 6：复习卡片

| 步骤 | 操作 | 期望结果 | 当前状态 |
|:----|:-----|:---------|:--------:|
| 6.1 | 进入复习页面 | 显示待复习卡片列表 | ✅ |
| 6.2 | 浏览列表 | Tab1 待复习 / Tab2 按科目 | ✅ |
| 6.3 | 点击卡片 | 翻转显示背面 | ✅ |
| 6.4 | 选择"验证一下" | LLM 出题 | ✅ |
| 6.5 | 作答 → 提交 | LLM 判题 → 反馈 | ✅ |
| 6.6 | 选择"我已记住" | 跳过 AI 出题，直接评分 | ✅ |
| 6.7 | 评分 (记住/模糊/忘记) | FSRS 更新 | ✅ |
| 6.8 | 全部复习完 | 弹出"今日复习完成" | ✅ |
| 6.9 | 跳过卡片 | 卡片从列表移除 | ✅ |
| 6.10 | 考试模式切换 | 文字透明度 80%→20% | ❌ **待办未实现** |

**测试**：
```
从首页点"开始对话" → 发几句消息 → 切换到复习 → 检查是否有卡片
有卡片: 翻转 → 验证 → 评分 → 下一张
无卡片: 检查空状态显示
```

**用户体验障碍**：
- 🔴 **无待复习卡片时的空状态** — 没有卡片时页面空白，用户不知道是"没有到期卡片"还是"从来没有卡片"
- 🔴 **记住/模糊/忘记 无说明** — 用户不知道三者对复习间隔的影响
- 🔴 **考试模式透明度未实现** — 需求已记录但前端没做（80%→20%）
- 🟡 **无复习进度条** — 已完成/总计
- 🟡 **Tab2 按科目** — 如果用户只有一个科目有卡片，Tab 切换没有意义
- 🟡 **退出复习后重新进入** — 上次复习到哪张卡片不记得

## 四、缺口汇总

| ID | 场景 | 缺口 | 用户影响 | 工作量 |
|:--:|:-----|:-----|:--------|:------|
| G1 | 首页 | 新用户分不清"自由对话"和"科目" | 困惑 | 小 |
| G2 | 聊天 | 模式无视觉标识 (structured/reading/free) | 不知道当前在什么模式 | 小 |
| G3 | 聊天 | WS 断连无提示 | 消息发不出去不知道怎么恢复 | 中 |
| G4 | 聊天 | 概念弹窗无故关闭 | 概念丢失 | 中 |
| G5 | 复习 | 无待复习卡片时空白页 | 不知道是"没有"还是"还没到" | 小 |
| G6 | 复习 | 评分按钮无说明 | 选错评分影响 FSRS | 小 |
| G7 | 复习 | 考试模式透明度未实现 | 已有需求延期 | 小 |
| G8 | 复习 | 无复习进度条 | 不知道还剩多少 | 中 |
| G9 | 个人 | **无学习计划进度** | **最大缺口** | 中 |
| G10 | 个人 | **无学习统计** | **最大缺口** | 中 |
| G11 | 历史 | 无科目/搜索筛选 | 对话多时找不到 | 中 |

### 优先级建议

```
P0 (阻塞):  无 — 核心流程可用
P1 (重要):   G9 计划进度 + G10 学习统计 (后端 API 已就绪)
P1 (重要):   G2 模式标识 + G6 评分说明
P1 (重要):   G5 复习空状态
P2 (舒适):   G3 WS 重连 + G4 概念弹窗修复
P2 (舒适):   G7 考试模式透明度 + G8 进度条
P3 (增强):   G1 首页引导 + G11 对话筛选
```
