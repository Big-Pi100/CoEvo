# CoEvo 用户场景分析

> 日期：2026-05-30
> 方法：以学生用户视角遍历完整使用流程，标注每步的用户目标、实际体验、缺失环节

---

## 一、用户角色

| 角色 | 目标 | 核心场景 |
|:----|:-----|:---------|
| **学生** (K12) | 学好知识，通过考试 | 学习→复习→评估循环 |
| **家长** | 了解孩子学了什么、进度如何 | 查看学习报告 |
| **教师/管理员** | 管理用户、查看统计数据 | 后台管理 |

## 二、学生核心场景流

### 场景 1：首次使用 — 注册与入门

```
用户操作                       用户看到的                     问题/缺口
─────────────────────────────────────────────────────────────────────
安装 App/打开网页              → 登录/注册页面                 
注册账号                       → 填写用户名/密码              
注册成功后                      → 跳转到首页                   
首次看到首页                    → "今天想学什么？" + 13 个科目   "开始对话"和科目网格的关系不清晰
```

**用户疑问**：
- "我该从哪里开始？" — 首页同时展示"自由对话"和"科目"，用户不知道区别
- "选了科目之后会发生什么？" — 选科目后才弹年级选择，层级太深
- **缺少**：新手指引/引导流程。首次用户不知道"刻意进化学习"是什么意思

### 场景 2：日常学习 — 选课进入教学

```
用户操作                       用户看到的                     问题/缺口
─────────────────────────────────────────────────────────────────────
选择"数学"                    → 弹出年级选择对话框
选"g7-9 初中"                → 后台创建 conversation + plan
                               → 跳转到 chat 页面
聊天页面加载                    → 骨架屏 → "你好！我是你的 AI 学习助手"
                               → 学习计划面板（折叠）
                               → 阅读模式检测（如果是语文）
用户输入"今天学一次函数"      → 消息气泡（等待中动画）
                               → LLM 回复 → 计划面板更新
```

**用户疑问**：
- "我选的年级和科目去哪了？" — 选科目后没在聊天页面展示确认信息
- "这个学习计划是什么？" — 计划面板默认折叠，用户可能不知道它的存在
- "语文为什么和其他科目不一样？" — 语文进入阅读模式，加载课文全文，但用户没有被告知"你进入了阅读模式"
- **缺少**：模式切换时的视觉反馈（structured vs. reading vs. free）

### 场景 3：阅读学习 — 语文课文

```
用户操作                       用户看到的                     问题/缺口
─────────────────────────────────────────────────────────────────────
选语文 → 选年级                 → 跳转到 chat
                                → 检测到 reading_card
                                → 显示全文阅读按钮
点击"查看课文全文"             → ReadingFullTextScreen
                                → 标题/作者/全文/赏析/手法/主题/易错
返回聊天                         → 继续对话
```

**用户疑问**：
- "课文全文在哪里？" — 阅读卡片需要等 _init 完成后才检测并显示
- "赏析和手法有什么用？" — 用户可能不知道这些是复习卡片的来源
- **缺少**：阅读进度 / 当前在阅读第几段落的显示

### 场景 4：复习卡片

```
用户操作                       用户看到的                     问题/缺口
─────────────────────────────────────────────────────────────────────
底部导航点"复习"               → Tab 1: 待复习 / Tab 2: 按学科
                                → 卡片列表（正面文字）
点击卡片                        → 翻转显示背面
                                → "我已记住" / "验证一下" 按钮
选"验证一下"                   → LLM 出题（选择题或填空题）
                                → 用户作答 → LLM 判题
                                → 显示正确/错误 + 反馈
                                → "记住" / "模糊" / "忘记" 评分
                                → FSRS 更新 → 下一张
全部复习完                      → "今日复习完成" 对话框
```

**用户疑问**：
- "哪些卡片今天需要复习？" — 列表只按 due 排序，没有"紧急程度"或"优先级"标识
- "怎么知道我记住了？" — "记住/模糊/忘记" 三个按钮没有说明各自的影响
- "为什么有些卡片要出题有些不用？" — AI 出题 vs 自主回忆的区别不清晰
- **缺少**：
  - 复习进度条（已完成/总共）
  - 复习统计（正确率、连续正确天数）
  - 卡片筛选（按科目/难度/掌握程度）

### 场景 5：查看学习进度

```
用户操作                       用户看到的                     问题/缺口
─────────────────────────────────────────────────────────────────────
底部导航点"个人"               → ProfileScreen
                                → 用户信息 + 设置
                                → 无学习计划进度
                                → 无学习时间统计
                                → 无复习统计
```

**用户疑问**：
- "我学了多久？" — 无学习时长统计
- "学习计划进行到哪了？" — 后端有 `GET /api/plans` 但前端没展示
- "今天我复习了多少张卡？正确率多少？" — 无复习统计
- "我连续学习了几天？" — 后端有 streak_days 但前端没展示
- **缺少**：
  - 学习计划进度条
  - 今日学习时长
  - 连续学习天数
  - 复习统计（今日复习数/正确率）

### 场景 6：历史对话

```
用户操作                       用户看到的                     问题/缺口
─────────────────────────────────────────────────────────────────────
首页点"历史对话"               → 对话列表（按时间排序）
                                → 显示对话标题/时间/消息数
选择一条对话                    → 跳转到 chat，加载历史消息
```

**用户疑问**：
- "对话标题是什么？" — 列表可能只显示 conversation_id 而不是有意义的标题
- "哪个对话是学数学的？哪个是学语文的？" — 没有科目标签筛选
- **缺少**：按科目/日期筛选、搜索功能

## 五、核心建议

### P1 — 立刻改善用户体验

1. **学习计划进度条**（Profile 页面）
   - 后端 `GET /api/plans` 已有数据，前端只需展示
   - 显示：当前阶段 / 总阶段数、已完成任务 / 总任务数

2. **复习统计卡片**
   - 今日复习数、正确率、连续学习天数
   - 后端已有 `GET /api/user/{id}/learning-report`

3. **模式标识**
   - 聊天页面顶部或计划面板显示当前模式（structured / reading / free）

4. **复习进度条**
   - 复习页顶部：已完成 / 待复习

### P2 — 持续改进

5. **新手指引** — 首次使用时弹窗引导
6. **卡片评分 tooltip** — 长按"记住/模糊/忘记"显示说明
7. **对话搜索** — 按科目或关键词过滤历史对话

### 这些只需要前端实现，后端 API 基本都已具备。
