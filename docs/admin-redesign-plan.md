## 二、目标设计

┌──────────────────────────────────────┐

├──────────────────────────────────────┤
│  [仪表盘] [用户管理] [订阅管理]       │  ← 顶部 Tab
├──────────────────────────────────────┤
│                                      │
│   Tab 内容区                          │
│                                      │
└──────────────────────────────────────┘
```

### 2.2 三个 Tab

#### Tab 1: 仪表盘（默认）

| 卡片 | 数据 |
|------|------|
| 今日新用户 | count |
| 今日活跃用户 | 有过对话/复习的用户数 |
| 今日复习量 | review_submit 次数 |
| 待过期用户 | 7 天内到期 |
| 总用户数 / 总卡片数 | 概览 |

#### Tab 2: 用户管理

```
搜索栏: [输入用户名/ID] [搜索]
──────────────────────────────────
用户列表:
┌─────────────────────────────────────┐
│ 张三 (user_abc123)                  │
│ 📅 注册 2026-05-10  📇 12张卡       │
│ 🔁 复习 45次  🟢 已激活→2027-12-31  │
│ [查看详情] [管理订阅]                │
└─────────────────────────────────────┘
```

**用户详情页**（点"查看详情"进入）:
- 基本信息（ID、用户名、注册时间）
- 学习统计（卡片数、复习次数、连续天数）
- 卡片列表（最近 20 张，含状态）
- 对话历史（最近 10 轮摘要）
- 计划列表（活跃计划）
- 操作记录（谁、何时、做了什么）

#### Tab 3: 订阅管理

```
┌─────────────────────────────────────┐

## 四、权限隔离设计

### 4.1 三种角色

| 角色 | 获取方式 | 权限范围 |
|------|---------|---------|
| **超级管理员** | `COEVO_ADMIN_KEY` | 全部功能，可管理其他管理员 |
| **服务人员** | 超级管理员在后台创建 | 搜索用户、查看详情、设置订阅、操作日志只读 |
| **只读观察者** | 超级管理员在后台创建 | 仅查看仪表盘和用户信息，不可修改 |

### 4.2 后端实现

```
admin_users 表（新增）:
  id TEXT PK
  username TEXT
  password_hash TEXT       -- bcrypt
  role TEXT                 -- "super" / "service" / "observer"
  created_by TEXT
  created_at INTEGER

admin_audit_log 表（新增）:
  id TEXT PK
  admin_id TEXT
  action TEXT               -- "set_subscription" / "view_user" / ...
  target_user_id TEXT
  detail TEXT               -- JSON 格式操作详情
  created_at INTEGER
```

### 4.3 前端实现

- 超级管理员登录后显示「管理员管理」入口
- 可创建/禁用/删除服务人员和观察者账号
- 服务人员和观察者使用独立登录（用户名+密码），非 admin key
- 所有管理操作记录审计日志

## 五、后端 API 扩展

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/api/admin/dashboard` | 仪表盘统计 |
| GET | `/api/admin/users?q=` | 增强版（含卡片数、复习数、连续天数） |
| GET | `/api/admin/users/:id` | 用户详情（卡片、对话、计划） |
| PUT | `/api/admin/users/:id/subscription` | 设置订阅到期 |
| POST | `/api/admin/users/batch-subscription` | 批量设置订阅 |
| GET | `/api/admin/users/expiring` | 7 天内到期用户 |
| POST | `/api/admin/admins` | 创建服务人员 |
| GET | `/api/admin/admins` | 管理员列表 |
| DELETE | `/api/admin/admins/:id` | 删除管理员 |
| GET | `/api/admin/audit-log` | 操作日志 |

1. **后端 API 先行** — 补齐所有数据查询接口
2. **前端 3 Tab 骨架** — 仪表盘 / 用户管理 / 订阅管理
