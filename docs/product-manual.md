# CoEvo 产品手册

> **产品名称**：刻意进化学习 · CoEvo
> **适用对象**：识字即可使用（约11岁+），无年龄上限。不限学科，AI知识库覆盖人类已知知识。
> **版本**：V2.1 · 2026-05-13
> **核心思想**：AI 特级教师——主动教、主动考、主动追薄弱点

---

## 一、一句话说清楚 CoEvo 是什么

> CoEvo 是一个 AI 特级教师。
>
> 家长告诉它"我孩子想学什么"，它自动生成一份完整的学习计划。
> 然后每天主动教孩子、在对话中实时考核、发现薄弱点立刻攻克、
> 确认掌握后才进入下一个知识点——同时对过往内容安排科学复习，确保不忘记。
>
> 你每天花 30 秒看看进度，其他全部交给 AI。

**这不是一个"对话机器人"——这是一个有课程大纲、有教学方法、有考核标准、有复习策略的 AI 教师。** 学习和复习、教学和考核全都无缝融合在 AI 对话中，不需要切换工具。

## 二、核心机制：AI 特级教师如何工作

### 整体流程

```
家长设定目标
    ↓
AI 生成学习计划（知识点体系 + 阶段 + 时间线）
    ↓
┌──────────────────────────────────────────────────────┐
│  每天孩子打开 App，AI 按计划主动教学：                  │
│                                                       │
│  ① 讲解新知识点                                       │
│     不是等你问——AI 按计划推进，像老师上课一样           │
│                                                       │
│  ② 实时考核                                           │
│     边讲边问，判断孩子是否真正理解                      │
│     比如教完"移项变号"，立刻出一道题让孩子解             │
│                                                       │
│  ③ 发现薄弱点                                         │
│     孩子答错了 → AI 不是直接给答案                     │
│     而是从不同角度换一种方式再讲一遍                    │
│                                                       │
│  ④ 针对性攻克                                         │
│     如果同一个知识点连续出错 → AI 停下来深挖             │
│     换讲法、换例子、换角度——直到孩子真懂了              │
│                                                       │
│  ⑤ 确认掌握 → 进入下一个                               │
│     AI 确认这个知识点已掌握 → 自动推进到下一个           │
│     制卡 + 复习 + 验证 全部自动完成，不需要手动操作      │
│                                                       │
│  ⑥ 同时安排旧知识复习                                  │
│     之前学过的知识点，AI 按记忆曲线安排定期考核           │
│     答对拉长间隔，答错加练——全部自动                     │
└──────────────────────────────────────────────────────┘
    ↓
家长每天花 30 秒看报告
   "今天学了什么、掌握了多少、哪里还有薄弱点"
```

## 三、家长使用流程（总计约 1-5 分钟上手）

### 第 1 步：告诉 AI 学习目标（约 30 秒）

发一句语音或打一行字：

> "我孩子初一，数学方程基础比较差，想用一个月打好基础。"

AI 理解后，自动生成一份**学习计划草案**。

---

### 第 2 步：确认学习计划（30 秒 ~ 5 分钟）

看一眼 AI 生成的计划。觉得合适 → 回复"可以"。如果想细看，最多 5 分钟。

```
📋 四周掌握：一元一次方程

第一周：方程基础概念 + 简单解法
第二周：复杂方程（去分母、去括号综合）
第三周：应用题（行程、工程、利润）
第四周：综合练习 + 查漏补缺

每天预估时间：15-20分钟
```

确认后，AI 从明天开始按计划自动教学。

---

### 第 3 步：AI 每天主动教学（自动进行，无需家长操作）

从第二天开始，孩子每天打开 App：

```
打开 App → AI 按计划开始今天的教学

‣ AI 讲解今天的新知识点
‣ 讲完立刻出题考核
‣ 答对了 → 继续推进
‣ 答错了 → AI 换种方式再讲，直到真懂
‣ 同时安排之前学过的知识点复习

全部在对话中完成，不需要切换任何界面
```

**孩子不需要知道"今天要学什么"——AI 知道，AI 带着走。**

---

### 第 4 步：你每天花 30 秒看进度

打开 App → 看今日概览：

```
📊 今日概览
• 学了：移项变号、合并同类项
• 复习：等式的性质（通过✅）、方程定义（通过✅）
• 薄弱点：移项变号做了3题错了2题 → AI 已安排明天再练
• 连续学习：6天 🔥
```

关闭。全部结束。

**你的全部投入**：
- 首次：30 秒说目标 + 30 秒确认计划
- 之后每天：30 秒看进度
- 每周：1 分钟扫一眼周报

## 四、常见问题（家长版）

### Q1：这个和 ChatGPT 有什么区别？

**ChatGPT 是你问它答**——你不知道问什么，它就不教。孩子自己都不知道自己哪里不会，怎么问？

**CoEvo 是 AI 主动教**——它有一套完整的学习计划，知道今天该学什么、该考什么、该复习什么。不需要孩子主动提问，AI 带着走全程。

打个比方：
- ChatGPT 像一本什么都能查的百科全书
- CoEvo 像一个有教案、有教学方法、会出题、会找漏洞的**特级教师**

---

### Q2：这个和学习机/点读笔有什么区别？

学习机里有预设的课程视频，孩子看完就完了——记住了多少？不知道。

CoEvo 不止教学——它**边教边考**。教的每一个知识点，当场验证孩子是否真懂了。没懂就换种方式继续教，掌握了才进入下一个。

**核心差异**：学习机是"播课"，CoEvo 是"教学+考核+追薄弱"的闭环。

---

### Q3：孩子需要每天花多长时间？

**每天 15-25 分钟**。全部在 AI 对话中完成，不需要切换界面。

- 3-5 分钟复习之前的旧知识（AI 按记忆曲线自动安排）
- 10-15 分钟学新知识 + 实时考核（AI 按计划推进）
- 2 分钟收尾（AI 总结今天学了什么、什么还没掌握）

周末可以适当延长到 30-40 分钟。

---

### Q4：孩子不自觉用怎么办？

前 3 天可能需要家长提醒一下。但和普通学习 App 不同的是——**CoEvo 不需要孩子"主动学习"**。

它不需要孩子去"找"学什么。打开 App，AI 已经知道该教什么了。很多 App 孩子不用是因为"打开不知道干什么"——CoEvo 没有这个问题，打开就有老师在等着。

连续学习 3 天后，成就系统（勋章、连续天数 🔥）开始起作用，大部分孩子会自己愿意打开。

如果两周后孩子完全不用，合伙人全额退款。

---

### Q5：CoEvo 能替代辅导班吗？

**能。**

辅导班做的事情是什么？教新课 + 布置作业 + 考试。但辅导班最大的问题是——一个老师面对几十个学生，顾不过来。

CoEvo 做的事情：
1. **教新课** — ✅ AI 按学习计划主动教学
2. **出题考核** — ✅ 边教边考，实时判断是否掌握
3. **找薄弱点** — ✅ 每个知识点单独追踪，答错的立刻标记
4. **攻克难点** — ✅ 针对薄弱点反复练，掌握了才通过
5. **复习旧知识** — ✅ 按记忆曲线科学安排，不忘记
6. **给家长反馈** — ✅ 每天一份精确到每个知识点的报告

**这些事，辅导班做不到一对一。CoEvo 可以。**

而且辅导班一个月 ¥3,000-8,000，CoEvo 首批合伙人 ¥1,288 终身。

### Q6：CoEvo 覆盖哪些学科？

CoEvo 使用的是 **DeepSeek 模型**，模型知识库里包含的内容，CoEvo 就能教。也就是说，**AI 几乎囊括了人类已有的全部知识**——凡是人类已有文字记录的知识，它都能调用。

根据测试情况，我们分两类说明：

#### ✅ 经过完整测试流程，可以放心使用

| 领域 | 说明 |
|:--|:--|
| **K12 课程** | 数学、物理、化学、生物、英语、语文、历史、地理 |
| **编程** | Python、C++、JavaScript 等 |
| **英语考试** | 托福、雅思、考研英语 |
| **职场技能** | Excel、PPT、项目管理、沟通表达 |
| **大学专业课程** | 高等数学、线性代数、经济学原理等 |

#### 🔍 待探索（理论上可以，但尚未大规模测试）

AI 知识库里其实还有大量内容——哲学、心理学、投资理财、摄影、乐理、法律基础……只要你感兴趣，都可以跟 AI 对话学习。家长也可以用来学自己感兴趣的东西。

**一个账号 = 一个人**。每个学习者都需要独立的账号来跟踪自己的学习进度。家里有多个孩子？每个孩子一个账号，各学各的，各看各的进度。

### Q7：孩子多大可以用？

**只要基本完成识字就可以用。** 一般 11 岁以上（小学三年级以上）能独立阅读和打字，就可以正常使用。

年龄没有上限——大人自己用来学新东西也完全可以。CoEvo 的学习计划机制对所有年龄段都适用。

**不合适的年龄段**：幼儿园及学龄前儿童（识字量不够，对话效率低）。

---

### Q8：隐私安全吗？孩子的数据会不会泄露？

数据存储在服务端数据库中，不会泄露给第三方。学习数据仅家长和孩子自己能看到。

## 五、产品界面概览

### 主界面

App 主要包含这几个页面：

| 页面 | 功能 |
|:--|:--|
| **对话页** | 主学习界面。AI 在这里教学、考核、攻克薄弱点——全部自动进行 |
| **学习计划** | 当前学习计划的完整展示，阶段进展、任务状态一目了然 |
| **复习页** | 过往知识点的科学复习，AI 按记忆曲线安排 |
| **家长看板** | 学习报告、每日概览、薄弱点追踪——家长 30 秒看懂进度 |
| **卡片库** | 所有已学知识点的卡片列表，可按学科/状态筛选查看 |
| **个人主页** | 学习统计数据、成就勋章墙 |

### 孩子的日常使用

```
① 打开 App → 进入对话页
② AI 已经开始教学："今天我们继续学习一元一次方程……"
③ 对话中：AI 教 → 出题 → 孩子回答 → AI 判断 → 纠正/继续
④ 过程中，所有知识点自动制卡、复习、验证——无需手动操作
⑤ 学完今天的量 → 对话结束 → 可以看到"今日完成" ✅
```

### 家长的日常使用

```
① 打开 App → 进入家长看板
② 看今日概览：学了什么、掌握率、薄弱点
③ 有薄弱点 → 知道就行，AI 已自动安排加强
④ 关闭。一天的学习监督完成，耗时约 30 秒
```
