# release 构建核查 + 体积分析（2026-09-27）

> 触发：白哥 `flutter build apk --release` 成功输出 + 4 行 `exception:` 警告
> 结论：✅ **构建成功**；`exception:` 全部是**第三方插件的 Kotlin 废弃警告**；
> 顺带量出 **≈21 MB 可省**（CJK 字体）与 **3 个死依赖**

---

## 一、那 4 行 `exception:` 不是错误

Flutter 输出格式把**非预期行**统一标成 `exception:`，但实际内容是 Kotlin 编译器的 **`warning:`**：

| 来源 | 条数 | 内容 |
|---|---|---|
| `audioplayers_android-5.2.1` | 2 | `isSpeakerphoneOn` 已废弃 |
| `flutter_tts-4.2.5` | 2 | `requestAudioFocus` / `abandonAudioFocus` 已废弃 |

- 🔑 **全部来自 pub 缓存里的第三方插件**（`AppData\Local\Pub\Cache\...`），
  **我们自己的代码 0 条**
- 🔑 **判据：看最后一行** —— `√ Built build\app\outputs\flutter-apk\app-release.apk (96.1MB)`
  有这行就是成功；真正失败会打印 `FAILURE: Build failed with an exception.`
- ⚠️ 这类「插件用废弃 API」的警告**只能等上游更新**，不建议自己 fork 修（维护成本 > 收益）

## 四、🔴 发现一：release APK 用的是 **debug 签名**

`android/app/build.gradle.kts:33-38`（Flutter 模板原样，连 TODO 注释都在）：

```kotlin
release {
    // TODO: Add your own signing config for the release build.
    signingConfig = signingConfigs.getByName("debug")
}
```

| 影响 | 说明 |
|---|---|
| ✅ **不影响**装到手机上测试 | debug key 也是合法签名，安装正常 |
| 🔴 **无法上任何应用商店** | Google Play / 国内商店均拒 debug 签名 |

ℹ️ 产品**只做 iOS** → 不阻塞。但若将来要出 Android 版，**必须先建 keystore**。

### 5.1 🔴🔴 更正：CJK 字体**不能子集化** —— 授权条款禁止

> ⚠️ **本节初版给的建议是错的，已更正。**
> 初版据「字形数 29,296 → 实际只用 3,873」推出「子集化省 ≈21 MB」——
> **只算了技术收益，漏查授权条款**。项目文档里**早已记录**该约束，我未先检索。

**阿里巴巴普惠体官方法律声明（2.0 与 3.0 同款）原文**：

> 「未经阿里巴巴授权，任何人不得：……2) 对阿里巴巴字体进行**修改、仿制、转换**、
> 翻译、反编译、反向工程、**拆分**、破解，或以其他方式试图从该字库软件获取源代码……」

**子集化 = 对字体文件做「拆分 / 转换 / 修改」→ 明确在禁止之列。**

项目内已有记录（我漏查了）：

| 出处 | 原文 |
|---|---|
| `design-system-spec-2026-09-25.md:778` | 「阿里普惠体 3.0 官方法律声明的禁止事项第 ① 条含「**转换**、**拆分**」」 |
| `coevo_tokens.dart:698` | 「中文 UI。全量 24.2 MB，**不做子集化**（阿里普惠体条款禁止拆分/转换）」 |
| `ui-ux-refactor-assessment:984` | 「~~E · 阿里普惠体子集化~~ ⚠️ 条款灰区 **不建议**」 |

**实测数据（保留，仍有参考价值）**：

| 字体 | 字形总数 | 大小 |
|---|---|---|
| `AlibabaPuHuiTi-3-55-Regular.ttf` | **29,296** | 8.14 MB |
| `AlibabaPuHuiTi-3-65-Medium.ttf` | 29,296 | 8.04 MB |
| `AlibabaPuHuiTi-3-85-Bold.ttf` | 29,296 | 7.98 MB |
| **实际用到的汉字** | **3,873**（`word.db` 3,868 ∪ `lib/**.dart` 1,144） | = 全量字形的 **13.2%** |

**合法且有效的替代：换一个允许子集化的中文字体**

| 选项 | 许可 | 可否子集化 | 备注 |
|---|---|---|---|
| **思源黑体 Noto Sans SC** | **SIL OFL 1.1** | ✅ **明确允许**（OFL 允许修改与再分发，仅限制单独售卖 + 保留许可声明） | 子集到 3,873 字 ≈ **1 MB/字重** → 三字重 ≈3 MB，**仍省 ~21 MB** |
| 其他 OFL / Apache-2.0 中文字体 | 需逐个核 | 视许可 | —— |

🔑 **判断链**：「这份字体允许我**修改字体文件**吗」—— 阿里普惠体**不允许**（免费商用 ≠ 允许改造）；
OFL 类**允许**。**「免费商用」与「允许子集化」是两个独立的授权维度**，
前者常被误当成后者。

> ⚠️ 换字体是**视觉决策**（字形观感直接影响 UI 气质）→ **必须白哥定**，
> 且要重跑字体相关的验收 + 真机肉眼比对。

### 5.2 因此现在**唯一确定可省**的是：3 个死依赖（见 5.3）

### 5.3 🔴 三个死依赖（代码 0 引用）

| 依赖 | `lib/` 引用 | 说明 |
|---|---|---|
| **`audioplayers`** | **0** | pubspec 注释写「后端 TTS 保留，音频仍需端侧播放」——<br>但 TTS **已全量端侧 `flutter_tts`**，`tencent_tts.rs` 是**无调用方**的预留 → **注释的理由已失效** |
| **`record`** | **0** | 3 处命中全是**注释**与 `Icons.record_voice_over` 图标名 |
| KaTeX 字体（×20） | — | 来自 `flutter_math_fork`，是 **`gpt_markdown` 的依赖**；公式渲染已于方案 A 删除 |

🔑 **删掉 `audioplayers` 还顺带消掉那 4 条警告中的 2 条**（正是它产生的）。

🔑 但**产品只做 iOS** → Android APK 体积只影响**自己测试时的传输**，优先级低。
