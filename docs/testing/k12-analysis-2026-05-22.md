**文科（general 管线）的概念提取最弱**，只有 2.7 个平均候选概念。

| 学段 | 科目 | domain | 问题 |

## 三、建议改进点

### P1: 文科概念提取 prompt 优化

**问题**：通用 `concept_extract.md` 对文科（语文/历史/地理/政治）提取能力偏弱，平均仅 2.7 个候选概念。

**建议**：为语文和文科建独立管线，或者增强通用提取 prompt 对文科概念的支持。

### P2: 低年级基础教育提取适配

**问题**：g1-2 语文拼音教学等基础内容，LLM 认为"没有值得提取的知识点"。

**建议**：在 `concept_extract.md` 中增加 "即使是基础内容也要提取" 的指引。

### P3: review-flow 未被触发

**问题**：K12 测试中创建了 candidate 但未触发卡片创建和复习提交（cards_created=0, reviews_submitted=0）。

**原因**：当前 K12 runner 的逻辑中，创建卡片后不再触发复习提交，因为 review 流程需要用户交互模拟。可增加自动化复习提交逻辑。

### P4: 测试崩溃问题

**问题**：Windows debug 模式下 30 测试一次性运行会栈溢出/内存分配失败。需分批按学段跑或用 release 模式。
