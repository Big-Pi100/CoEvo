## 测试执行流程

### 每次部署前

```
1. cargo test (全量)          ← 后端单元测试
2. flutter analyze             ← 前端静态检查
3. 手动执行本篇 1-11 项功能测试  ← 浏览器自动化
4. 截图存对比基线
5. 检查 14-1 到 14-4 资源指标
6. 审批→部署
```

### 每次部署后

```
1. 跑 1-11 项功能测试          ← 确认部署没坏
2. 检查 18-1 到 18-5 系统健康   ← 确认服务正常
3. 通知巡检邮件
```

### 每日巡检（已自动化）

```
自动检查 18-1 到 18-5 系统健康
自动检查 15-1 到 15-7 用户活跃
自动检查 16-1 到 16-4 付费转化
自动检查 17-1 到 17-5 营销效果
产出巡检报告发邮件
```
