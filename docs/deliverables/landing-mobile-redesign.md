# CoEvo 落脚页移动端改版方案

> 版本: v1.0 · 2026-06-17  
> 状态: 设计方案（待审）

---

## 一、问题诊断

当前页面是桌面优先设计，在手机上存在以下核心问题：

| 问题 | 根因 |
|:----|:-----|
| 水平方向信息过密 | 3 列对比卡、2×2 数据面板、3 列信任卡片 → 缩成 1 列后内容冗长 |
| 首屏信息超载 | Hero + 3 徽章 + 4 个数据统计 + 按钮 → 用户抓不住重点 |
| 点击目标太小 | 导航链接 (`font-size:13px`)、对比卡内多项文字 → 拇指难以精准点击 |
| 滚动过多 | 全页 10+ 模块，手机需滑 15+ 屏 → 信息淹没 |
| 缺少移动端特有交互 | 无滑动卡片、无触点反馈、无渐进式展示 |

---

## 二、设计原则

1. **Mobile-first 重构**：不再基于桌面版做媒体查询，单独规划手机端内容层级
2. **Duolingo 风格统一**：与产品端视觉语言保持一致（详见 `docs/design/Duolingo/DESIGN.md`）
3. **单列流体布局**：不允许任何横向滚动或 2 列及以上并排布局
4. **首屏只做一件事**：让用户 3 秒内理解"这是什么" + 一个可点击的行动点
5. **渐进式呈现**：非关键信息折叠（"了解更多"展开），减少认知负荷
6. **拇指友好**：所有可点击元素最小 44×44px，核心按钮在屏幕下半区

## 三、Duolingo 风格应用

### 3.1 品牌色（转换为 CoEvo 品牌色）

| Duolingo 原色 | CoEvo 对应色 | 用途 |
|:-------------|:-------------|:-----|
| Duo Green `#58cc02` | CoEvo Deep Blue `#1A237E` | 主按钮、品牌标题 |
| Sky Blue `#1cb0f6` | CoEvo Emerald `#00C853` | 次要按钮、链接 |
| Snow White `#ffffff` | `#ffffff` | 页面背景 |
| Cloud Gray `#e5e5e5` | `#e5e5e5` | 边框 |
| Silver `#afafaf` | `#afafaf` | 禁用/占位文字 |
| Almost Black `#3c3c3c` | `#3c3c3c` | 正文文字 |
| Duo Green Light `#d7ffb8` | `#E8EAF6` (Indigo 50) | 高亮背景 |

### 3.2 字体

| Duolingo | CoEvo 替代 |
|:---------|:-----------|
| Feather (display) | **Noto Sans SC, 700 weight** — 中文大标题 |
| din-round (body) | **Noto Sans SC, 500 weight** — 正文字体 |
| letter-spacing: 0.053em | 保持中文 `letter-spacing: 0.03em` |

### 3.3 形状

| 元素 | Duolingo | CoEvo |
|:----|:---------|:------|
| 按钮圆角 | 12px | 12px |
| 卡片圆角 | 12px | 12px |
| 输入框圆角 | 12px | 12px |
| 按钮阴影 | `0 4px 0 #3f8f01` | `0 4px 0 #0D1457` (深蓝暗色) |
| 卡片阴影 | 无 (flat) | 无 (flat) |

### 3.4 按钮样式

**主按钮 (Primary CTA)**:
```css
background: #1A237E;          /* CoEvo Deep Blue */
color: #ffffff;
border-radius: 12px;
padding: 16px 32px;
font-weight: 700;
font-size: 15px;
box-shadow: 0 4px 0 #0D1457;  /* 3D 按压效果 */
```

**次要按钮 (Secondary/Outline)**:
```css
background: transparent;
color: #00C853;               /* CoEvo Emerald */
border: 2px solid #e5e5e5;
border-radius: 12px;
padding: 14px 24px;
font-weight: 700;
font-size: 15px;
```

## 八、技术实现要点

- **新建设计系统**: 替换当前 CSS，从头构建 Duolingo 风格样式
- **`mobile.css`**: 专为移动端设计，不继承现有桌面 CSS
- **滑动卡片**: CSS `scroll-snap-type: x mandatory`，原生性能
- **3D 按钮**: `box-shadow: 0 4px 0 var(--color-primary-dark)` + 点击时 `translateY(2px)`
- **固定底部 CTA**: `position: sticky; bottom: 0`
- **渐进展开**: `<details><summary>` 标签实现
