## 二、V2 → V3 关键变更

### 2.1 管线完成
原计划的所有脚本全部跑通并产出全量数据。

### 2.2 考试设计转向

| 旧（V2.2） | 新（V3） |
|:----------|:--------|
| 预出题 + 存答案到题库 | 运行时 LLM 动态按出题框架生成试卷 |
| 考题在 task 层面 + 题库前端不安全 | 大考在 stage 层面，不留痕迹 |
| `generate_assessment.py` | `k12_assessment` crate（后端 Rust） |
| 小考大考混在一起 | 小考 → ws 对话流，大考 → 独立考试页面 |

### 2.3 小考 vs 大考

| | 小考（日常考核） | 大考（阶段测试） |
|:----|:---------------|:---------------|
| 触发 | 对话中 LLM 自然发问 | Stage 完成后系统推送通知 |
| 位置 | ws 会话流内 | 独立考试页面 |
| 覆盖范围 | 单次对话的 1-2 个 task | 整个 stage 所有 task |
| 实现 | ✅ 已有（ColdPath 2） | ⏳ 待开发（k12_assessment crate） |
