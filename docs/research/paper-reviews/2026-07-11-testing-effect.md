## 设计审查: 测试效应——为什么"考考考"才是最好的学习方法？

**来源**: 博客文章（2026-07-11）
**核心主题**: Karpicke & Roediger 测试效应——考试不仅是检测手段，考试本身（检索练习）就是最好的学习方法，效果比反复阅读高 30-60%

### 对 CoEvo 设计的启示

- **B2 客观验证 = 测试效应的产品化实现**
  - 影响范围：`k12_quiz.rs`、`k12_quiz_api.rs`、`ws.rs`
  - 建议改进：文章引用 Karpicke 2006 经典实验——阅读 + 反复测试组一周后记住约 80%，反复阅读组仅约 50%。CoEvo 的 B2 模块正是测试效应的工程化实现。可以进一步强化"测试即学习"的认知：在 B2 验证环节的 UI 文案中强调"你正在通过测试加深记忆"，而非"你正在接受检测"。
  - 优先级：P2

- **"尝试回忆即使失败也有益"的设计含义**
  - 影响范围：`k12_quiz.rs`、`prompts/quiz/`
  - 建议改进：文章引用了重要发现——"答错的学生在最终测试中比根本没尝试的学生表现更好"，因为尝试回忆本身激活了神经通路。这意味着 B2 验证中即使学生答错，这个过程也是有价值的。当前 B2 流程可能在学生答错后直接展示正确答案，可改为"先让学生再试一次"的机制，给大脑第二次检索机会。
  - 优先级：P1

- **"高频低风险测试"的产品定位**
  - 影响范围：`plan_handler.rs`、`achievement_engine.rs`
  - 建议改进：文章做了一个关键区分："高频低风险测试（促进学习）"vs "低频高风险考试（筛选排名）"。CoEvo 的 B2 验证正是高频低风险测试的完美形态。可在 `plan_handler.rs` 中明确将 B2 验证列为"每日学习任务"的一部分，强调"今天的小测验不是为了打分，而是为了帮你记得更牢"。
  - 优先级：P2

- **测试效应 + 间隔重复 = 记忆的最佳组合**
  - 影响范围：`fsrs_scheduler.rs`、`card_repository.rs`
  - 建议改进：文章明确指出"测试效应 + 间隔重复 = 记忆的最佳组合"。这正是 CoEvo 的"FSRS + B2"架构的理论基础。建议将这一组合显性化：在 FSRS 复习卡片中，每次复习都是一次"微型测试"，而非"重新阅读"。应确保 UI 层面默认先展示问题（要求学生回忆）再展示答案，而非同时展示。
  - 优先级：P1

### 已确认的设计

- **B2 验证机制**：文章证明"考试本身是最好的学习方法"，完全支撑 B2 模块的核心设计
- **FSRS 间隔安排复习**：文章建议的间隔自测节奏（学完→1天→1周→1月）正是 FSRS 的自动调度
- **"三题全对"绕过自我感觉良好陷阱**：文章指出自测有一个问题——"你很难知道自己是不是自我感觉良好"，CoEvo 的客观验证解决了这个问题

### 设计差距

- **缺少"测试效应"知识教育**：文章揭示了测试效应的反直觉性——"感觉吃力反而更有效"。大多数学生和家长不了解这个原理，可能会觉得"总是在做题很累"。CoEvo 可以考虑在用户首次使用 B2 时提供简短的认知科学解释，帮助用户理解"为什么我们需要通过测试来学习"。
