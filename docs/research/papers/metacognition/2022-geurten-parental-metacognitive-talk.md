# Relations between Parental Metacognitive Talk and Children's Early Metacognition and Memory

## 核心发现

- 72名2.5-4.5岁儿童及其父母参与实验
- 父母在互动中的"元认知语言"（如"你觉得对吗""你是从哪里开始不懂的"）预测孩子的元认知准确性
- 孩子的元认知能力在父母的元认知风格与记忆表现之间起中介作用
- 环境因素（父母元认知风格）影响早期元认知发展
