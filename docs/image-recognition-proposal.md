# 对话中图像识别输入 · 方案评估

> 日期: 2026-05-17
> 目标: 支持用户上传手写/印刷的数学题、公式、图表，AI 识别后进入对话

---

## 一、需求分析

| 需求 | 说明 |
|------|------|
| 手写数学题 | 用户拍照上传手写题目，识别为文本 + LaTeX 公式 |
| 几何图形 | 手绘几何图 → 识别形状 + 标注 |
| 物理题 | 含公式 + 文字的混合识别 |
| 中英文混排 | K-12 场景以中文为主 |
| 成本 | 每张图 < ¥0.05，日均 50 张预算可控 |

---

## 二、候选方案

### 方案 A: DeepSeek V4 Vision（推荐 ⭐）

```
用户拍照 → base64 → POST /v1/chat/completions
  messages: [{role:"user", content:[
    {type:"text", text:"识别这张图片中的数学题"},
    {type:"image_url", image_url:{url:"data:image/jpeg;base64,..."}}
  ]}]
  model: "deepseek-chat-vision"
```

| 维度 | 评估 |
|------|------|
| 手写识别 | ⭐⭐⭐⭐ DeepSeek V4 多模态强，能理解手写中文/数学 |
| 数学符号 | ⭐⭐⭐⭐ 原生理解 LaTeX，输出即可用 |
| 上下文理解 | ⭐⭐⭐⭐⭐ 能理解题目意图，直接融入对话 |
| 成本 | ⭐⭐⭐ 图片 ≈ 500-2000 token，约 ¥0.001-0.005/张 |
| 集成 | ⭐⭐⭐⭐⭐ 已集成 DeepSeek API，零迁移成本 |
| 延迟 | ⭐⭐⭐ 2-5 秒/张 |

### 方案 B: 腾讯云数学公式 OCR

| 维度 | 评估 |
|------|------|
| 手写识别 | ⭐⭐⭐ 手写体支持（含中文），非数学内容较弱 |
| 数学符号 | ⭐⭐⭐⭐⭐ 返回 LaTeX，精确到 180 种符号 |
| 成本 | ⭐⭐⭐⭐ ¥0.01-0.03/次，首月免费额度 |
| 集成 | ⭐⭐ 需要额外 SDK + 腾讯云账号 |
| 延迟 | ⭐⭐⭐⭐ < 1 秒 |

### 方案 C: 通义千问 Qwen-VL

| 维度 | 评估 |
|------|------|
| 手写识别 | ⭐⭐⭐⭐ Qwen2.5-VL 中文手写强 |
| 成本 | ⭐⭐⭐⭐ ¥0.003/千 token（图片按分辨率计），非常便宜 |
| 集成 | ⭐⭐ 需要阿里云百炼账号 |
| 延迟 | ⭐⭐⭐ 2-4 秒 |

### 方案 D: 本地 OCR（flutter_tesseract_ocr / ML Kit）

| 维度 | 评估 |
|------|------|
| 手写识别 | ⭐ 训练数据依赖英文印刷体，中文手写差 |
| 数学符号 | ⭐ 不支持 LaTeX 输出 |
| 成本 | ⭐⭐⭐⭐⭐ 免费 |
| 结论 | ❌ 不适合 CoEvo 的教育场景 |

## 四、推荐方案: DeepSeek V4 Vision

### 理由

1. **零集成成本** — 已使用 DeepSeek API，只需传图片 base64
2. **上下文理解** — 不仅识别文字，还能理解题目含义，直接嵌入对话
3. **成本可控** — 图片 ≈ 500-2000 token，日均 50 张 < ¥1
4. **一次请求完成** — 识别 + 解题 + 教学，LLM 一站式处理

### 架构

```
用户拍照
  │
  ├─ Flutter image_picker (已有) → 压缩到 1024px
  │
  ├─ base64 编码
  │
  ├─ POST DeepSeek API (model: deepseek-chat-vision)
  │     messages: [{
  │       role: "user",
  │       content: [
  │         {type:"text", text:"请识别图中的题目，用中文回复"},
  │         {type:"image_url", image_url:{url:"data:image/jpeg;base64,..."}}
  │       ]
  │     }]
  │
  └─ LLM 返回识别结果 → 显示为对话消息
       用户可追问，AI 基于识别结果继续教学
```

### 前端改动

| 改动 | 位置 |
|------|------|
| 聊天输入框旁加 📷 按钮 | `chat_input.dart` |
| `image_picker` → 拍照/选图 | 已有依赖 |
| 图片压缩 (1024px) | 新增 `_compressImage()` |
| base64 编码 | `dart:convert` |
| WS 消息扩展 image 字段 | `ChatRequest` + JSON |

### 备选：DeepSeek 不可用时

如果 DeepSeek Vision 灰度访问受限，备选为 **Qwen-VL**（通义千问），成本更低，中文手写同样出色。

## 五、风险

| 风险 | 缓解 |
|------|------|
| DeepSeek Vision 灰度中，API 不稳定 | 备选 Qwen-VL，接口兼容 |
| 大图 token 消耗超预期 | 前端压缩到 1024px，token ≈ 500 |
| 手写潦草识别不准 | system prompt 引导 LLM 标注不确定部分 |
| 图片包含敏感内容 | 已有 NSFW 过滤 + prompt 约束 |
