## 二、设计风格

### 品牌色

| 角色 | 颜色 | 色值 |
|:--|:--|:--|
| 主色 | 深邃蓝 | `#1A1A2E` |
| 强调色 | 紫罗兰 | `#6C63FF` |
| 渐变 | 蓝 → 紫 | `#1A1A2E` → `#6C63FF` |
| 背景 | 白色/浅灰 | `#FFFFFF` / `#F8F9FA` |
| 文字 | 深灰 | `#333333` |

### 字体

- 标题: **Inter**（无衬线，现代感）
- 正文: **Noto Sans SC**（中文优化）
- 英文: **JetBrains Mono**（代码/品牌场景）

### 交互效果

- **Hero 区域**: 动态粒子背景（Three.js 粒子系统）
- **卡片**: 鼠标悬停上浮 + 阴影过渡
- **下载按钮**: 磁吸效果 + 脉冲动画
- **导航**: 滚动时固定顶部 + 毛玻璃
- **滚动**: 渐入动画（Intersection Observer）

### 布局策略

- 桌面优先，响应式到移动端
- 最大内容宽度: 1200px
- 间距: 8px 网格系统

## 三、技术栈

| 技术 | 用途 |
|:--|:--|
| **HTML5** | 骨架 |
| **CSS3** | 样式 + 动画 + 响应式 |
| **Three.js** | Hero 粒子背景（CDN 加载）|
| **Nginx** | 静态文件托管 + API 反向代理 |

> 选择**纯静态页面**的原因：
> - 首屏加载极快（< 1s）
> - SEO 友好（备案审核和搜索引擎都需要）
> - 无框架依赖，维护成本低
> - Flutter Web 依赖 CanvasKit，首屏 3-5s 不适合官网

## 四、部署方案

```
keyievolution.fun:80/443
       │
    nginx
       │
       ├── /  → /var/www/coevo-landing/     ← 官网静态页
       │
       └── /api/  → proxy_pass :8080        ← API 反向代理
       └── /ws    → proxy_pass :8080/ws     ← WebSocket 代理
       └── /admin → proxy_pass :3000        ← 管理后台（Flutter Web）
```

---

## 五、本地开发流程

```
① 在 E:/CoEvo/landing/ 下编写 HTML/CSS/JS
② 用浏览器直接打开 index.html 预览
③ 本地满意后 → scp 到 VPS → 配置 Nginx
④ 备案通过后 → 域名解析上线
```

## 六、SEO 与备案要求

- `<title>` 和 `<meta description>` 完整填写
- 页脚展示 ICP 备案号（占位符，通过后替换）
- 页面包含联系方式
- robots.txt + sitemap.xml（可选）
