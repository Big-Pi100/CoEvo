# 概念提取三个问题 · 改进方案

> 日期: 2026-05-19

---

## 问题 1: 左滑跳过容易误触 / 概念窗口误触关闭

### 现状

| 文件 | 行号 | 问题 |
|------|------|------|
| `card_list_screen.dart:436` | `Dismissible` 左滑直接执行跳过，无确认 | 误触率极高 |
| `chat_concept_dialog.dart:32` | `showDialog` 缺 `barrierDismissible: false` | 点击外部区域关闭 = 错误跳过 |

### 修复

1. **卡片左滑** — `confirmDismiss` 回调内加 `showDialog` 确认弹窗
2. **概念窗口** — `showDialog(builder: ..., barrierDismissible: false)`

## 问题 2: 按钮文案不一致

### 现状

| 按钮 | 当前文案 | 语义问题 |
|------|---------|---------|
| 左(跳过) | `isLastPage ? '完成' : '跳过并继续'` | "完成" ≠ "跳过" |
| 右(确认) | `isLastPage ? '确认制卡' : '确认并继续'` | "确认制卡" vs "确认"容易混淆 |

### 修复

统一为两词方案：
| 按钮 | 中间页 | 最后页 |
|------|--------|--------|
| 左(跳过) | `跳过 (${n})` | `跳过` |
| 右(确认) | `确认并继续 (${n})` | `确认制卡 (${n})` |

括号内显示本页确认数量，信息透明。

## 问题 3: 提取结构缺少公式

### 现状

提取 prompt (`prompts/concept_extract.md`) 只要求 `front/back/source_sentence/domain`，没有公式提取指引。

### 修复

更新 prompt 加入结构化提取要求：

```
每个卡片必须包含:
{
  "front": "简洁的概念名称（名词/短语，不用问句）",
  "back": "完整释义。如果有公式，必须是 LaTeX 格式（\(行内\) 或 \[独立\]）",
  "formula": "核心公式（LaTeX，可选）",
  "meaning": "公式含义的一句话解释（可选）",
  "background": "背景/应用场景（可选）",
  "source_sentence": "来源于 AI 回复的原文",
  "domain": "所属领域"
}
```

**原则**：有则填写，无则留空。不要编造。领域无关但结构完整。
