## 2. 与 CoEvo 现有课程的对照

| 维度 | CoEvo | Marble taxonomy | 差距 |
|:-----|:------|:----------------|:------|
| **学科覆盖** | 科学/数学/语言/人文 | 科学/数学/英语/历史/个人/生活/计算机/学会学习 | Marble 多了"学会学习"和"生活技能" |
| **知识粒度** | → Plan → Stage → Task ↓ | → Subject → Domain → Micro-topic ↓ | 粒度相近，Marble 更细 |

## 3. 建议方案（三级递进）

### 方案A：浅层接入（1-2天）

**做什么：** 将 Marble 的 JSON 数据加载到 CoEvo 的 SQLite 数据库，作为课程参考数据。

**具体：**
```
marble/topics.json → 新表 curriculum_topics
marble/dependencies.json → 新表 curriculum_dependencies
marble/clusters.json → 新表 curriculum_clusters
```

**能做什么：**
- 产品内可查看"官方课标建议的学习顺序"
- 博客内容引用：对比 CoEvo 进度与课标进度
- 后端 API 暴露供前端参考

**不做：** 不影响现有的学习计划和复习系统。

---

### 方案B：中等集成（1-2周）

在方案A基础上，将 Marble 数据用于增强现有功能：

| 功能 | 用 Marble 做什么 |
|:-----|:----------------|
| **K12 计划编排** | 依赖图替代人工编排 Plan→Stage→Task，自动生成学习路径（需先学 A 再学 B）|
| **ColdPath 概念映射** | AI 提取的概念自动对齐到 Marble 微主题，获得 `assessmentPrompt` 和 `evidence` |
| **复习评估** | 每个卡片复习时可引用 Marble 的评估提示作为验证标准 |
| **知识缺陷诊断** | 用户对概念 C 表现差 → 回溯依赖图 → 推荐复习先决知识 A 和 B |

---

### 方案C：深度整合（4周+）

将 Marble 作为知识骨架，CoEvo 作为交互和评估层：

```
用户 ↔ CoEvo（对话+复习） ↔ Marble taxonomy（知识骨架）
                                    │
                           ColdPath 提取的概念
                           ↕ 自动对齐
                           Marble 微主题
                           ↕ 依赖链
                           自适应学习路径
```

**需要做：**
- 将 CoEvo 的 K12 计划从静态 Plan→Stage→Task 改为动态依赖驱动
- ColdPath 出口增加 taxonomy 对齐层
- 新增"知识地图"视图：用户的掌握状态在 Marble 的 1,590 节点图上可视化
- 新增"评估模式"：用 Marble 的 `assessmentPrompt` 做交互式验证

## 4. 风险与限制

| 风险 | 等级 | 说明 |
|:-----|:----:|:------|
| **仅覆盖 K-6** | ⚠️ | 初中和高中没有。但 `os-taxonomy-fr`（法国课标）已覆盖PS→Terminale（3-18岁），6,051个微主题，10,050条依赖 |
| **无中国课标** | ⚠️ | Marble 映射的是 NGSS/Common Core/英国国家课程。CoEvo 用户在中国，需手动对齐中国课标 |
| **AI 生成+人工审核** | ⚠️ | 数据由 Claude 辅助生成，虽有审核但不能保证 100% 教育专业性 |
| **CoEvo 现有数据结构** | ⚠️ | 现有 prebuilt_cards 的表结构需调整才能关联 Marble 的 topicId |
| **许可证合规** | ✅ | ODbL 允许商业化产品使用 |

---

## 5. 结论

**建议从方案A开始。** 1-2天即可完成数据入库，不影响现有功能，后续可根据反馈决定是否深入。

方案A的好处：
- 零风险：数据只读，不改变现有行为
- 低成本：一个后端 handler + 三张新表
- 为方案B/C预留基础：数据已在，需要时打开功能即可
