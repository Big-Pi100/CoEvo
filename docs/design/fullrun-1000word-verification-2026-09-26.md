## 三、🔴 实施中新发现的 3 个漏洞（已修）

### 3.1 🔴🔴 `word_form.json` 含 **5,692 条双重变形垃圾（15.4%）**

```
abandoneds     ← abandoned     (abandoned 已是过去分词，又被加复数)
abandoneded    ← abandoned
abandoneding   ← abandoned
aberrationsed  ← aberrations   (aberrations 已是复数，又被加过去式)
```

**根因**：旧 `build_word_form.py` 对**已经是变形的词**又展开了一遍。

**✅ 已修**：判据「form 的 base 自己也有 base」→ 丢弃。**实测过滤 3,980 条**。

### 3.2 🔴 `anchor` 必须对**新词表**算，不是旧词表

**踩坑**：对旧词表算 → `carefully`（LLM 判 `is_own_entry=false`，**将不建卡**）会**把自己当 anchor**。

**✅ 已修**：先用 `is_own_entry` 过滤出新词表再算。修正后链断 7 → 27（多出的全是垃圾，**正确暴露**）。

### 3.3 🔴 `action`（映射去留）判据必须用 LLM 的 `is_own_entry`，不是旧库 `in_vocab`

**踩坑**：用旧库 `in_vocab=1` 判 → **误删 10 条必需路由**：

| 词 | LLM 判定 | 误判后果 |
|---|---|---|
| `carefully` | `is_own_entry=false`（不建卡） | 🔴 **划词 `carefully` 无卡可跳** |
| `appropriately` | `false` | 🔴 同上 |

**✅ 已修**：`drop` 仅在 **`is_own_entry=true` 且 `relation=derivation`** 时生效。drop 从 37 → 27。

### 3.4 🆕 幻觉词素新增一类：**连接元音**

**实测**：`technology` 的 **`-o-`**、`monument` 的 **`-u-`**、`oceanography` 的 `-o-` 被当成独立 `root`。

**根因**：这些是**连接元音（combining vowel）**，不是词根（`techno` + `logy`）。
**✅ 已修**：单字符 root 一律过滤（真后缀 `-s`/`-y`/`-a`/`-e` 白名单除外）。实测拦下 4 条。

> **四类幻觉词素汇总**（已全部可拦）：
> ① 单字母后缀 `-d`(bidding) `-n`(given) · ② 无意义后缀 `-e`(resolute) ·
> ③ 假词根 `st`(stable) · ④ **连接元音 `-o-`/`-u-`**
