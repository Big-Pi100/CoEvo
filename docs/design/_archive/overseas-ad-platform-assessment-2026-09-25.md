## 〇、直接结论

> **技术上是所有方案里最好的（官方 Flutter 插件、个人可注册、结算透明），但「中国区分发 + 国外广告平台」有 3 层独立阻塞，其中合规层是硬的。**
>
> **而这三层阻塞全部指向同一个答案：把「国外广告平台」和「海外区上架」绑在一起用 —— 那正是路径 C，而且它现在看起来比路径 D 更优。**

| 组合 | 可行性 | 说明 |
|---|---|---|
| 中国区上架 + AdMob | ❌ **不可行** | 广告内容监管 + 数据出境 + 后台不可访问（见 §二） |
| **海外区上架 + AdMob** | ✅ **可行且干净** | 即路径 C；技术上零桥接开发，eCPM 反而更高（见 §三） |
| 中国区上架 + 国内聚合平台 | ⚠️ 灰色 | 即路径 D（见 `ad-monetization` 文档） |

**关键反转**：中国区流量在 AdMob 眼里是 **Tier 3 靠下**（eCPM $0.8–1.5），而东南亚/日韩是它的 4–8 倍。**所以「做海外区」的广告收益很可能高于「做中国区」** —— 这与早前「海外区收益有限」的判断相反。

## 一、技术上：这是所有方案里最成熟的一条

### 1.1 `google_mobile_ads` 是 Google 官方 Flutter 插件

| 项 | 实测 |
|---|---|
| 发布者 | **`google.dev`**（Google 官方，非第三方维护） |
| likes / 下载 | **2,480 likes ｜ 712k 下载** |
| 最新版本 | **9.0.0** |
| 前置要求 | **Flutter 3.27.0+**（Ad Manager 路线要求 3.38.1+） |
| 支持格式 | Banner · Interstitial · Native · **Rewarded** · App Open · Rewarded Interstitial |
| 官方文档 | `developers.google.com/admob/flutter/quick-start` |

**接入成本几乎为零**：

```dart
// 1. 初始化（main.dart）
MobileAds.instance.initialize();

// 2. iOS 侧只需改 Info.plist
//    GADApplicationIdentifier = ca-app-pub-################~##########
```

**这是决定性的对比**：

| 方案 | 技术路径 | 开发量 |
|---|---|---|
| **AdMob** | **官方 Flutter 插件** | **≈ 0**（只改 Info.plist + 调用 API） |
| 国内聚合平台（有 Flutter SDK 的） | 第三方 Flutter 包 | 低（但个人政策未知） |
| 国内聚合平台（只有原生 SDK 的） | **自写 platform channel** | **1,200–1,600 行 / 2–3 周** |

### 1.2 个人可注册（AdMob 官方明确）

AdMob 官方注册流程第 3 步原文：

> 收款信息包括您的**姓名**、**账号类型（个人或组织）**以及收款地址。

**「个人或组织」并列 → 个人可注册，不需要公司、不需要营业执照。**（网上流传的「需营业执照」是内容农场文章的错误，把企业用的 W-8BEN-E 与个人用的 W-8BEN 搞混了。）

**⚠️ 但有一个不可逆的坑**：

> 选择您目前居住的国家或地区……**您之后无法对此进行更改。**

注册地决定收款验证方式，**一次选定不能改** → 建议注册前想清楚（用中国大陆身份证 + 国内银行账户是可收款路径，见 §五）。

### 1.3 但有一个顺序约束

**AdMob 要求 App 已上架**（多个来源一致：「AdMob要求App已在Google Play或App Store上线」「测试包（如APK直装）不被认可」）。

→ **必须先上架，才能接 AdMob**。不能先接好广告再上架。

**这反而与路径 D 的风险缓释设计吻合**（见 `ad-monetization` §8.4）：「先上免费版 → 上架后加广告」，两边都指向同一个顺序。

## 二、❌ 但中国区分发有三层独立阻塞

三层各自独立成立，任一层都足以否决。

### 2.1 技术层：AdMob 后台在中国大陆无法稳定访问

| 事实 | 来源 |
|---|---|
| 「AdMob 管理后台（apps.admob.com）和 SDK 资源域名在中国大陆常规网络环境下**无法稳定访问**」 | 大数跨境 |
| 「Google 主站在中国平均**加载失败率 98.7%**」 | Pingdome Global Network Performance Report 2023 |

**这一条的实际影响**：即使 SDK 在用户设备上能请求到广告，**开发者本人无法登录后台**——看不到数据、配不了广告位、提不了款、无法申诉。

> ⚠️ **这条值得你亲自实测**（3 分钟，与上一轮的 App Store 实证同一思路）：**用 iPhone Safari 打开 `apps.admob.com`**。
> - 打不开 → 确认无法运营，此路不通
> - 能打开 → 技术层阻塞减轻，但**合规层（2.3）仍然成立**
>
> **不要把这条当作唯一依据** —— 它的表述偏绝对，而 AdMob SDK 的实际广告请求域名（`googleads.g.doubleclick.net`）在境内部分可达。真正的经营者是「你能否管理账户」，不是「SDK 能否请求」。

### 2.2 收益层：中国区流量的 eCPM 极低

| 地区 | AdMob eCPM（2026 基准） |
|---|---|
| 美国 / Tier 1 | $4–22（激励视频 $14–22、插屏 $9–14） |
| Tier 2（日韩等） | $5–10（激励视频 $8–10） |
| **中国区** | **$0.8–1.5** ← 实测口径 |
| Tier 3 | $2–3（激励视频） |

**根因**：广告库存的地域分配极度不均 —— 「**国内广告库存仅占全球总量的 3.7%**」（Statista 2023）；「中国区 eCPM 显著低于欧美（$4–8），主因是**国内广告主竞价活跃度低**」。

> **一条我判定不可信的第三方说法**：有内容农场文章称「谷歌服务未在中国大陆正式运营，**所有广告收入统计均排除该区域**」「实际收入结算以非中国大陆用户的展示与点击为准」。
> **这与 AdMob 官方政策不符**（AdMob 是全球平台，没有地域排除条款），我倾向认为该文作者把「Google 搜索业务退出中国」与「AdMob 广告业务」混淆了。
> **但保守估计也不改变结论**：即使中国区流量计费，eCPM $0.8–1.5 也远低于其他地方。**结论不依赖这条存疑信息。**

### 2.3 合规层（最严重）：两层监管，都是硬的

#### ① 广告内容监管 —— 境外平台无法对接中国广告审查

- 《广告法》第四十条 + 《互联网广告管理办法》（2023 修订）第七条：**所有在中国境内发布或展示的广告内容必须接受国家市场监督管理总局监管**
  → **即便广告由境外平台（如 AdMob）提供，只要用户位于中国且广告内容可被访问，就可能被认定为「在中国境内发布广告」**，从而需符合本地审查要求
- **AdMob 无法对接中国广告审查系统** → 无法确保广告素材不含敏感内容（政治、赌博、仿牌）→ 违反《互联网广告可识别性执法指南》的「广告须显著标识且内容合法」

#### ② 数据出境 —— 未列入认可清单

| 要求 | 我们的情况 |
|---|---|
| 《个人信息出境标准合同办法》：向境外传输个人信息需**签标准合同或做安全评估** | AdMob SDK 默认收集**设备标识符（GAID/IDFA）、IP、应用使用行为**，全部回传境外 |
| **Google 尚未被列入中国认可的跨境数据流动白名单** | 网信办公告 |
| 《数据出境安全评估办法》第四条 | 处理超 100 万用户个人信息须申报安全评估（早期达不到，但**规模上去后触发**） |

**已有实际处置案例**：

> **2023 年工信部通报的 56 款违规 App 中，有 17 款因「擅自调用海外广告 SDK 导致数据外泄」被下架。**

**47% 的占比（17/56）意味着这是高确定性风险，不是「可能」。**

#### ③ 还有一层加剧因素：即将落地的新规

CAC（网信办）**2026-01-10 发布的《互联网应用程序个人信息收集使用规定（征求意见稿）》**：

> 适用范围**明确涵盖「嵌入式 SDK」**；**App 运营者对其自身及内嵌 SDK 的数据行为负主要责任**，须**技术审计 SDK 行为**。

→ 境外广告 SDK 会被要求提供合规材料，而 AdMob 是境外主体、无中国备案。

#### ④ 叠加 APP 备案环节

APP 备案要求填报 **SDK 清单 + 权限调用说明**。填一个境外广告 SDK，等于**主动标记自己做了跨境数据传输**——备案环节就可能被驳回，或被要求补充材料。

**综合判断**：

```
中国区上架 + AdMob
  技术层：App 内 SDK 也许能跑（但后台管理不了）
  收益层：可以收，但 eCPM $0.8-1.5
  合规层：❌ 广告内容监管 + 数据出境 —— 两条都硬
```

**→ 不可行。而且比路径 D 更差** —— 路径 D 是「超范围经营」（一个备案层面的问题），这条是「**广告内容违法 + 数据出境违规**」（两个不同法规体系的问题），并且有 47% 下架率的实证案例。

## 三、🔑 但结论反转：海外区 + AdMob 反而是最优解

三层阻塞全部指向同一个方向：**把 AdMob 用在海外区**——那就是路径 C。

而且有个**反直觉的收益结论**：

| 对比 | 中国区流量 | 海外华人 / 东南亚 |
|---|---|---|
| AdMob eCPM（激励视频） | **$0.8–1.5** | **$6.8（东南亚）～$14–22（欧美）** |
| 广告库存占比 | **3.7%** | **96%+** |
| 广告主竞价 | 国内广告主不买境外平台 | Google Ads 全球需求池 |

**「做海外区」的广告收益可能比「做中国区」高 4–8 倍** —— 这推翻了我早前「海外区收益有限」的判断。

### 3.1 路径重排：C 从「备选」升到「首选」

| # | 路径 | 做法 | 成本 | 法律 | 技术 | 收益预期 |
|---|---|---|---|---|---|---|
| **①** | **C · 海外区 + AdMob** | 上架海外区（不含中国大陆），**AdMob + Apple IAP** | $99/年 + 收款手续费 | ✅ **干净** | ✅ **零桥接**（官方插件） | **可能最高**（eCPM 4–8 倍） |
| ② | D · 中国区 + 国内聚合 | 个人身份 + 聚合平台 | ¥0 | ⚠️ 灰色 | 🟠 视平台（0 或 2–3 周） | 中（国内 adx） |
| ③ | A · 注册公司 | 公司 + ICP 经营许可 + 直连穿山甲/优量汇 | ¥1.5–3 万 + 2–3 月 | ✅ 干净 | 🟠 需软著 + 上架 | 中高 |
| ④ | B · 免费版 | 只上架不变现 | $99/年 | ✅ 干净 | ✅ 零 | 0 |

**C 现在同时胜在四点**：法律干净 · 技术最简单 · 个人友好（AdMob 明确接受个人）· 收益预期最高。

### 3.2 但 C 的代价必须说清楚

| 代价 | 说明 |
|---|---|
| **没有中国大陆用户** | 这是最大的代价。产品是中文界面 + 中英对照词卡 → 只服务**海外中文母语者**（海外华人、留学生、港澳台、东南亚华人） |
| 收款受限 | 个人结汇 5 万美元/年额度；需 W-8BEN；单笔超 $5,000 需国际收支申报 |
| 广告延迟 | 新账户有观察期，「起量慢」 |

**这里有一个只有你能判断的问题**：**海外中文母语者的英语学习需求，是否足够支撑这个产品？**

我的看法：**可能存在被低估的需求**——
- 海外华人家长对子女的中文/英文双重需求强
- 留学生、新移民的英语提升需求刚性且付费能力强
- 港澳台地区用户的英文学习需求长期存在
- 而且**他们的 eCPM 是日韩/欧美级别**，变现效率远高于中国大陆用户

**但我没有数据支撑这个判断**，这属于市场判断，需要你自己定。

### 3.3 第三条路：双版本（技术上可行，但建议后置）

同一套 Flutter 代码，广告层做抽象后按区域切换广告源：

```
中国区构建  → 国内聚合平台 SDK
海外区构建  → google_mobile_ads
```

**技术上完全可行**（Flutter 条件编译 + flavor），但**不建议现在做**：
- 早期用户量不足以支撑双市场运营（客服、审核、税务都要分两套）
- 先把一个市场跑通，验证「有没有人用」，再决定是否分叉

## 五、如果走 C：收款细节（已核实）

| 项 | 内容 |
|---|---|
| 门槛 | **$100**（未达标顺延下月） |
| 周期 | 每月 1–6 日核算上月，**21 日打款**；电汇到账 3–14 个工作日 |
| 币种 | **美元**（国内银行自动结汇为人民币） |
| **税务** | 个人填 **W-8BEN**（非美国纳税人声明）→ 依据中美税收协定，预扣税 **30% → 10%**；有效期 3 年 |
| 账户类型 | **个人**（与「组织」并列，官方口径） |
| 收款方式 | ① 国内银行电汇（需 SWIFT/BIC，如招商银行全币种账户）② **Payoneer**（约 2%，最低 $20 可提）③ PingPong（约 1.5%） |
| 隐性成本 | 中间行手续费 **$15–30/笔**；汇率以付款月首个工作日 Google 基准价为准（比市场价低 1.5–2%） |
| ⚠️ 外汇管制 | 个人结汇 **5 万美元/年**；单笔超 $5,000 需国际收支申报 |
| ⚠️ 平台抽成 | **口径不一**：主流说法 **32%**（开发者得 68%）；另有来源称 15–20%。**建议在 AdMob 后台实测自己的实际单价** |

**出现频率最高的提现失败原因**（FYI）：
- 银行信息不匹配（41%）
- W-8BEN 签名缺失 / 地址与身份证不一致（约 15%）
→ **地址必须与银行账户、身份证完全一致**，不要用虚拟地址。

**⚠️ 一条风险提醒**：AdMob 封号后果比国内平台重——「若因政策违规被封，**未付款项可能被永久冻结**」。避免诱导点击、避免自己狂点测试广告（用官方测试广告位 ID）。
