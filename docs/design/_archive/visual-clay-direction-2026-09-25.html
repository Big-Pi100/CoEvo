粘土：让「可触摸」变成界面语言

Claymorphism 的核心是一条几乎被忽视的规则 —— 元素的填充色可以与背景无关。这恰好绕开了 Neumorphism 死掉的真正原因（必须与背景同色，导致对比度天花板极低）。

但它的正确用法不是「全都做成粘土」。我建议的规则是：内容保持平面，可交互的东西才有体积。文字永远不动，能被戳的东西才是粘土。

这带来一个额外好处 —— 粘土感本身就在说「按我」，可点击性变成了直觉，不需要边框或下划线去提示。

01
三重阴影：每一层在做什么
Claymorphism 不是「大圆角 + 阴影」。它是一条三个阴影层的固定公式 —— 少任何一层，效果就塌。
逐层叠加
① 仅外阴影
7px 9px 18px rgba(150,125,95,.26)
只做一件事：把形状从背景上抬起来
② + 内暗影
inset -5px -5px 11px rgba(186,166,138,.55)
右下沉下去 —— 产生体积与凹面
③ + 内亮影 ＝ 粘土
inset 4px 4px 10px rgba(255,255,255,1)
左上鼓起来 —— 这一步才「充气」
④ 按下状态
两个 inset 反向，去掉外阴影
外阴影消失 = 沉进页面 —— 按压反馈
阴影公式（三条必须同一条声明，顺序不能改）
box-shadow:
  7px 9px 18px   rgba(150,125,95,.26),      /* ① 外阴影 · 浮起 */
  inset -5px -5px 11px rgba(186,166,138,.55),  /* ② 内暗 · 体积 */
  inset 4px 4px 10px  rgba(255,255,255,1);      /* ③ 内亮 · 充气 */
三个细节决定成败：外阴影要染成元素自身的色相（用中性灰/黑会让粘土发脏）；两个 inset 必须反向且与全站光方向一致（左上光）；内亮要比内暗更亮、更透明 —— 完全对称的一对会读成塑料而不是粘土。

03
深色模式：需要如实说明的取舍
Claymorphism 在深色下是公认的弱点 —— 不是不能做，是做不到浅色那么好。

浅色 · 粘土的原生环境

粘土感依赖「亮部高光」。浅色底上，白色内亮影可以开到 rgba(255,255,255,1) —— 膨胀感完整。这是 claymorphism 真正的主场。

膨胀感完整对比度可控阴影自然

深色 · 必须降级处理

白高光在深色底上会变成「发光」而非「膨胀」。必须把内亮压到 0.05–0.07，同时加大外阴影不透明度。结果是体积感减弱约一半，但换来不刺眼。

高光要压到 6%膨胀感弱化夜读友好
04
Flutter 实现：技术成本要说清楚
这是 HTML 原型，但真正要跑在 Flutter 上。有一个原生缺口。

🔴 Flutter 不支持 inset 阴影

Flutter 的 BoxShadow 只有外阴影，没有 inset 属性。而粘土效果的核心恰恰是两个 inset 阴影。

所以我实测了现成的包 flutter_inset_box_shadow —— 最新版 2022-04 发布，已 4 年未更新，且要求 hide BoxDecoration 替换整个类型，风险高。不建议引入。

✅ 推荐：自研 200 行，渐进式落地

第一步（覆盖约 80% 效果，零依赖）：外阴影用原生 BoxShadow，内阴影用 foregroundDecoration + LinearGradient 模拟。

第二步（若视觉不够）：写一个 ClayDecoration CustomPainter，按 Chromium 的做法「画一个被圆角矩形挖空的矩形再模糊」，约 150–200 行，零第三方依赖、完全可控。

动效是粘土感的一半

粘土不仅靠阴影，还靠弹性。按下时缩放 0.95 并用 Curves.elasticOut 回弹 —— 这是 Flutter 的原生强项，几乎零成本。

缺了动效，粘土只是个圆角卡片。有了它，用户会真的想去戳。

额外工程量：约 1 周

ClayDecoration 组件 + 设计 token（光方向、模糊比例、按尺寸缩放的圆角）+ 现有 theme 扩展。

建议在 Step 2「设计系统」阶段做，与调色板一起定。不影响 Phase 1 的清障工作。

这一版的框架做了修正

上一版我把 A 墨 / B 格 / C 夜 并列成「三选一」。加入粘土之后，框架应该分成两层 —— 因为粘土是一种质感语言，不是配色语言，它可以叠加在任何底色上：

  • 层级一 · 底色氛围：墨（暖纸） / 格（纯白） / 夜（深墨）→ 决定阅读体验与痕迹语法
  • 层级二 · 质感语言：平面 / 粘土 → 决定交互元素的手感

所以真正的选项是组合，不只是「选一个」。从搭配协调度看：
墨 + 粘土 —— 最协调（暖沙色系与粘土天然的柔和感同源）
格 + 粘土 —— 张力最大（Swiss 网格的硬朗与粘土的柔软相冲，但冲得有意思）
夜 + 粘土 —— 最独特但有代价（深色下粘土要降级处理，膨胀感减半）

还有一个纯粘土方案：全粘土（不做底色方向，整站粘土化）—— 视觉记忆点最强，风险是阅读界面必须仍然保持零粘土，否则读不下去。
