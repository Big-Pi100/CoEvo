## 一、问题：功能简单，视觉就是产品

白哥的判断：「我们的功能其实很简单，所以视觉上其实非常重要。」

这是对的，而且可以量化。产品能力清单：

| 能力 | 竞品状态 |
|---|---|
| RSS 内容流 | 通用技术 |
| 划词查词 | 词典 App 有，阅读 App 没有 |
| 生词本 + FSRS 复习 | Anki / 墨墨都有 |
| 语音包离线播放 | 通用技术 |

**没有任何一项是护城河。** 那么用户为什么选我们、留下、并且愿意看广告？

### 1.1 我上一版给的建议不够

我之前写的是「双轨设计语言：激励层用 Duolingo 风，阅读层用微信读书那样的克制排版」。

**问题在于：微信读书的视觉是「功能性的干净」，不是「有主张的克制」。** 它好看，但它没有性格 —— 换个 logo 就变成另一个产品。照搬它，等于主动放弃唯一的差异化战场。

### 1.2 真正的差异化空间在哪

阅读场景确实要求克制（不能打扰阅读）。但克制不等于平淡，差异化的空间在三个地方：

| 位置 | 为什么可以做个性 |
|---|---|
| **阅读界面的细节** | 排版质量、留白节奏、以及下面要讲的「痕迹」 |
| **外围界面** | 信息流、复习、统计不干扰阅读，可以强个性 |
| **品牌触点** | 启动、加载、空状态、成就、分享图 |

## 二、视觉签名：痕迹

### 2.1 我找到的这条主线

产品有一条**独有的行为链**：

```
读文章 → 划线查词 → 词进入生词本 → FSRS 复习 → 从「陌生」变成「我的」
```

这条链在页面上可以留下**痕迹**，而痕迹会随熟练度**逐渐淡去**。

> **学习的终点，是痕迹的消失。**
> 真正掌握一个词之后，它对你来说就是普通文字，不再需要被标记。

### 2.2 为什么这是「竞品做不出来」的

| 竞品 | 为什么没有 |
|---|---|
| 微信读书 / Kindle | 有阅读，没有查词记忆系统 |
| 欧路词典 / 有道 | 有查词，没有长文阅读场景 |
| 多邻国 / 墨墨 | 有记忆系统，没有阅读 |
| Anki | 有记忆系统，卡片是独立的，不在语境里 |

**只有「长文阅读 + 查词记忆」同时存在时，痕迹才有意义。** 而这是我们的产品形态本身。

### 2.3 它同时是功能，不只是装饰

这一点很重要 —— 痕迹不是我们硬加的美术效果：

1. **区分「我的词」和生词** —— 打开一篇文章，一眼看出哪些词是我学过的
2. **难度预判** —— 生词密度高就别硬啃
3. **进步可见** —— 重读旧文章时，痕迹变淡 = 你真的进步了
4. **把「读」和「记」在视觉上连起来** —— 用户能感知到这两个动作是一个整体

### 2.4 三态定义（与 FSRS 状态映射）

| 态 | 触发条件 | 视觉强度 | 用户感受 |
|---|---|---|---|
| **刚查过** | `reps = 0`（查了但没复习过） | 最明显 | 「这词我不认识」 |
| **复习中** | `reps 1–2`，或 stability 未达阈值 | 中等 | 「有印象了」 |
| **已掌握** | `reps ≥ 3 且 lapses = 0`（暂定，可调） | 几乎不可见 | 「这就是我的词」 |

> 阈值沿用 §5.7.3 统计页「掌握词数」的既有口径，保持一致。

### 2.5 ⚠️ 一个必须处理的风险：痕迹会不会干扰阅读

**会，如果做得太明显。** 三条处理原则：

| 原则 | 做法 |
|---|---|
| **已掌握态必须近乎不可见** | 不是「淡」，是「几乎看不出」。它只是让这个词比周围文字暖一点点 |
| **界面上不放开关** | 遵守「阅读界面保持单纯」的决策，界面上没有多余元素 |
| **开关放阅读设置面板内** | 需求真实存在（有用户就是不喜欢任何标记），设置里能找到即可，默认**开启** |

## 三、三个方向

三个方向**共用同一份数据、同一套熟练度定义**，差异只在**痕迹的语法** —— 也就是用哪种视觉语言表达「熟悉程度」。这决定的不只是好看，而是产品性格。

---

### 方向 A · 墨（Paper & Ink）

| 项 | 值 |
|---|---|
| **隐喻** | 一本被反复读过的书，铅笔留下的印子 |
| **底色** | 暖白 `#FAF8F4`（阅读区）／ 纯白 `#FFFFFF`（卡片） |
| **正文** | `#24211C`（暖黑，不用纯黑） |
| **强调色** | 朱砂 `#B4432C` |
| **正文行高** | 1.82（偏松，书感） |
| **痕迹语法** | **底色浸染** —— 极淡的朱砂底纹，三态用 alpha 0.145 / 0.072 / 0.025 |
| **辅助字体** | Inter（UI）+ Literata（正文）+ Charis SIL（IPA） |
| **圆角** | 大（16–20px），柔和 |
| **气质** | 安静、温暖、书卷气、东方印记 |

**优势**：最贴「阅读」这个行为本身；暖色底长时间阅读不易疲劳；朱砂印记有辨识度且不喧哗。

**风险**：偏文艺，可能对「想快速提升英语」的功利型用户不够「有效率感」。

---

### 方向 B · 格（Grid & Lab）

| 项 | 值 |
|---|---|
| **隐喻** | 语言学实验记录 / Swiss 排版 / 校对稿 |
| **底色** | 纯白 `#FFFFFF` |
| **正文** | `#141414`（近黑） |
| **强调色** | 电光青绿 `#00C08B` |
| **正文行高** | 1.74（偏紧，信息密度高） |
| **痕迹语法** | **下划线** —— 三态用线宽与透明度（2.5px 实线 / 1.5px 半透明 / 1px 虚线） |
| **辅助字体** | **JetBrains Mono 用于音标与元数据** + Inter（UI）+ Literata（正文） |
| **圆角** | 极小（2–4px），硬朗 |
| **气质** | 精密、理性、工具感、现代 |

**特征细节**：
- 音标用**等宽字体**（`/ˈvɜːtɪkl/` 对齐全站统一），这是语言学工具的经典做法
- 元数据（时长、生词数）用等宽 + 竖线分隔，非圆角胶囊
- 信息流卡片用**横线分隔**而非卡片阴影（Swiss 网格）
- 词卡的词性标签是实心色块（`ADJ.`）

**优势**：最有「专业学习工具」的感觉；等宽音标与网格系统在同类产品里几乎没人做；和「数据/进步」这类界面天然契合。

**风险**：偏冷，情感温度低；用户可能觉得「像科研软件」。

---

### 方向 C · 夜（Field & Sound）

| 项 | 值 |
|---|---|
| **隐喻** | 深夜专注、暗房里的一束光、声音的场 |
| **底色** | 深墨 `#14161C`（阅读区）/ `#1C1F27`（卡片） |
| **正文** | `#C9C7C2`（**不是纯白** —— 深色底上纯白会眩光） |
| **强调色** | 暖橙 `#FF8A45` + 薄荷 `#6EE7B7`（辅助） |
| **正文行高** | 1.84 |
| **痕迹语法** | **光** —— 熟练度 = 亮度。三态：`#FFD9B8`（暖光）/ `#DEDCD7` / `#8E939F` |
| **辅助字体** | Inter + Literata + Charis SIL |
| **圆角** | 大（18–20px） |
| **气质** | 沉浸、夜间、像音乐 App、有情绪 |

**优势**：**夜间阅读是真实的高频场景**，多数阅读类产品夜间模式只是「反色」，而我们把它做成主语言；深色 + 暖橙的对比度强，视觉记忆点最突出；Literata 在深色上表现优秀（Google Play Books 就是这样用的）。

**风险**：白天阅读的用户会觉得重；办公/通勤场景下深色可能不如浅色舒服。

### 3.4 三者对比

| 维度 | A 墨 | B 格 | C 夜 |
|---|---|---|---|
| 痕迹语法 | 底色浸染 | 下划线 | 光 |
| 底色 | 暖白 | 纯白 | 深墨 |
| 气质 | 温暖书卷 | 冷静精密 | 沉浸情绪 |
| 记忆点 | 中 | 中高 | **高** |
| 白天体验 | **最好** | 好 | 差 |
| 夜间体验 | 中（需另做深色版） | 中（需另做深色版） | **最好** |
| 「学习效率感」 | 低 | **高** | 中 |
| 情感温度 | **高** | 低 | 中高 |
| 竞品相似度 | 中（像纸质书类 App） | **低** | 中（像音乐/冥想 App） |

### 3.5 混合可能性（值得考虑）

三个方向不是互斥的。**最有可能的最优解是混合**：

```
基础语言：A 墨 或 C 夜（二选一作为产品主色）
    +
痕迹语法：可独立选择（底色浸染 / 下划线 / 光）
    +
B 格的局部要素：等宽音标 + 网格化的数据界面
```

举例：**A 的暖纸底 + B 的等宽音标 + A 的底色浸染痕迹** —— 白天舒适、音标专业、痕迹有手作感。

**但主底色（暖白 / 纯白 / 深墨）必须选一个**，它决定产品给人的第一印象。

## 四、与既有决策的关系

### 4.1 「双轨设计语言」需要修正

之前定的方案是：

| 层 | 原方案 |
|---|---|
| 激励层 | Duolingo 风（高饱和绿、3D 按钮、活泼插画） |
| 阅读层 | 克制排版（微信读书风） |

**问题**：两套语言会让产品看起来像两个 App 拼起来的。Duolingo 的高饱和绿 `#58cc02` 和任何一个上述方向的配色都冲突。

**修正建议**：**以选定的方向为唯一视觉系统**，激励层（成就、分享图、引导页）只做「同色系内的活泼」——保留 Duolingo 的**动效与结构**（进度感、庆祝反馈、圆润造型），但**改用选定方向的调色板**。

| 层 | 修正后 |
|---|---|
| 全站基调 | **选定方向**（如 A 墨：暖纸 + 朱砂） |
| 激励层 | 同调色板 + Duolingo 式的动效与节奏 |
| 阅读层 | 同调色板 + 最高克制度 |

这样产品是一个整体，而激励层依然「活泼」——活泼来自动效与节奏，不是来自换一套颜色。

### 4.2 对排版规格的影响

§6.6 的排版规格需要按选定方向微调：

| 项 | A 墨 | B 格 | C 夜 |
|---|---|---|---|
| 行高 | 1.82 | 1.74 | 1.84 |
| 正文色 | `#2A261F` | `#141414` | `#C9C7C2` |
| 圆角 | 16–20px | 2–4px | 18–20px |
| 音标字体 | Charis SIL | **JetBrains Mono** | Charis SIL |
