## 二、为什么这个模型成立

**核心前提：全产品边际成本趋近于零。**

| 成本项 | 性质 | 金额 |
|---|---|---|
| 词库（12,791 卡） | 一次性生成 | 已投入 |
| 语音包（63,048 条） | 一次性生成 | ¥48.7 |
| 语音包分发 | 一次性/用户 | ¥0.227（290 MB @ CDN ¥0.8/GB） |
| 阅读器 / 查词 / 复习 / 朗读 | 纯本地计算 | 0 |
| 服务器 | 仅登录 / 同步 | 极低 |

**没有任何按使用量计费的项目。** 因此广告和会员都是**纯增量收入**。

> 这也是不引入跟读评测（¥0.005/次）等消耗型功能的原因 —— 那会引入边际成本，让模型从「纯增量」变成「有成本上限约束」，复杂度上升。

## 四、单用户经济模型

| 项 | 数值 |
|---|---|
| 月广告 ARPU | ¥1.5–4.5（日看 1–3 次 × eCPM 30–50） |
| 会员转化率 | 假设 3% → ¥0.30/月 |
| **月均总收入/活跃用户** | **约 ¥3.2** |
| 语音包分发（一次性） | ¥0.227 |
| 首月净收入 | 约 ¥3.0 |
| 次月起净收入 | 约 ¥3.2（分发成本已摊销） |

**结论：模型健康。**

**唯一敏感度**：广告收入对**日展示次数**高度敏感。日均 0.5 次 → ARPU 降到 ¥0.75。
→ **核心工作是「让用户每天都打开」，不是「提高会员转化率」。**

## 五、广告形式（体验底线）

| 形式 | 采用 | 说明 |
|---|---|---|
| 开屏 | ✅ | 冷启动，可跳过 |
| 原生信息流 | ✅ | 书库列表页自然插入 |
| 插屏 | ⚠️ 谨慎 | 只在**离开阅读器时**展示 |
| 激励视频 | ✅ | 用户主动观看，eCPM 最高 |
| **横幅 Banner** | ❌ | 阅读时持续占位，伤害体验 |

**关键原则：阅读过程中绝不能出现广告。** 阅读是沉浸场景，一次打断就会流失用户。

**SDK**：海外区 Google AdMob；中国区穿山甲 / 优量汇。

## 六、一个需要留意但不阻塞的点

广告 ARPU（¥1.8–3.0）低于会员价（¥9.9）：

- 纯收益看，用户看广告比付费更划算（付费后不再产生广告收入）
- 但会员的真实作用是**留住不接受广告的用户**（否则直接流失），不是提高客单价

→ 所以 9.9 这个定价不需要动。

**需要新增的**：广告开关。

