四个分支的文案（后端已定案，前端照搬）：
· 原密码错 → 原密码不正确
· 新密码弱 → 密码至少6位含英文+数字
· 新旧相同 → 新密码不能与原密码相同
· 无密码账号 → 该账号尚未设置密码，请先完成注册
⚠️ 最后一条是匿名试用账号（从未设密码）—— 它在这一行点击会看到这句， 而不是一个「点了没反应的死入口」。
为什么「其他设备需要重新登录」这句话必须有：
后端在改密码成功后会失效该用户的其他会话（保留当前这台）—— 这是为了防「账号被盗后，主人改了密码而攻击者的会话仍然有效」。
📌 这是真实的副作用，用户事先就该知道；否则他会以为「App 出故障把我踢了」。

四成功之后 ✅ 推荐轻提示

改成功后不弹新弹层（弹层套弹层会让人以为还没完成）， 直接用既有 toast 提示 —— 与「导入电子书成功」用的是同一套。
