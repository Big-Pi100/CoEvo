一条数学结论，决定了可选范围
药丸内容 = [图标 13][间距 6][文字]。图标只占左边、右边没有对称物 → 「图标 + 文字」整块居中时，文字必然偏右 (13+6)/2 = 9.5px （这是数学必然，不是实现问题）。
想消掉这 9.5px 只有两条路：① 右侧留出与图标等量的空白（＝我上一轮的做法，观感更糟）； ② 不要图标（＝方案 ⑤）。
所以：只要保留图标，文字就一定是 +9.5px，没有第三种可能。
