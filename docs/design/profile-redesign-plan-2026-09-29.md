### 🔴 顺带查出一个**真 bug**（不是设计问题）

`:604` `:610` `:616` `:642` 四处 `context.push` 指向**未注册的路由**：

| 路由 | 在 `app.dart` 路由表？ | 后果 |
|---|---|---|
| `/earnings`（收益明细） | 🔴 未注册 | 落到 `/:unknown` → **点了没反应 / 跳到奇怪页面** |

### 「风格不符合整体风格」的具体表现

| 项 | 现状（本页） | 其他 tab 页（信息流 / 复习） |

## 四、重设计方案

### 结构（按 §6.1 定稿 + 现役视觉语言）

```
我的                            ← 自绘顶栏（23px/w600/−0.345），副标题「白哥 · 免费版」
├ 顶部统计区（Clay 大卡）        ← 连续天数 + 掌握词数 + 「分享我的学习记录」
├ 账号                          ← 头像 + 昵称（**删实名 / 手机号**）
├ 内容偏好                       ← 🆕 兴趣筛选（§6.3 定「留在我的页」）
├ 订阅                          ← 订阅状态 / 管理订阅 · **恢复购买** / 历史订单
└ 其他                          ← 联系工作人员 / 🆕 关于
```

### 与现状的差异（逐项）

| 项 | 改动 | 依据 |
|---|---|---|
| 外壳 | `AppBar` → **自绘顶栏**（与信息流/复习页逐字一致） | 现役页统一写法 |
| 容器 | `Container` → **`Clay`** | 同上 |
| 分区 | 直堆 → **分组 + 分组标题** | 复习页语汇 |
| 间距 | 手写值 → **`CoSpacing`** token | 现役页统一 |
| 底部 | 补 `tabBarClearance = 100` | `_ShellScaffold` 开了 `extendBody:true` |
| 删 | 推广二维码 · 推广统计 · 真实姓名 · 手机号 · 跳过概念 · trial 弹窗 | §4.2 / `:456` / `:457` / `:386` / `:391` |
| 加 | 兴趣筛选 · 关于 · 恢复购买（显式一行） | §6.1 |
| 调 | 成就区 → 「统计区 + 分享入口」 | §4.2 / `:396` |

### 三档主题都成立

原型里三档（墨/格/夜）**用真实 token 值**（照 `coevo_tokens.dart` 实测），可实时切换验证。
⚠️ **夜档最容易出问题** —— 粘土「内亮」在深底被压到 `rgba(255,255,255,.062)`，
所以**务必切到夜档看一遍**再定。

## 五、🔴 待白哥决策的 3 件（**依赖未就绪**，不是设计偏好）

| # | 事项 | 冲突点 | 选项 |
|---|---|---|---|
| **1** | **朗读设置**去哪 | §6.3 定「移到阅读界面内」（查词浮层长按 + 阅读设置面板）。🔴 但 `reader_screen.dart:59` 注释明说「面板本身（字号/行高/主题/痕迹开关/**语速**）**是独立一批，不在骨架内**」→ **面板还没做** | **甲**：先留在「我的」（**本次只清理不搬家**）· **乙**：本次一并做阅读面板（范围明显变大） |
| **2** | **主题风格**去哪 | 同上（§6.3 划进阅读面板）。⚠️ 但三档是**全局主题**（影响所有页面），搬进阅读面板后，**不读书时想改主题就没入口了** | **甲**：留在「我的」（它是全局设置，放这语义更对）· **乙**：按 §6.3 搬（或两处入口） |
| **3** | 顶部是「统计区」还是「成就区」 | §4.2 说「连续天数/里程碑并入顶部」+ 统计不设独立页；§6.1 写「顶部：**统计区 + 分享入口**」；而代码放的是 `AchievementSection`（含**成就列表**）→ 三者不是一回事 | **甲**：顶部只放**统计 + 分享**，成就列表留在 `/achievements` · **乙**：保留现有成就列表（页面更长） |
