粘土质感规格（定稿）

质感语言已定：粘土。底色氛围三档全做，用户可切换。 这两者不是并列选项，而是两层叠加 —— 粘土的四个参数是每档主题各自的一组 token。

这一页是给开发照着做的规格：三层阴影公式、尺寸阶梯、圆角与粘土强度的匹配规则、状态、动效。 顶部切换主题，全部组件会跟着变。

主题
阴影层

01粘土解剖：三层阴影，缺一层就不成立

顺序不能改。勾掉顶部任意一层，就能看到它负责什么 —— 外阴影负责「浮起」，内暗负责「体积」，内亮负责「充气」。 少掉内亮的粘土只是个带阴影的圆角方块；少掉内暗会变成纸片。

① 外阴影 · 浮起
6px 8px 16px
② 内暗 · 体积（inset 右下）
inset -5px -5px 12px
③ 内亮 · 充气（inset 左上）
inset 4px 4px 10px
全站光照方向：左上
外阴影像素方向 = 内暗方向 = 右下 · 三者必须一致，否则立体感会「打架」

02尺寸阶梯：同一组参数不能套所有尺寸

26px 的圆角 + 8px 的阴影偏移，放在 120px 的卡片上成立，放在 26px 高的药丸上会糊成一团。 阴影参数必须随元素尺寸缩放 —— 这是最容易在实现时被忽略、上线后才发现的细节。

03⚠️ 一个必须先解决的冲突：圆角承载不了内阴影

校验三档主题参数时发现：「格」主题原本的圆角是 8px（Swiss 网格、硬朗、工具感）， 但粘土的内阴影是 inset -5px -5px 12px —— 影响范围从边缘算起约 17px， 远超 8px 圆角能承载的尺度。

几何关系是硬约束：圆角半径 ≥ inset 偏移 × 3 左右。 圆角不够时，内阴影会绕过圆角形成「月牙状」伪影，边缘看起来发脏 —— 比不做粘土更难看。

这是「格 + 粘土」的真实代价，需要你拍板。 三档主题里，「墨」和「夜」的圆角本来就大（26 / 24px），与粘土天然匹配； 只有「格」需要妥协 —— 要么放大圆角（削弱瑞士网格的硬朗感），要么缩小粘土参数（削弱质感）。 我推荐中间那条：圆角 8px → 14px，参数降到 md 档。这样它仍然是三档里最「精确」的那一个， 因为有更小的圆角、更紧的阴影、以及独一无二的等宽音标字体。

05四态：按下靠「塌陷」，禁用靠「抽掉内亮」

粘土的物理直觉让状态表达变得非常直接 —— 不需要换颜色或加边框。 按下＝凸起转凹陷（它真的被压下去了）；禁用＝抽掉内亮（它瘪了）。 真按一下下面第一个按钮试试。

三层齐全
inset 方向互换 + scale(.97)
保持凸起 + 强调色填 + 外阴影染强调色
只留极淡外阴影 → 视觉上「塌了」

06边界：阅读界面零粘土

为什么这条规则值得写死： 粘土是注意力磁铁 —— 有体积的东西会抓住视线。阅读时用户唯一该注意的是文字。 如果阅读界面里有一个粘土卡片，每次滚动它都会把视线拉过去。 这不是审美判断，是注意力预算的问题。

08Flutter 实现路径（有个原生缺口）

🔴 Flutter 的 BoxShadow 不支持 inset —— 而粘土的核心恰恰是两个 inset。现成的 flutter_inset_box_shadow 最新版发布于 2022-04， 已 4 年未更新，且要求 hide BoxDecoration, BoxShadow 替换整个类型（侵入性高）。不建议引入。 

// 第一步：零依赖方案（约 80% 效果），先用这个上线
BoxDecoration(
  color: t.clayFill,
  borderRadius: BorderRadius.circular(r),
  boxShadow: [BoxShadow(offset: Offset(6, 8), blurRadius: 16, color: t.clOut)],  // ① 外阴影
)
// 内阴影用前景渐变模拟：左上亮 → 右下暗
foregroundDecoration: BoxDecoration(
  borderRadius: BorderRadius.circular(r),
  gradient: LinearGradient(
    begin: Alignment.topLeft, end: Alignment.bottomRight,
    colors: [t.clLight, t.clLight.withOpacity(0), t.clShade.withOpacity(0), t.clShade],
    stops: const [0, .42, .58, 1],
  ),
)

// 第二步：若视觉不够，写 ClayDecoration（约 150–200 行）
// 做法与 Chromium 相同 —— 画一个巨大矩形，用圆角矩形 Path.combine 挖空，
// 再对结果 MaskFilter.blur，最后平移向边缘方向。可 100% 还原 inset。
动效是粘土感的一半。 按下 scale(.97) 90ms + 松手 Curves.elasticOut 回弹 320ms —— 这是 Flutter 的原生强项，几乎零成本。缺了动效，粘土只是个圆角卡片。 额外工程量约 1 周（ClayDecoration 组件 + token 扩展 + 三主题验收）。

看这一页时，重点看三件事

  1. 切到「格」看第 03 节 —— 这是唯一需要你拍板的地方：圆角放宽到 14px，还是把粘土参数缩得更小、保住 8px 的硬朗？（我推荐前者）
  2. 切到「夜」看第 01 和第 04 节 —— 深色下内亮必须压到 6.2%，体积感会明显弱于浅色。这是 claymorphism 的公认弱点，不是实现问题。看这个降级你是否接受。
  3. 按一下第 04、05 节的按钮 —— 粘土的手感一半在动效（凸起 → 凹陷 → 弹性回弹）。静态截图看不出这个。
