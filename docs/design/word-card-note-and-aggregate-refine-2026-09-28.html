一、「段内说明」是什么 —— 锚点里的两种用法

锚点 visual-word-card-target 里有一个类 .mnem-note， 它在两处被用到，但用法不同：

用例段内说明放什么有没有「主体」
disorganized ②词源故事 词源链：organon（希腊·工具／器官）→ 拉丁 organizare → 古法语 organiser → 英语 organize → disorganized 无 —— 它就是这一段的正文
（锚点用 inline 把 margin/padding/border 全置零，说明它没打算做「分隔」）
laser ①词源故事 说明：五个词的首字母拼成的缩写 → 激光器。整体造词，没有词根可拆 —— 词源就是最好的记忆法。 有 —— 上面是 .mnem-main（缩写展开），下面是 .mnem-note
（这时虚线才起作用：段内主次）

🔑 所以「段内说明」= 一个记忆法段里、主体之外的那一层补充： 它解释「为什么这词要这么记」，而不是再讲一遍词源。

1.0 判据：哪种记忆法「最有效」—— 库里已经记着了

先说一个必须先讲的边界：「真实记忆效果」在本机测不出来 —— word.db 里没有任何复习表（只有词库 19 张表）， 而复习数据在设备上的 user.db； 本项目也还没有用户。
→ 所以「哪种记忆法效果更好」无法用本项目数据回答，只能靠两层可得证据。 🔑 如实标注，不假装有数据能证明它。

第一层 · 本项目自己的判定规则（mnemonic_type 表）

这张表就是「遇到什么词该用哪种法」的定义，priority 是判定顺序：

pri类型适用条件（applicable_when）线索的性质
1root 词根词缀可拆成现代英语仍透明的词根/词缀（incredible = in+cred+ible）结构性 · 可迁移（一词根带一串词）
2cognate 同源串记与另一个英语词共享同一词根或词源；谐音不算结构性
3etymology 词源故事整体借词、不可拆（café ← French café）结构性，且对不可拆词是唯一手段
4collocation 搭配整记有 ≥1 条高频固定搭配半结构（用法层）
5image 联想图像抽象词，靠意象或谐音联想人为 —— 依赖个人经验，不可迁移
6context 语境原句默认附加 ← 兜底类别—（不是一种「法」，是没别的法时的落点）
🔑 这张表隐含的「有效性阶梯」是合理的：越结构化的线索越有效 —— 可拆解 > 同源 > 词源 > 搭配 > 人为联想；而 context 根本不在这条阶梯上， 它是「以上都不适用」的兜底。
这与记忆心理学的两条稳共识同向（不引用具体数字，只借方向）： 加工深度（讲得通的结构 > 死记）与 生成效应（要自己动手拆 > 只读一遍）。

第二层 · 那条「最有效的线索」，卡上到底给没给到

🔴 关键一步：每个词最有效的记忆法，库里已经记着了 —— 就是 profile.primary_code （制卡时按上表判定），而 rationale 正是「为什么这种法对这个词有效」。

于是「该不该显示」就不再是覆盖率问题，而是：

显示优先级 ＝ 那条被判为「最有效」的记忆法，在卡上有没有被给到
· 已经给了（段里就是它）→ rationale 只是复述 → 不显示
· 没给到 → rationale 是这条线索的唯一出口 → 必须显示

1.2 重合率：一条约束，不是排序依据 判据已降级

🔴 本稿第一版把这一节当成了判据 —— 那是错的（白哥纠正）。 它现在的地位是「排除法」的辅助：高重合 → 确定不必显示； 但低重合不能推出「该显示」，因为低重合有两种相反的含义（§1.0 开头那条）。

我把 rationale 与「该词卡上实际显示的那两段（按 CardSlots.resolve 补位后的 ① ②） + etymology_text」做了内容重合度比对（词集合，中英文都算）：

root 词根词缀5,33483%3,061（57%）🔴 不该显示
etymology 词源故事3,52559%607（17%）🔴 多数字重复

为什么 root 类会重复到 83%（这类数字可信，与结构性判据同向）
root 的 rationale 写的就是「怎么拆」—— apostol(使徒)+ic(…的) → 使徒的， 而 ① 词根词缀段显示的正是这个拆分 → 复述。
⚠️ 但同一个数字在另外两类上会骗人
· cognate 重合 44% 看似「一半重复」——实际是巧合： 它的 rationale 讲「与 blood / I, me, my 同源」， 而卡上 cognate 段只有族标签、内容为 0（98%）。 重合来自「词形相似」，不是「内容重复」→ 低重合 / 中重合都推不出结论。
· context 重合 33%（次低）——不是因为它藏着新线索， 而是因为它讲的东西根本不属于这张卡（31% 是搭配策略、25% 是联想、37% 杂项）。 → 🔑 「重合率低」有两种相反解释，数字分不出来（§1.7 给出实证）。

结论：重合率只能当「排除法」（高 → 确定不显示），不能当排序依据。

🔑 为什么 P0 是「有效性最低」的 image，而不是 priority 最高的 root？
因为要看的是「这条线索有没有给到」，不是「这条法在绝对意义上强不强」：
· root 的法最强，但它已经在 ① 段里给了 → 再显示一遍是复述

Q-scope · 是否要把 context 类里「内容其实是联想/搭配」的那些捞回来？
实测 context 的 1,410 条 rationale：31% 讲搭配、25% 讲联想、3% 同源、3% 形近、 4% 专名背景、37% 以上都不像。
· 选 ①（推荐）先不碰：context 类整体搁置，等分类修好再说 —— 规则简单、不会误伤
· 选 ② 按内容捞：rationale 含「联想/想象」或「搭配/连用」的显示（≈790 词）—— 能多覆盖有效内容，但规则变成「猜」，且会显示 37% 那批性质不明的东西的风险
· 选 ③ 修数据：给 rationale 补一个「内容类型」字段（要重跑一遍 LLM 分类，有成本）

1.5 两个待定的细节（只对做法甲适用）

若采纳 §1.8 的做法乙，Q-note-1 就不存在（rationale 直接占据槽位，无所谓「贴哪」）。 下面两条只影响走做法甲的那一类（即 cognate）。

Q-note-1 · 贴在哪里？
① 贴最上面那条记忆法段之下（样张里的做法）—— 语义最近（「为什么用这条线索」）； 但若 ② 词源段在它上面，说明词源的联想会贴在词源下面，略有错位
② 统一贴记忆法组末尾（①② 之后）—— 位置固定，但与上面两段离得有点远
对 cognate 类：它的归属段是 cognate（不上卡）→ 只能贴到现有 ① 或 ② 之下，建议贴 ②（同属「词的来龙去脉」）。
Q-note-2 · 加不加标签前缀？
做法甲的样张里加了 联想图像 / 记忆法 的小字前缀。 锚点原文没有这个前缀（就是一句小字 + 虚线）。
· 加 → 明确「这行讲的是哪种记忆法」—— 对 cognate 类有用（否则看不出那句是在讲同源）
· 不加 → 更像锚点、更轻
做法乙不需要这个决定（槽位标签本身就是类型名）。

🔑 所有样张里的字段（音标 / 释义 / 例句 / 词源链 / 分拆法 / 段入口 / rationale） 都逐条取自真库，未做美化 —— 包括「该段有没有 entry」这类看不到但决定界面的细节 （上一稿就因为「没核实就写」把 pos 画错，这次逐项核对过）。
