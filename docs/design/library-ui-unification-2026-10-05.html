方案与信息流统一与「我的」页统一语义贴合滑动删除风险

🔑 三处改动其实是同一条规则： spec §〇 规则 1 ——「内容平面 / 交互粘土；有体积的只可能是可点的东西」。 ① 是「落点」问题（同位置同职责 → 同落点）； ② 是「可点却没体积」（该有粘土的没有）； ③ 是「内容却做成了平面行」（该是卡片的做成了表格）。
