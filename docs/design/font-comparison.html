⚠️ IPA 音标字体（必须单独选一款）

实测发现：上面的阅读字体都不能显示 IPA 音标。
以 Literata 为例——完整字体（非子集）只有 3/96 个 IPA 扩展字符，缺失 ɪ ʊ ʃ ʒ ː ʌ ɔ ɜ ɒ ɹ ɛ。 而我们的词卡里有 90.2%（11,585 / 12,839 张）的音标用到这些字符，其中 ɪ 出现 9,892 次、 ː 4,340 次。

后果：若只用一款阅读字体，90% 的词卡音标会回退到系统字体，出现字体混排、大小不一。

解决：阅读正文用 Literata，音标另配一款覆盖完整 IPA 的字体。下面是候选——都实测过我们语料里的全部 32 个 IPA 字符。

判断建议

  • 看耐力：连续读三段，哪一款眼睛最不需要"使劲"。
  • 看辨识度：注意 l I 1、rn vs m、a 的字形差异 —— 学习场景里辨错字母的代价比母语读者高。
  • 看混排：词卡是「英文释义 + 中文释义」混排，中英两种字体的视觉重量要匹配。
  • 看深色模式：切到深色再看一遍。衬线字体在深色背景上的表现差异很大，晚间阅读是高频场景。
  • 看小字号：把字号拖到 15px 再看 —— 用户在通勤、光线差的环境会用小字号。
  • 注意：不同字体的视觉大小不同（x-height 差异），同样 18px 有的看起来大有的小。这是真实差异，不是错觉。
  • IPA 部分：重点看 ʊ ʃ ʒ ʌ ɒ 这几个 —— 有的字体里它们和基础字母视觉重量不协调。另外 Literata 那栏是反例（会回退成系统字体，明显不一致）。
