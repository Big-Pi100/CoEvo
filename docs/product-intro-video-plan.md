## 一、项目背景

### 产品定位
**一句话**：AI 对话中自动发现值得记住的概念，用户确认即制卡，按 FSRS 记忆曲线复习，通过客观验证完成内化。

**Slogan**：如果不想被 AI 取代，你需要刻意进化。

### 核心流程
```
AI 对话学习任何东西
 → 对话后系统自动提取候选概念
 → 用户勾选确认 / 对话中说"把XX制成卡片"
 → FSRS 记忆曲线在最佳时间弹出复习
 → 翻牌回忆 + 客观验证（打字 / AI 快问快答）
 → 日积月累，刻意记住 → 真正进化
```

### 差异化优势

| 维度 | ChatGPT | Anki | CoEvo |
|:--|:--:|:--:|:--:|
| AI 对话 | ✅ | ❌ | ✅ |
| 自动提取概念 | ❌ | ❌ | ✅ |
| 用户确认制卡 | ❌ | ❌ | ✅ |

## 四、技术实现方案

### 方式 A：Remotion 代码生成（推荐 ✅）

基于 Remotion 框架，用 React + TypeScript 代码生成视频。

**优势**：
- ✅ 纯代码驱动，可版本管理（Git）
- ✅ 数据驱动——数据变化可自动更新视频
- ✅ 精确到帧级的控制
- ✅ 可复用组件，下次改文案就能快速生成新版本
- ✅ 支持多尺寸输出（16:9 + 9:16）
- ✅ 无版权风险（自生成画面）

**实现路径**：
```
1. 环境搭建（Node.js + Remotion + FFmpeg）
2. 按场景拆分 React 组件
3. 每个场景包含：文字动画 + 渐变/粒子背景 + 时间轴
4. 集成 Lucide 图标做视觉辅助
5. 选择合适的 BGM（免费商用音乐）
6. 渲染输出 MP4（H.264）
```

**预估渲染时间**：60 秒视频约需 5-15 分钟（取决于电脑配置和复杂度）
