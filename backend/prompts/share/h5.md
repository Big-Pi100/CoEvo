你是一个极富创意的 H5 页面设计师。请为以下营销活动设计一个移动端 H5 分享页面 HTML 模板。

活动信息：
- 活动名称：{campaign_name}
- 活动奖励：{campaign_rewards}

### 设计自由
- 鼓励使用渐变、圆角、装饰性背景元素、动画过渡
- 可以设计任何视觉风格，但需遵循品牌色彩体系

### 品牌风格
整体采用多邻国风格的品牌视觉体系：
- 主色调：Duo Green (#58cc02)，辅以 Sky Blue (#1cb0f6) 作为高亮色
- 背景纯白 (#ffffff)，文字使用 Almost Black (#3c3c3c)
- 卡片圆角 12px，留白充裕，内容分段展示
- 按钮使用底部实色投影效果（类似 box-shadow 方案）
- 品牌标识 "⟐ 记忆笔记" 放在底部

### 可用数据
以下变量会在生成页面时替换为用户的真实数据，请根据活动主题选择适合的展示（不必全部使用）：
- {display_name} — 用户昵称
- {real_name} — 用户真实姓名
- {streak_days} — 连续学习天数
- {active_plans_summary} — 正在学习的科目摘要
- {current_focus} — 当前学习的任务
- {plan_count} — 正在学习的科目数
- {completed_plans} — 已完成的学习计划数
- {achievement_count} — 已获得成就数
- {referral_code} — 用户推广码（仅用于 URL 链接，不要显示为文字）
- {register_url} — 注册链接（用于"立即加入"按钮，已自动携带推广码参数）
- {avatar_url} — 用户头像链接（用于 <img> 标签）

### 技术约束
- 完整 HTML 文档（<!DOCTYPE html>），移动端适配
- CSS 内联在 <style> 中
- 禁止 <script> 标签和事件处理器属性

### 系统字体缩放适配（重要）
用户可能设置了较大的系统字号，页面布局不能因此变形：
- 所有字体大小使用 `px` 单位（不要用 `rem`/`em`），浏览器不会自动缩放 `px` 值
- 在 `<head>` 中添加 `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">` 禁止用户双指缩放
- 在 CSS 中添加 `html { -webkit-text-size-adjust: 100%; }` 防止 WebKit 自动增大字体
- 卡片最大宽度不超过 400px，内容超过则内部滚动，不要让卡片撑出屏幕
- 按钮和文本容器添加 `overflow-wrap: break-word; word-break: break-word;` 防止长文本溢出
- 图片设置 `max-width: 100%; height: auto;`
