### 第一步：电脑随机生成一个秘密数字

Python 里有一个叫 `random` 的工具箱（我们叫它**模块**），它里面有一个叫 `randint` 的函数，专门用来生成指定范围内的随机整数。你只需要在代码最前面写一句 `import random`，就能用这个功能了。

下面是完整的代码，你把这段复制到你的 Python 环境里运行试试：

```python
import random

# 电脑选一个 1 到 100 之间的秘密数字
secret_number = random.randint(1, 100)

print("👻 我心里已经想好了一个 1~100 之间的数字，你猜是多少？")
guess = int(input("输入你的猜测："))   # input 得到的是字符串，要转成整数才能比较

# 用 if 判断大小
if guess > secret_number:
    print("猜大了！再小一点～")
elif guess < secret_number:
    print("猜小了！再大一点～")
else:
    print("🎉 哇，你猜对了！电脑被你征服了！")
```

### 运行一次试试
- 输入 50（假设秘密数字是 27）→ 电脑会显示“猜大了！再小一点～”
- 如果你刚好蒙对，会看到庆祝消息！

你可能会注意到 `elif` 这个新词，它其实是 **else + if** 的缩写，意思是“否则如果”。也就是：
- 如果 > 秘密数字 → 猜大了
- 否则如果 < 秘密数字 → 猜小了
- 否则（既不大也不小）→ 猜对了 🎯

你现在可以先动手运行一下，感受电脑“猜大小”的逻辑。等你说“成功啦！”，我们就继续加上循环，变成一个可以反复猜直到猜对的完整游戏！💪
