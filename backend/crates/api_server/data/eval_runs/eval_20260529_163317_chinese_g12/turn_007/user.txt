（拍手，跟着老师一字一拍）

**我爱——我们的——祖国——**（拍三下，双手举高）  
**我爱——祖国的——土地——**（拍三下，手指下方）  
**我爱——祖国的——山河——**（拍三下，双手画波浪）  
**我爱——祖国的人民——**（拍三下，双手贴胸口）  
**我爱——祖国的花朵——**（拍三下，双手托腮）  
**我们——爱——祖国——**（拍三下，双手比心）  
**祖国——爱——我们——**（拍三下，双手指向自己）  
**我们——和——祖国——**（拍三下，手拉手左右摇）  
**永远——不分——开——**（拍三下，双手交叉抱紧）

**老师，我跟着拍了两遍！**  
“土地”就是脚踩的大地，“山河”是山和河，“人民”是所有人，“花朵”是小朋友，对吗？  
**我们爱祖国，祖国也爱我们，所以永远不分开！** 我记住了！✨
