**① 唱读**  
我是小学生——天天起得早——  
背着书包上学去——见人问声好——  
我是小学生——学习本领强——  
写字画画做算术——快乐又健康——

（拍手三下，笑）  
再来一遍：  
我是小学生——（啪）天天起得早——（啪）  
背着书包上学去——（啪）见人问声好——（啪）  
我是小学生——（啪）学习本领强——（啪）  
写字画画做算术——（啪）快乐又健康——（啪）

**② 理解**  
“天天起得早”——就像你早上会自己穿好衣服，不用妈妈叫。  
“见人问声好”——像你对老师大声说“老师好”，对同学说“早上好”。  
“学习本领强”——写字要工工整整，画画要颜色漂亮，做算术要算得对。  
“快乐又健康”——上学很欢乐，身体也要多运动，不挑食。
