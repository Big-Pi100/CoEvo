**① 唱读**  
跟我拍手读：  
我是中国人——（啪）  
我爱中国——（啪）  
我爱长江——我爱黄河——（啪啪）  
我爱长城——我爱黄山——（啪啪）  
我是中国人——我爱中国——（啪啪）  
我爱国旗——我爱国歌——（啪啪）  
我爱国徽——我爱北京——（啪啪）  
我是中国人——我爱中国——（啪啪）

**② 理解**  
“我是中国人”——黑眼睛、黄皮肤，我们就是中国人。  
“我爱长江，我爱黄河”——长江、黄河像两条长龙，是中国的大河。  
“我爱长城，我爱黄山”——长城盘在山顶，黄山有奇石和云海。  
“我爱国旗，我爱国歌”——五星红旗，奏响国歌。  
“我爱国徽，我爱北京”——国徽上有星星和天安门，北京是我们的首都。

**③ 输出**  
现在，你跟着老师念一遍：  
“我是中国人——”（你接下去）  
“我爱中国——”  
“我爱长江——我爱黄河——”  
……（一直念完）
