**（跟着老师拍手，一字一拍，声音清脆）**  
春——天——发——芽——（拍四下，手指轻轻向上顶，像小草钻出来）  
夏——天——开——花——（拍四下，双手在脸旁张开，像花开）  
秋——天——结——果——（拍四下，双手做摘果子动作，放到嘴边假装咬一口）  
冬——天——飘——雪——（拍四下，手指轻轻向下落，像雪花飘）  

**（接着做四季动作，身体也跟着动）**  
春天摸嫩芽——（蹲下，手指轻轻碰地面，再站起来）  
夏天扇扇子——（右手在脸旁扇风，左手叉腰）  
秋天摘果子——（踮脚，右手向上摘，放进左手“篮子”）  
冬天搓搓手——（两手来回搓，嘴巴呼口白气）  

**（读完，笑嘻嘻地看着老师）**  
老师，我读完啦！春天的小草是偷偷钻出来的，夏天扇扇子凉凉的，秋天果子甜甜的，冬天搓手暖和和的！我全都记住啦！
