**（站得直直的，先深吸一口气，然后拍着手边背边做动作）**  

**我——是——小——学——生——**（拍五下，指自己）  
**天——天——起——得——早——**（拍五下，伸懒腰）  
**背——着——书——包——上——学——去——**（拍七下，做背书包走路）  
**见——人——问——声——好——**（拍五下，挥手鞠躬）  

**我——是——小——学——生——**（拍五下，拍拍胸脯）  
**学——习——本——领——强——**（拍五下，指脑袋）  
**写——字——画——画——做——算——术——**（拍七下，比划写字、画画、算数）  
**快——乐——又——健——康——**（拍五下，双手比心，再拍拍肚子）

**（背完，笑嘻嘻地看着老师）**  
老师，我背完啦！全对没有？
