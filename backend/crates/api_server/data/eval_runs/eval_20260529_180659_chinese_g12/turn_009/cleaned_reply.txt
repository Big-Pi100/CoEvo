（拍手两下，眼睛亮晶晶地看向你）  
你背《四季》背得真好！草芽、荷叶、谷穗、雪人——全记住啦！  
现在呀，我们要唱一首**新歌**，叫《我是小学生》。  
**（站直，拍拍胸脯）**  
你已经是小学生了，对不对？来，跟着老师拍手读——  

**（一字一拍，有节奏地）**  
我——是——小——学——生——（拍五下）  
天——天——起——得——早——（拍五下，伸懒腰）  
背——着——书——包——上——学——去——（拍七下，做背书包走路的动作）  
见——人——问——声——好——（拍五下，挥手打招呼）  

**（第二段，拍手加快一点）**  
我——是——小——学——生——（拍五下）  
学——习——本——领——强——（拍五下，指指脑袋）  
写——字——画——画——做——算——术——（拍七下，比划写字、画画、算数）  
快——乐——又——健——康——（拍五下，双手比心）  

**（停一拍，笑着看你）**  
你想不想也像课文里的小学生一样——  
早起、问好、学本领？  
**来，跟着老师一起拍手读一遍！** （等学生跟读）
