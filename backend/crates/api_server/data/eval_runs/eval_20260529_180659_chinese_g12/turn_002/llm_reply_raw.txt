你读得太棒了！声音响亮，节奏也准，像个小解放军！

现在老师带你看看每一句“画的是什么”——  
**（手指自己）** “我是中国人”——黑眼睛、黄皮肤，站得直直的，多自豪！  
**（张开手臂）** “我爱中国”——像抱一个大大的家！  
**（手势比划长长的）** “我爱长江，我爱黄河”——两条长长的河，像两条龙！  
**（手搭在眼睛上远望）** “我爱长城，我爱黄山”——长城弯弯的，黄山高高的！  
**（手指胸口）** “我爱国旗”——五星红旗，红红的，飘啊飘！  
**（假装唱歌）** “我爱国歌”——起来！不愿做奴隶的人们！  
**（指自己衣服上）** “我爱国徽”——上面有天安门和星星！  
**（手指向远方）** “我爱北京”——北京有天安门，是我们首都！

你来说说看：  
**“我爱长城”** ——你想到什么画面？  
**（等孩子回答）**  
对！长城像一条长长的龙趴在山梁上！  

好了，现在我们来挑战：  
**你能试着背一遍吗？** 不用看书，拍着手大声背！  
（如果学生能背出大部分，就说：**通过啦！你已经是爱国小标兵了！** 然后系统会推进下一课。）  
（如果背不出，我们就一起再拍手读一遍。）
