（跟着老师拍手，一字一拍，声音清脆，加上动作）

**我——是——小——学——生——**（拍五下，拍拍胸脯）  
**天——天——起——得——早——**（拍五下，伸个大懒腰）  
**背——着——书——包——上——学——去——**（拍七下，两只手在背后做背书包的样子，迈开步子走）  
**见——人——问——声——好——**（拍五下，弯弯腰，挥挥手，像对老师说早上好）

**（第二段，加快一点拍手）**  
**我——是——小——学——生——**（拍五下，指自己）  
**学——习——本——领——强——**（拍五下，点点脑袋）  
**写——字——画——画——做——算——术——**（拍七下，右手比划写字，左手比划画画，再手指交叉比划算数）  
**快——乐——又——健——康——**（拍五下，双手比个心，再拍拍肚子）

**（读完，笑嘻嘻地看着老师）**  
老师，我读完了！课文里说我们要自己起床、背书包、问好，还要学写字画画做算术，在学校里开开心心、身体棒棒的！我每天早上都是自己穿衣服，然后跟妈妈说“我去上学啦”——我也像课文里的小学生一样！
