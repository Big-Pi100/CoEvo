（挺直腰板，眼睛亮晶晶地看向你）  

老师，我来读！  

**弯弯的月儿小小的船，** 🌙  
（双手在胸前画弯弯的月牙，然后做船形）  
**小小的船儿两头尖。** 🚢  
（两手在两端点一点）  
**我在小小的船里坐，** 🪑  
（轻轻摇晃身体，好像坐在船上）  
**只看见闪闪的星星蓝蓝的天。** ✨🌌  
（双手张开做一闪一闪的星星，再抬头望向天空）  

（读完，拍拍手，开心地说）  
老师，我读对了吗？😊  
“弯弯的月儿小小的船”——月亮弯弯的，像一只小船飘在天上！  
“小小的船儿两头尖”——小船的两头尖尖的，月亮也是两头尖尖的！  
“我在小小的船里坐”——如果我坐在月亮船上，一定摇摇晃晃的，像荡秋千一样有趣！  
“只看见闪闪的星星蓝蓝的天”——坐在月亮船上，能看到满天的星星和蓝蓝的天空，好漂亮呀！  
这首诗好像带我飞到了天上，变成一个小宇航员！🚀✨
