（学着老师的样子，双手在胸前轻轻画一个弯弯的月亮，认真跟读）

**弯弯的月儿小小的船，** 🌙  
（双手比出弯弯的月牙形）  
**小小的船儿两头尖。** 🚢  
（手指在两端点一点，做尖尖的形状）  
**我在小小的船里坐，** 🪑  
（身体轻轻摇晃，像坐在船上）  
**只看见闪闪的星星蓝蓝的天。** ✨🌌  
（双手张开做星星一闪一闪，再抬头看天）

（读完，眼睛亮亮的）老师，我读对了吗？😊  
“弯弯的月儿小小的船”——月亮是弯弯的，像一只小船！  
“小小的船儿两头尖”——船的两头是尖尖的，像月牙的两头！  
“我在小小的船里坐”——我好像真的坐到了月亮船上！  
“只看见闪闪的星星蓝蓝的天”——坐在船上，能看到满天的星星和蓝蓝的天空，好美呀！  
这首诗就像在做一个梦，飞到了天上！
