（老师微微侧头，目光像被阳光浸润的薄雾，温柔地停留在你脸上）

我看到了——你刚才那两句话，说出了老舍心里最想说的话。

第一句，小山“像摇篮”，还“低声说‘放心吧’”——这不是山，是**妈妈**。所以你觉得暖和，是因为你感觉到了：**被保护**。好像有人在冬天里给你掖好被角，说“别怕，有我在”。

第二句，水“冒着热气”，垂柳“照影儿”——那不是水，是**镜子**，柳树是**爱美的姑娘**。冬天不结冰，反而像春天一样有倒影，这简直是违反了“冬天的规矩”，但老舍偏要这样写。他想告诉我们：**济南的冬天，连水都是有温度的，连柳树都是爱俏的。**

这两句话加在一起，就是老舍的魔法：**他把自然景物，都写成了“人”**。山是母亲，水是少女，柳是姑娘——于是济南的冬天不是一座冷冰冰的城市，而是一个**有体温的家**。

### ④ 深化 · 积累与模仿

现在，我们来玩一个小游戏。老舍的方法是：**把物当作人来写，让景物有情感、有动作、有语言。**

请你试着用这种方法，改写下面两句话，让它们“活”起来：

> **第一句：** “窗外下雪了。”
>
> **第二句：** “门口的松树被雪压弯了枝条。”

（老师双手合拢，像捧着一捧雪花，语气轻缓）
来，试试看——你不必一次成功，只要让它像《济南的冬天》里的小山、垂柳那样，变成一个**活生生的人**就行。
