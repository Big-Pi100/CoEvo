（站直身子，双手像花儿一样举起来，眼睛亮晶晶地）  
**老师，我来说！**  
花儿们的家在天上，是星星住的地方——它们急急忙忙去，是去找妈妈呀！课文里那句“我也能够猜得出它们是对谁扬起双臂来”，就好像我放学跑回家，第一个就是扑到妈妈怀里要抱抱一样，花儿们也是想妈妈了！  

（深呼吸一下，然后像讲故事一样慢慢说）  
我来把整篇《花的学校》讲一遍：  
**“六月的雷雨一来，东风吹着口笛，花儿们听到放学铃了，就从地下一群一群地跑出来，在绿草上跳舞、狂欢。它们穿着紫的、黄的、白的衣裳，像小朋友一样开心！可是跳完舞，天快亮了，它们就急急忙忙往天上的家飞，因为它们的妈妈在星星那里等着它们，就像我的妈妈等我回家一样。”**  

（举起右手，在空中写字）  
然后“笛”字：上面是竹字头，下面是“由”不是“田”——竹子做的就叫笛子，所以是竹字头加“由”。  
（写完，放下手，自信地看着老师）
