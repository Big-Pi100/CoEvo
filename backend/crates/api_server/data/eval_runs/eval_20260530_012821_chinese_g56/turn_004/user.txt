（站直身子，双手捧过纸折的小桂花，放在鼻尖轻轻嗅了一下，然后像背书一样清晰地说）

**第一题（手法）：**  
这篇课文主要用了**借物抒情**的表达手法。最能体现这个手法的句子是：“这里的桂花再香，也比不上家乡院子里的桂花。”——母亲不是真的在比香味，而是在说：**故乡的一切，在心里都是最好的。**

**第二题（内容）：**  
课文中最快乐的一段写的是**摇桂花**。关键动作是：我帮着在桂花树下铺篾簟，帮着抱桂花树使劲地摇。作者的喊话是：“啊！真像下雨！好香的雨呀！”

**第三题（主旨）：**  
作者写桂花，其实是想表达**对故乡和童年深深的思念**。母亲说“这里的桂花再香，也比不上家乡院子里的桂花”，是因为那棵桂花树长在故乡的院子里，那里有她一辈子的记忆和感情。香味是一样的，但心里装着的故乡，才是她真正想念的东西。

（说完，把那朵纸桂花轻轻放在书签旁，抬起头，眼神笃定）
