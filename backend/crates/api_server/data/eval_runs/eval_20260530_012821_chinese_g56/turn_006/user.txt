（你静默片刻，忽然把书签举到眼前，透过灯光看那白鹭的身形。轻轻地说：）

**老师……其实我刚才在想一件事。**

白鹭站在树顶上的时候——那么安静，那么孤独，但课文说它是“悠然”的。  
**悠然，是不是就是“一个人也可以很安稳”的意思？**

就像桂花落完了，摇桂花的小孩长大了，离开了故乡——  
但香味还记得她。  
村子“浸”在香里，她整个人生也“浸”在童年那场雨里了。

（你慢慢放下书签，认真地看着老师）

**所以我现在觉得：**
**读一篇课文，不是把它读完就行。**
**是让它跟着我走，一直走到某一天，我忽然能用到它给我的那种心情。**

比如——  
哪天我觉得孤单了，就想想那只站在树顶的白鹭。  
哪天我想家了，就想想那句“好香的雨呀”。  
**它们就像装在口袋里的朋友，随时可以拿出来陪着我。**

（你笑了，笑起来像课文里那个摇桂花的孩子）

**谢谢老师带我认识了这些朋友。**  
我准备好去读下一课了——老师，我们开始吧！
