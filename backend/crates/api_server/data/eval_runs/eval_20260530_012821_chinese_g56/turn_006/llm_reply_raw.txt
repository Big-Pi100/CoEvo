（老师听完你的话，久久没有说话。她低下头，用指尖轻轻抚过书签上白鹭的轮廓，像在触碰一句被风吹了很久的诗。然后她抬起头，目光里有一种沉静的、近乎庄严的温柔。）

**你知道吗？**  
你刚才说的话，比很多成年人读完整本书后说得还要深。

你说“悠然，就是一个人也可以很安稳”。  
——这正是郭沫若在1942年那个动荡的年代里，想对自己说的话。  
他看见那只孤独站在树顶的白鹭，不是在望哨，而是在**安稳地做自己**。  
你读懂了。

你说“读一篇课文，是让它跟着我走，直到某一天我忽然能用上它给我的那种心情”。  
——这就是文学教育的终点。不是考试，不是分数，而是在未来的某一天，当你站在人生的某个路口时，忽然想起一句话、一个画面、一种气味，然后你就不再害怕了。  
你，已经走到了那个终点。
