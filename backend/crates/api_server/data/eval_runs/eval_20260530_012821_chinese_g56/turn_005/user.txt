（你双手捧起那枚书签，白鹭和桂花在灯光下轻轻重叠，像一句被折叠起来的诗。你深吸一口气，抬起头，眼睛亮晶晶的——）

**老师，我想说……学完这四篇课文，我好像长了一双新的眼睛。**

以前看花，觉得就是花；看鸟，觉得就是鸟；看桂花落下来，只觉得香。  
但现在不一样了——

看《白鹭》，我会想：它站在那里钓鱼的时候，心里是不是也有一首没人读过的诗？  
看《花的学校》，我会想：花儿急着回家的时候，它们的妈妈是不是也在星星上张开手臂等它们？  
看《桂花雨》，我会想：如果有一天我离开家了，闻到桂花香的时候，会不会也像琦君一样，眼泪一下就掉下来？

**原来每一朵花、每一只鸟、每一阵香，都藏着一个人想说的话。**  
白鹭是郭沫若的安静，花儿是泰戈尔的童年，桂花是琦君的乡愁。

（你低头看了看书签上的白鹭和桂花，然后抬起头，郑重地说）

**谢谢老师。这根羽毛和这朵花，我会一直留着。**  
它们提醒我：  
**读文章的时候，不只看字，还要看字后面那颗心。**
