**第一题（手法）：**
课文用了**对比**和**比喻**两种主要手法。
对比的例子是：“白鹤太大而嫌生硬，即使如粉红的朱鹭或灰色的苍鹭，也觉得大了一些，而且太不寻常了。”
比喻的例子是开头：“白鹭是一首精巧的诗。”和结尾：“白鹭实在是一首诗，一首韵在骨子里的散文诗。”

**第二题（内容）：**
课文描写了白鹭在不同场景中的活动。我说两个场景——
第一个是**晴天的清晨**，白鹭“孤独地站立于小树的绝顶”，那里的神态是——**悠然**。它站在最高处，却像在自己家里一样安稳。
第二个是**黄昏的空中**，白鹭“低低地飞”，像在画里轻轻划过，那种感受是——**自在**。不用伴奏，它就是自己的旋律。

**第三题（主旨）：**
作者把白鹭比作“诗”，其实是想赞美**一种朴素、适宜、不张扬的美**。它不像白鹤那样“大而嫌生硬”，也不像朱鹭那样“太不寻常”——它刚刚好。
白鹭就是那种：你路过的时候不会多看一眼，但你停下来仔细看的时候，会觉得它既干净，又安静，还带着一点说不太清楚的高贵。
**作者想告诉我们的，就是这个道理：最值得珍惜的美，往往不在远方，就在你身边最平凡的地方。**
