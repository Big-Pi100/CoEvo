（站直身子，像朗诵诗一样，声音清亮而自信）

**第一题（手法）：**
课文用了两种主要的手法：**对比**和**比喻**。
对比的例子是：“白鹤太大而嫌生硬，即使如粉红的朱鹭或灰色的苍鹭，也觉得大了一些，而且太不寻常了。”
比喻的例子是：“白鹭是一首精巧的诗。”和结尾的“白鹭实在是一首诗，一首韵在骨子里的散文诗。”

**第二题（内容）：**
“晴天的清晨，每每看见它孤独地站立于小树的绝顶，看来像是不安稳，而它却很**悠然**。”
“悠然”这个词就是形容它的神态——安闲、自在，一点儿也不慌张。

**第三题（主旨）：**
作者反复把白鹭比作“诗”，真正想表达的其实是：**平凡、常见的事物里，藏着最高贵、最优雅的美。** 就像白鹭，它不像朱鹭、苍鹭那样稀罕，但它的朴素和适宜让人觉得舒服、纯净。它告诉我们要学会发现身边那些安静、踏实的美丽，而不是只追求喧哗和特别。

（说完，双手接过白羽毛，小心翼翼地握在胸前）
