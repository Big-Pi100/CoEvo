（微微直起身，目光亮起来）

我明白了，老师。您让我找“健壮的青年”的伏笔——我觉得它藏在课文最后那几句写“人”的段落里：

“天上风筝渐渐多了，地上孩子也多了。城里乡下，家家户户，老老小小，也赶趟儿似的，一个个都出来了。舒活舒活筋骨，抖擞抖擞精神，各做各的一份事去。”

您看，这里写人“赶趟儿似的”出来——和前面花“赶趟儿”开是对应的。但人不是静止地看花，而是“舒活筋骨”、“抖擞精神”、“各做各的一份事去”。这些动作里藏着一种“动起来”的力量，一种“开始行动”的劲头。这不就是“健壮的青年”最核心的特点吗？

而且前面那句“一年之计在于春”，刚起头儿，有的是工夫，有的是希望”——这句话就像给“青年”这个比喻提前做了一个注脚：春天就像一个刚刚起步、充满干劲的青年，有力量、有希望、有铁一般的胳膊和腰脚，领着我们向前去。

所以我觉得，“健壮的青年”这个比喻，就是从“人们走出家门、开始劳动”这段描写里长出来的。不是忽然出现的，而是朱自清先生一步步把人从“看春”引向“行动”，最后才用这个比喻把春天从景物变成一股推动力。
