（我低头想了想，手指轻轻在课本上划过，然后抬起头来）

老师，我觉得老舍先生的语言，有一种“拉家常”的气味。

朱自清写春天，语言很精致、很密，像画工笔画——每一笔都细细地点上去，颜色要调得正，线条要描得准；读的时候，你会觉得他是在“端详”春天、在“打磨”文句。

但老舍不一样。他写“济南真得算个宝地”，“真得”两个字，就像他坐在你对面，端着茶杯，探过身子来，很认真地对你说：“我跟你讲，这儿真的好。”不是那种站在讲台上宣布，而是朋友之间的“安利”。

还有那句：“这一圈小山在冬天特别可爱，好像是把济南放在一个小摇篮里。”——他不是先说山怎么怎么好看，而是先造了一个“小摇篮”的画面，让你自己先想象那个安安静静、暖和和的氛围，然后再说“它们安静不动地低声地说：‘你们放心吧，这儿准保暖和。’”这里的“放心”、“准保”，都是平时家里长辈说话的口气。不是书面的，是口语的；不是冷的，是热的。

所以我觉得，老舍的语言气味是 **“暖烘烘的、带着北方话那种干脆和实在”** 。他不追求朱自清那种“每一个字都是精心挑选”的精致感，而是追求一种“我把我看到的、感受到的，像讲故事一样讲给你听”的亲切感。这种语言，让人读着读着，就像自己也坐在济南的阳光下，被一圈小山抱住了。
