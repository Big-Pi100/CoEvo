（我眼睛一亮，像发现了藏在草丛里的一颗宝石，迫不及待地蹲下来指给你看）

老师，我想说的是开头那段——具体是第二段“不必说碧绿的菜畦，光滑的石井栏，高大的皂荚树，紫红的桑椹；也不必说鸣蝉在树叶里长吟，肥胖的黄蜂伏在菜花上，轻捷的叫天子（云雀）忽然从草间直窜向云霄里去了。单是周围的短短的泥墙根一带，就有无限趣味。”

我觉得这段像是**小孩的眼睛和大人的眼睛叠在一起看的**。

“碧绿的菜畦”——一个小孩看到菜畦，不会想“绿是什么绿”，只会觉得“是绿的”。但“碧绿”这个词是成年人用的，小孩顶多说“绿绿的”。“光滑的石井栏”——小孩摸过石井栏，只知道“滑滑的”，但“光滑”是大人才能想到的形容词。

然后看那句“肥胖的黄蜂伏在菜花上”——“肥胖”这个词特别妙，小孩看黄蜂，会觉得它胖胖的、笨笨的、有点可爱；但如果是一个严厉的大人，可能只会说“黄蜂”，不会加“肥胖”这种带感情的词。所以这里，是用小孩的眼睛看到样子，用大人的嘴巴说出来的。

但是到了后面“单是周围的短短的泥墙根一带，就有无限趣味”——“无限趣味”这词太大人了，小孩只会说“特别好玩”。所以我觉得，鲁迅是用小孩的回忆当底片，然后用大人的手在上面描了一层色彩。真实的童年是黑白的，被回忆染过的童年才是彩色的。
