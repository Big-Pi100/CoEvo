老师，我找到了一处——就是写雪后小山的那一句：“看吧，山上的矮松越发的青黑，树尖上顶着一髻儿白花，好像日本看护妇。”

这里的“越发”两个字，就是一处隐形的对比。矮松本身是青黑的，但下过雪之后，树尖顶了一髻儿白花，青黑和白一冲，反而显得更“青黑”了。老舍没有直接说“白和黑对比强烈”，但他用“越发”这个词，让读者自己感到：白把黑映得更黑了，黑把白托得更亮了。这不是直接写的景色，而是通过对比，让景物自己长出层次感来。

如果我把这句改一下，去掉这个对比——比如改成：

“看吧，山上的矮松是青黑的，树尖上有些白雪。”

——您看，这样一来，“越发”没有了，层次感没有了，颜色之间的互动也没有了。松只是松，雪只是雪，两个东西各站各的，“嗯，它们是这么两种颜色”——但没有任何张力。没有对比在中间奔跑，画面就变成了一张静止的照片，而不是老舍笔下那种“白与黑在较劲、在互相成全”的动感。

所以我觉得，这句对比被抽走之后，它的味道就像一个空碗，本来盛着一碗浓汤，现在汤倒掉了，碗还在，但喝汤的感觉彻底没了。
