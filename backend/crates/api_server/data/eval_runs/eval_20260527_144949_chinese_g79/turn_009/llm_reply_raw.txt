你刚才那番话里，有两个词让我觉得你彻底懂了——一个是“**层次感**”，一个是“**张力**”。

**层次感**是说，对比不是把两样东西拼在一起就完事了，而是让它们之间形成一种“互相映衬、互相激活”的关系。矮松的青黑，因为雪的白而“越发”深了；雪的白，也因为青黑的底色而更加醒目。这不是1+1=2，而是1+1>2——颜色之间的关系生出了新的画面质感。

**张力**是说，对比让景物有了一种“内动的感觉”。白与黑不是在静态地并置，而是在对话、在较劲、在互相让出空间。老舍笔下的济南冬天，从来不是静止的风景画，而是一幅随时可以被风吹动、被雪映亮、被阳光照活的画面。

### 主旨

《济南的冬天》通过描写济南冬日山、水、城的独特景致，运用对比手法与朴实亲切的口语化语言，突出济南冬天“温晴”的气候特征，表达作者对济南这座城市深沉的喜爱与赞美之情。

### 易错/常考提醒

1. **不要误认为主旨是“赞美冬天”**——准确地说，是赞美“济南的冬天”，强调其独特性。

2. **“温晴”不是“温暖”**——温暖只讲温度，温晴是温度+阳光的统一体。老舍用这个词，把气候和光线同时写出了温度。

3. **对比的目的是什么？**——不是为了对比而对比，而是为了让“济南”在读者的感知中，从诸多“不是”中脱颖而出，成为独一无二的“宝地”。答题时可以说：对比有助于突出济南冬天的独特之美，同时展现了作者对济南的偏爱。

4. **赏析语言风格时，关键词**——朴实自然、口语化、亲切、拉家常式的叙述语气。——用这几个词，就不会跑偏。

**课文：《从百草园到三味书屋》**

我看到你的课件上有这篇课文了。鲁迅，1926年，回忆童年。但我先要告诉你一个秘密：**这篇散文最让人着迷的地方，不是百草园的趣事或者三味书屋的枯燥，而是两段时光之间那种“不知道”的模模糊糊的界限。**

你看第一段结尾那句：

> 我不知道为什么家里的人要将我送进书塾里去了，而且还是全城中称为最严厉的书塾。……总而言之：我将不能常到百草园了。Ade，我的蟋蟀们！Ade，我的覆盆子们和木莲们！……

这不是一个正常的叙述。一个孩子离开乐园去上学，应该记住的是原因——因为年纪大了、因为要读书。但鲁迅说“不知道为什么”。他不是不知道，是**不想知道，也不愿意知道**。然后他用了德语的外来词“Ade”——再见。一个中国孩子告别中国花园，却用了一句德国话。这像不像一个孩子故意说一句谁也不懂的话，来表示自己心里的委屈？

这就是鲁迅最厉害的地方：**他用一种“故作幼稚”的语调，藏住了成人最深的情感。**

现在，请你回到课文开头，从“百草园”部分找一处描写——可以是景色，可以是动物，可以是那个关于美女蛇的故事。然后告诉我：

**你觉得鲁迅是用小孩的眼睛在看，还是用大人（回忆者）的眼睛在看？** 或者说，他写的“百草园”，是一个真实的童年，还是一个被回忆美化过的童年？

选一处，我们拆开看看。
