（你低头翻看课文，手指顺着字行轻轻划过，然后抬起头）

老师，我找到了一处对比——就在写“山”的那一段。

课文里说：“这一圈小山在冬天特别可爱，好像是把济南放在一个小摇篮里。”然后作家接着说：“它们安静不动地低声地说：‘你们放心吧，这儿准保暖和。’”

您看，这里虽然没有直接说“冬天”和“别的季节”比，但老舍先生特意用了“特别可爱”这个词——“特别”两个字，说明冬天的小山和其他季节的小山不一样。而且，他把山比作“小摇篮”，把济南比作“婴儿”——摇篮是温暖的、安全的，婴儿是被呵护的、被抱住的。这和前面开头说的“温晴”一脉相承：冬天本应该是冷的、刺骨的，但济南的小山却“准保暖和”，像一个母亲抱住了孩子。

还有后面写雪的时候：“就是下小雪吧，济南是受不住大雪的，那些小山太秀气！”——这里又有一个对比：其他地方的冬天可能会下大雪，雪压山、风刮脸；但济南的小山“太秀气”，连大雪都承受不起。作家用“受不住”三个字，反而写出了一种娇嫩、温柔、让人心疼的美感。

所以我觉得，老舍先生的对比手法不只用在开头那三段“反面教材”里，还用在写景的时候：他一直在用“冬天本应如何”来反衬“济南的冬天如何”。这种隐形的对比，反而更让人觉得济南冬天的“温晴”是一种奇迹，是一种被大自然偏爱的特例。
