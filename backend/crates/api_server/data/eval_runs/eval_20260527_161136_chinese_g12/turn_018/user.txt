老师听到你选“水”字宝宝，眼睛都亮了！你说得对，水就像小河一样弯弯曲曲，还会闪闪发光！我们一起来玩“水”字变魔术——

**第一步：看形状**  
你伸出一根手指，在空中画个“水”字：  
（中间一条长弯线，像小河的河床；左边一撇，右边一捺，像溅起的小水花。）  
老师再教你一句口诀：**“小河弯弯流，水花两边开”**，这样你一辈子都不会忘啦！

**第二步：组词找朋友**  
“水”字能跟好多字做朋友呢——  
- **河水**（小河里的水）  
- **开水**（烧热的水）  
- **水果**（苹果、梨子里有水水的果汁）  

你还能给“水”字找两个朋友吗？比如……**“水杯”**？**“水花”**？

**第三步：小挑战**  
老师考考你：  
你知道“水”字在“水果”里和“水杯”里，读音一样吗？  
（你抿嘴笑一想：一样！都是shuǐ！）  
但是“水果”的“水”念得快一点，像小水滴跳起来；“水杯”的“水”可以拉长一点，像满满一杯水慢慢倒。  

**第四步：写一写**  
现在伸出小手，跟着老师一笔一划写“水”：  
（竖钩、横撇、撇、捺）  
**边写边念：**  
一点竖钩像河底，左边撇来右边捺，水花四溅真好玩！  

你学会了吗？如果记住了，明天我们就认识“火”字宝宝——它和水可是好朋友，因为火煮水会变成热水喝呢！🔥
