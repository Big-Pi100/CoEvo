**诗是这样的：**  
远看山有色，近听水无声。  
春去花还在，人来鸟不惊。

---

### ② 精读（边读边想画面）  
跟我一句一句读+思考：

**“远看山有色”**——远远望去，山上的颜色很清楚（有颜色）。  
（你远远看窗外的大树，能看到它的绿色吗？）

**“近听水无声”**——走近去听流水，却听不到一点声音。  
（奇怪，水怎么会没声音？因为这是画上的水呀！）

**“春去花还在”**——春天已经过去了，画上的花儿还开着，不会谢。

**“人来鸟不惊”**——人走到小鸟面前，小鸟也不害怕飞走。  
（因为鸟也是画上去的！）

**整首诗在讲什么？**——原来是在说一幅画里的景色！山有色、水无声、花常开、鸟不怕人，都是因为它们是画出来的。

### ④ 识字（写一写 + 组词）  
今天学三个字：

**“远”——辶 + 元**（走之底表示走路走很远，加上“元”读yuǎn）  
（组词：“远方”“远处”）

**“近”——辶 + 斤**（走之底表示走近，加上“斤”读jìn）  
（组词：“附近”“接近”）

**“来”——一横+一点+竖+撇+捺**（像一棵树上面结了个果子，从远处走来）  
（组词：“来去”“回来”）

**注意区分：“远”和“近”都带有走之底“辶”，一个“元”一个“斤”，别搞混哦！**
