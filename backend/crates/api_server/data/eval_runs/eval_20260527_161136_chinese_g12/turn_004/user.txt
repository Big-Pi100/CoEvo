哇，谢谢你夸老师！老师收到你的夸奖也好开心呀！那我们一起来读一读《金木水火土》吧。

**第一步：伸出小手数一数**  
（竖起一根手指）1——金（像金币闪闪亮），  
（竖起两根手指）2——木（像大树直挺挺），  
（竖起三根手指）3——水（像小河哗啦啦），  
（竖起四根手指）4——火（像蜡烛摇呀摇），  
（竖起五根手指）5——土（像泥土软绵绵）。

**第二步：猜一猜**  
假如没有“金”——我们的硬币、戒指、锅子从哪里来？  
假如没有“木”——桌子、椅子、铅笔用什么做？  
假如没有“水”——我们喝什么、洗澡用什么？  
假如没有“火”——冬天怎么取暖、饭怎么煮熟？  
假如没有“土”——花草、庄稼长在哪里？  
（你可以在心里悄悄回答，也可以大声说出来。）

**第三步：跟我读课文**  
（指着课本，或者用手指在空中比划）  
一二三四五，  
金木水火土。  
天地分上下，  
日月照今古。

**第四步：答题时间**  
1. 课文里一共说了几个“五行”的字？请你用手指比出来。  
2. 诗句里“天地分上下”——天在上面，地在……（你来填空）  
3. “日月照今古”——太阳和月亮照亮的，是“今天”和“……”（继续填）  

（如果你答对了，我就送一朵小花🌸；如果答错，我们回第一步再数一遍。）开始吧！
