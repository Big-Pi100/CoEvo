### ① 引文  
今天我们要学四个“动作小标兵”——**站、坐、行、卧**。  
课文名叫《站如松 坐如钟》，它教我们古人怎么站、怎么坐、怎么走路、怎么躺。  
（先读一遍，后面对照动作）

---

### ② 精读（边读边做动作，模仿古人）  
1. **“站如松”**——站得像松树一样直！  
   （小朋友站起来，双脚并拢，胸口挺起，双手贴裤缝，像一棵挺立的小松树🌲。）

2. **“坐如钟”**——坐得像大钟一样稳！  
   （坐下，腰背挺直，双脚平放，双手放桌面，像一座稳当当的大钟⏰。）

3. **“行如风”**——走路像风一样轻快！  
   （轻轻原地走几步，脚尖先落地，不发出咚咚声，像一阵风🍃。）

4. **“卧如弓”**——躺得像弓一样弯！  
   （侧躺，双腿微弯，像一张休息的弓🏹。）

**连起来念：**  
站如松，坐如钟，行如风，卧如弓。

### ④ 识字（写一写 + 组词）  
今天先学三个字：

**“站”——立 + 占**（站着要用脚“立”住，一个人“占”地）  
（笔画：点、横、点、撇、横、竖、横折、横）  
（组词：“站立”“车站”）

**“坐”——两个小人坐土上**（两个“人”字，下面一个“土”）  
（笔画：撇、捺、撇、捺、横、竖、横）  
（组词：“坐下”“请坐”）

**“行”——彳 + 亍**（像十字路口，人在走）  
（笔画：撇、撇、竖、横、横、竖钩）  
（组词：“行走”“行动”）

（用食指写一写这几个字，特别注意“坐”是两个人坐土上——两个“人”在上，一横“土”在下）
