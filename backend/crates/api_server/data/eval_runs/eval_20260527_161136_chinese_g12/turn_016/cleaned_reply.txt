**日、月、水、火。**  
（睁开眼看看下面的图画想象：）

- **日** 像天上圆圆的太阳，中间有一点（古时候的写法像圆圈加一点）。  
- **月** 像弯弯的月亮，里面有两横。  
- **水** 像流动的小河，中间一条曲线，两边是水花。  
- **火** 像燃烧的火焰，两边向上飘。
