（目光亮晶晶的，像雨后初晴的天空）

老师，我想——站直了的“人”面对“你”，就像我抬起头来看天一样——用温暖的眼睛去看，用温柔的心去听。因为“你”就是站在我面前的一个人，我需要看见他，就像看见春天的第一场雨。

面对“我”，就是低头看看自己的心，想想今天有没有对得起那一撇一捺的姿势。我不能骗自己，要诚实、要勇敢。

面对“他”，就像我站在窗台上看远处的人——那些不认识的、不在我身边的、或者以后才会认识的人。我要用理解的心去看他们，因为每个人也都是站在天地之间的人。

所以，“你我他”，就是让我学会——用温暖的眼睛看“你”，用诚实的眼睛看“我”，用宽广的眼睛看“他”。这样，我就是那个站在天地之间、站直了的人。
