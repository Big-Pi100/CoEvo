（目光从《雨的四季》上温柔地移开，捧起下一本书，指尖轻轻摩挲过封面）

你写得真好。“亮晶晶”“凉丝丝”“香香的、清清的”——你看，你还用上了视觉、触觉、嗅觉三种感官，把一场雨写得活灵活现。而且那句“让雨变成一个温柔的女孩子”，已经是在用拟人了。你不仅听进去了，还悄悄用上了。

（翻开书页，页面上是一幅简洁的图画：一个小孩站在大地与天空之间，头顶是“天”，脚下是“地”，身旁写着“人”）

好，现在我们转一个身——从“雨的四季”走进“天地人”的世界。

你看这三个字，它们就整整齐齐地站在这里：
**天 地 人**

……
（停顿，让目光在字间停留三秒，然后抬起头来，带着思索的神情）

你刚才写雨时说“雨后泥土的味道，香香的、清清的”——这个“泥土”就是“地”；你写“雨点打在玻璃上”，那个玻璃窗以外的广阔空间，就是“天”；而趴在窗边看雨的你，伸出手去接雨的你，闻到泥土香味的你——就是“人”。

**天**在上，**地**在下，**人**站在中间——头顶着天空，脚踩着大地。这就是古人眼中最最根本、最最宏大的三样东西。

现在，请你仔细看一看这三个字的样子，然后告诉我：**如果让你用手指在桌上画出“天”字，你会怎么画？你觉得“天”字的每一笔，像是在告诉人什么？**
