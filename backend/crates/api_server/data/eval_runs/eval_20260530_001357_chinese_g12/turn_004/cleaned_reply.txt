（拍手，两拍一停）  
“我爱——我们的祖国——”（双手画个大圆圈，代表“祖国”）  
跟读：“我爱我们祖国的土地——”（双手向下摊开，像摸大地）  
“我爱我们祖国的山河——”（双手举高，左右摇摆，像山和河）  

（放慢速度，眼神交流）  
来，小手拍起来，跟我读：  
“我爱我们祖国的人民——”（右手放在左胸口）  
“我爱我们祖国的花朵——”（双手托腮，像开花）  

（突然加快节奏）  
“我们爱祖国，祖国爱我们——”（先指自己，再双手张开拥抱）  
“我们和祖国，永远不分开——”（两手交叉握紧，晃一晃）  

（停，等学生跟读一遍）  
好！你刚说的“土地”“山河”都是祖国妈妈送给我们的礼物，对不对？现在你跟着我再念一遍，我要听你大声读！
