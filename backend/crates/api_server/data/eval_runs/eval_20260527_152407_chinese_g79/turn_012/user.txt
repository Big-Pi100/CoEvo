老师，我来回答这三个问题：

1. **手法题**：课文主要运用了**象征**和**克制抒情**两种手法。  
   - **象征**：课文中的“菊花”象征着**生命的坚韧与希望**。母亲生前一直想带史铁生去北海看菊花，而菊花正是在秋天（萧瑟的季节）热烈开放，这与史铁生瘫痪后的绝望命运形成了鲜明对比——菊花在秋风寒霜中依然烂漫开放，象征着即使在最艰难的环境中，人也可以活出生命的色彩。  
   - **克制抒情**：母亲说话的语气非常“淡”，比如“听说北海的花儿都开了，我推着你去走走”，她从不直接表达自己的痛苦和恐惧，反而用平静的日常语气去安慰儿子；而母亲的病情却非常“重”（大口大口吐着鲜血、病入膏肓）。“淡”与“重”的冲突，让情感变得更加深沉，读者读到母亲去世时，会感到一种“蓄满了却没有爆发”的悲痛，这正是克制抒情的力量。

2. **内容题**：母亲两次提议去北海看菊花，第一次史铁生说“我不去！”并猛地把东西摔向墙壁，母亲只好悄悄退出去；第二次母亲再提起时，史铁生答应了，但母亲却因为病重被送进医院，再也没有回来。这段内容的作用是：一方面展现了母亲对史铁生无条件的耐心和爱——即使被他粗暴拒绝，她依然一次次地尝试；另一方面，史铁生的答应成了对母亲最后的回馈，然而母亲却没有等到那一天——这让“看花”这件事变得无比遗憾，也让“子欲养而亲不待”的悲痛刻入读者心中。

3. **主旨题**：“好好儿活”在课文里经历了从**被忽略→被辜负→被领悟**的转变。  
   - 母亲第一次说“好好儿活”时，史铁生正沉浸在自暴自弃中，根本没有听进去。  
   - 母亲第二次说“好好儿活”是在病重时，她的话断了半截，没有说完。  
   - 课文结尾，史铁生带着妹妹去北海看了菊花，终于明白了母亲的意思：“好好儿活”不是“活着就行”，而是**像菊花一样，在生命的秋天里依然选择热烈、深沉、烂漫地开放**——它象征着直面苦难，不再沉溺于自怜，而是用坚韧与希望去回应母亲的嘱托。史铁生最终活成了母亲希望的样子。
