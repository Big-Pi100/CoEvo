（小朋友眨眨眼睛，一边想一边用手指在空中比画）

**“偷偷地”**——让我觉得小草就像我弟弟，他在我写作业时悄悄从门缝里探进头来，怕被我妈妈发现一样，怕怕的、好玩的。所以“偷偷地”是有小动作的、可爱的，不是大张旗鼓的，而是**悄悄冒出来**的。

**“钻出来”**——我觉得是用了“钻”字，就感觉小草是用头、用力地、自己使劲拱出来的。如果是“长出来”，就只是自然而然高了；但“钻”是有力气的，像小笋芽顶开泥土，急急地想看看春天长什么样子。冬天在地下憋了那么久嘛！

（接着掰手指头数）

然后那些动作——“坐着、躺着、打两个滚、踢几脚球、赛几趟跑、捉几回迷藏”——我觉得都是**小朋友在草地上做的事**！因为是打滚、做游戏、跑来跑去的，大人们一般就坐椅子上看书。所以这里写的应该是**我们这群小学生**，像我们下课就在操场上这样玩的。

老师，我这样理解对吗？
