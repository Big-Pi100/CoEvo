（小朋友闭上眼睛，安静了几秒，然后缓缓睁开，嘴角带着笑意）

老师，我躺在那片草地上了——

**后背和手肘贴着草地**——感觉像是妈妈刚晒过的被子，软软的、暖暖的；草尖有点刺刺的，痒痒的，像在轻轻挠我痒痒。我把手张开平放，草叶在我手下微微弹起，好像在跟我玩。

**风从脸上拂过**——不像冬天的风那么凶、像刀子，也不像夏天的风那么黏糊糊。春天的风像妈妈用手背轻轻擦我的脸，温温的、滑滑的，还带了点湿湿的露水气。我觉得它像一支看不见的羽毛，一下下扫过去。

**空气里的味道**——我闻到了青草的味儿，有点像刚割完草时那种清新的带点苦的香；还有泥土的味道，像雨后花园里那种潮潮的、厚实的气息；然后空气中还飘过来一点点淡淡的野花香，像奶奶院子里那棵丁香树的味道，远远地飘过来又飘走了。

（说完，有些不好意思地缩了缩脖子）
老师，我是不是说得太多了？😅
