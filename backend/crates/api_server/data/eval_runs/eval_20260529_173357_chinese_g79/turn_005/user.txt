老师，刚开始读到“卖弄”这个词，我觉得它好像有点不太好——比如我们班有的同学考试考了100分，故意把试卷在别人面前晃来晃去，大家就会说他“卖弄”，有点讨厌。

可是朱自清在这里写鸟儿“卖弄清脆的喉咙”——我觉得不是批评鸟儿。因为鸟儿又不是故意要炫耀自己唱歌多好听，它是**太高兴了**，春天来了，花儿开了，树叶嫩嫩的，风也暖暖的，它憋了一整个冬天，终于可以舒舒服服地唱了！所以它就忍不住“卖弄”起来了，像我们春游的时候，高兴得一路又喊又唱，妈妈说我“疯玩”，其实不是真的疯，是太开心了。

而且他后面写鸟儿“唱出宛转的曲子，跟轻风流水应和着”——这就像一场音乐会！鸟儿不是一个人瞎唱，它是和风、和水一起在合奏。所以这里的“卖弄”是**活泼的、可爱的、得意里带着天真**的那种感觉。

就像我弟弟搭好一个积木城堡，会喊“姐姐快看！”——他不是要气我，是真的觉得自己好棒，想让我夸他。😄
