**第一题（手法）**：  
这篇课文主要运用了**比喻**和**拟人**的修辞手法来突出济南冬天的特点。  
比如，他把济南比作“小摇篮”——“济南的冬天是没有风声的，济南的冬天是响晴的，冬天是温晴的。”这个比喻让人感觉济南冬天就像妈妈摇着摇篮一样温暖、安全、平静。  
还有拟人的地方，比如“济南的水是清亮的，绿得像块蓝水晶。”他把水写得像有生命一样，静静地卧在大地上，显得很温柔、很安静。

**第二题（内容）**：  
老舍在描写济南冬天的水时用了“清亮”“绿汪汪的”“冒着热气”这些词。水的状态是**温温的、软软的、静静的**——它不像北方的水那么冰，也不像南方的水那么流得快，而是像一块暖暖的绿玉，安安静静地卧在那儿，水面上还冒着一层薄薄的水汽，像在呼吸一样。

**第三题（主旨）**：  
作者借济南的冬天想表达的是：**济南的冬天不是寒冷的、可怕的，而是温晴的、可爱的、充满生机的。他想告诉我们，冬天也可以这样温暖和美好，就像济南这个城市一样，给人一种安详、舒服、像家一样的感觉。** 这其实是在表达他对济南的深深喜爱和眷恋，就像在自己家里一样安心、自由。
