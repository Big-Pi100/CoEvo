（手指轻点课文第二段）

看我标红的这几个字——  
**“小草偷偷地从土里钻出来，嫩嫩的，绿绿的。”**

请你用“心”的眼睛再看一遍：  
- **“偷偷地”**——小草像个害羞的小孩，怕人发现。你读到这个词时，心里是什么感觉？  
- **“钻出来”**——为什么不是“长出来”，而是“钻”出来？  
- 然后作者写**“坐着，躺着，打两个滚，踢几脚球，赛几趟跑，捉几回迷藏”**——  
  这一连串动作，都是什么（人）在草地上做的事？
