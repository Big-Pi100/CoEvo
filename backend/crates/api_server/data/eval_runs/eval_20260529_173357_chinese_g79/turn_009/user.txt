**第一题（手法）**：  
老师，我明白了，《济南的冬天》**最主要的手法是“对比”**。  
比如文章一开头，老舍就说：  
> “对于一个在北平住惯的人，像我，冬天要是不刮风，便觉得是奇迹；济南的冬天是没有风声的。”

他用**北平的冬天**——刮大风、干冷——来和**济南的冬天**——没风声、安静——对比，一下子就让人感觉到济南冬天的**温和**。  
接着又用**伦敦的冬天**——没日光、阴沉——和**济南的冬天**——响晴、看得见太阳——对比，突出济南冬天的**晴朗**。  
最后还用**热带的冬天**——日光毒辣——和**济南的冬天**——温晴、舒服——对比，突出济南冬天的**恰到好处**。

这个对比手法的作用是：**不让读者自己去猜济南的冬天有多好，而是让读者在和别的冬天的对比中，自己得出结论——济南的冬天真暖和、真舒服、真可爱**。这样印象特别深！
