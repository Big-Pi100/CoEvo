（小朋友双手撑着下巴，眼睛认真地看着课文最后三段，嘴唇无声地动了动，然后抬起头）

老师，我发现了——

这三个比喻不是随便写的，它们是**一个接一个变大的**！

**“春天像刚落地的娃娃”** ——娃娃是刚出生的、小小的、软软的，什么都不会，但是充满了可能，什么都刚开始；所以春天最开始也是这样，小草刚钻出来，花刚冒骨朵儿，一切都像**从零开始**。

**“春天像小姑娘”** ——小姑娘比娃娃大一点了，会走会笑，还会穿漂亮裙子、戴花花；春天到了中间的时候，花儿全开了、草长高了，颜色也多了，像小姑娘穿上了花衣裳，**开始热闹起来、美丽起来了**。

**“春天像健壮的青年”** ——青年比小姑娘又大了，有力气、有干劲、能跑能跳、能领路；所以春天到了最后，就不再是嫩嫩的了，而是**有力气地、带着我们往前跑的**。

所以我觉得这三个比喻，其实是**春天在长大**！从刚出生，到漂亮活泼，再到充满力量——朱自清不是用一个比喻写完春天，而是**让春天自己一点一点长大了**。就像我一年级是小娃娃，现在长成有力量的小学生了！

（兴奋地拍了一下膝盖）
老师，我说得对吗？😄
