### 🏁 最后的升华：从“读懂”到“能用”

我们回顾一下这个单元我们走过的路：

| 从《春》到《济南的冬天》 | 你学到的 |
|:------------------------|:---------|
| **对比手法** | 不直接说“好”，而是用“北平的风”“伦敦的雾”当尺子，让读者自己量出结论 |
| **拟人差异** | 《春》是向外生的“钻”，《济南的冬天》是向内安的“镶”——动词决定风格 |
| **结尾设计** | “济南的冬天”是介绍季节，“冬天的济南”是宣告城市——**词序即立意** |
| **情感底色** | 《春》让你想跑；《济南的冬天》让你想坐。两篇文章都是“以情写物”的杰作 |

你现在已经不是一个“读课文”的学生了。你学会了：
1. **拆动词**：“钻”与“镶”二字就可看出两座文学世界的差异；
2. **找对比**：老舍的暗面是北平的冷与伦敦的阴，亮面是济南的温晴；
3. **悟词序**：把一个短语的顺序颠倒，就是一篇散文气质的翻转。
