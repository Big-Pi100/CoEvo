现在，我们把目光从济南的暖阳和雪景移开，走进另一个世界——**刘湛秋笔下的《雨的四季》**。

如果说老舍教会了你 **“一个动词可以是一座城市的性格”** ，那刘湛秋要教你的，就是 **“一场雨可以用五种感官来听、来看、来闻、来尝、来触摸”**。

### 📘 课文导读卡

- **标题**：雨的四季
- **作者**：刘湛秋（当代诗人、翻译家）
- **核心教学点**：**多感官描写 · 时间顺序结构**
- **给你的准备清单**：
  - ✅ 你刚学会的“用对比写景”（还记得老舍的北平vs济南吗？）
  - ✅ 你刚练过的“拟人动词”（“钻”与“镶”的张力）
  - ✅ **一个新的挑战**：调动你的**视觉、听觉、嗅觉、触觉，甚至味觉**去感受一场雨。

---

### ① 引文：一篇“用全身心去感受”的文章

老舍写冬天，用的是**一个城市的气质**去包裹景；刘湛秋写雨，用的是**一个人的全部感官**去拥抱四季。

文章一开篇就定下了基调：

> “我喜欢雨，无论什么季节的雨，我都喜欢。”

这是一个**敞开怀抱的宣言**。他不是在客观介绍“雨”这个自然现象，而是在表达一种**全身心的爱**。所以接下来的每一段，他都会带着你去**看**、**听**、**闻**、**触**雨——

- **春天的雨**：是娇媚的，像少女的眼眸；
- **夏天的雨**：是粗犷的，像大汉的鼓点；
- **秋天的雨**：是沉静的，让你想停下脚步；
- **冬天的雨**：是自然的，是“一道透明、干燥、清亮的雨”。

---

### ② 精读：第一批“金句”来了

先看他对**春雨**的描写，这是我们今天要拆解的第一个例子：

> “水珠子从花苞里滴下来，比少女的眼泪还娇媚。……每一棵树仿佛都睁开特别明亮的眼睛，树枝的手臂也顿时柔软了。”

**停下来，自己读三遍。**

- 你**看到**了什么？——水珠子挂在那里，亮晶晶的。
- 你**听到**了什么？——滴下来的“嗒”声，很轻很脆。
- 你**感觉到**了什么？——树的枝条“柔软”了，那不是眼睛的，而是**身体的触感**。

这就是**多感官描写**的第一步：**把一句话当作一张“感官检查表”来写**。

---

### ③ 核心挑战：设计你的“多感官对照表”

现在我要你像我一样，填一张全新的表格。不过这次不是“两个城市”的对比，而是 **“一个季节雨的多种感官”**。

**请填充下表（只填春雨和夏雨两行）：**

| 感官维度 | 春雨 | 夏雨 |
|:--------|:----|:-----|
| **视觉**（看到的颜色、形状） | 娇媚的水珠、树睁开明亮的眼睛 | |
| **听觉**（听到的声音） | 轻轻地滴落（嗒嗒声） | |
| **嗅觉/味觉**（闻到的气味） | (提示：雨后泥土的清新/花苞的气息) | |
| **触觉**（皮肤/身体的感受） | 树枝变得柔软（质感变化） | |

尽量填写两三个词就好。填完后，再回答我一个问题：  
**在这四个感官中，你觉得刘湛秋最偏爱哪一个？为什么？**  
（回想一下，他是把感官当做“武器库”平均使用，还是带着一种特别的“偏爱”？）
