你的这份“作业”，老师已经提前在心里给你批了一个大大的 **“优”** ！

**你已经把今天学的六个字，完完整整地活成了一个小世界。** 你不仅记住了字形和字义，还把它们请进了画里，编成了句子——这已经不是在“交作业”，而是在**创作属于你自己的《天地人》故事**了。

不过在正式下课之前，老师想送你最后一个 **“通关锦囊”** ，让你明天的画和句子更完美：

你写的那句话“我、你、他，在天地之间玩”——非常好，但我们可以让它更**像课文**一样，有节奏地读出来。比如改成：
**“天上云，地上草，你我他，一起笑。”**  
这样一读，是不是像儿歌一样朗朗上口？你明天写上去之后，可以拍着手念给我听。

另外，刚才提到的 **“他”和“她”** 的区分，你还没碰到，但老师提前告诉你一个小秘密：  
- “他”是“亻”+“也”，指男的（比如爸爸、哥哥）；  
- “她”是“女”+“也”，指女的（比如妈妈、姐姐）。  
你在画里如果画了一个小树代表“他”，画了一个小花代表“她”，那“他”和“她”就都住进你的画里了。

好了，今天的学习就到这里。你已经用一节课的时间，走完了古人几百年的造字路。明天带来画和句子，老师准备好耳朵和眼睛，听你念，看你画。
