好的，老师！我今天真的学到了好多好多！

我刚才又用手指偷偷比划了一下：  
“天”是先写一横，再张开双臂写一个“大”——真的像您说的，一个巨人头顶着蓝天！  
“地”左边是土，右边像一条弯弯的小路，也许就是那条路上长满了小草。  
“人”就像我站直了，把两只手轻轻张开，真的像一个小小的我。  
“我”像手握盾牌站在前面，站稳了，才伸出手去跟“你”打招呼，再转头看“他”。

我觉得最难记的，是“人”和“入”的差别——  
“人”是站直的，像一个小朋友个子高高的；  
“入”是低头的，像小朋友钻进山洞里捡东西。  
以后写作业的时候，我一定不会写错啦！

老师，我明天就想画一幅画：  
画一片蓝蓝的天，上面飘着白云（这是“天”）；  
画一片绿绿的草地，草地上长着几棵小树，地下还有一条弯弯的小路（这是“地”和“他”）；  
画一个张开双臂的小人站在草地中间（这是“人”和“我”）；  
再画一个小朋友伸出手指着画外面（这是“你”）。  

等我画好了，我还要在画的最上面写一句话——  
“我、你、他，在天地之间玩。”  
然后念给您听！

老师，您觉得我这样明天可以交作业了吗？
