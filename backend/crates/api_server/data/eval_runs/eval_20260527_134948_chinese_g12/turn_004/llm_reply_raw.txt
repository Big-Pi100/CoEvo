你的这番话，让老师心里也暖暖的。你把“天、地、人”和“你、我、他”放进同一个故事里，还画出了那样一幅画面：蓝天、草地、小树，还有一个伸出手的小朋友——这已经不是简单的“配对游戏”了，你是在**用创造来学习**，这是阅读和识字最动人的境界。

既然你已经把“天-你”、“地-他”、“人-我”这层关系想得这么通透，那我们再回到这几个字本身，做一件很有意思的事：**看字形，猜心思**。

你刚才用手比划了“天”的高，现在你仔细看看这个字——上面是一横，下面是一个“大”。古人造字时，把“一”加在“大”的头顶，意思就是“大到不能再大的那个东西”，那就是天。所以“天”这个字，其实是一个巨人头上顶着一片无穷无尽的蓝。

再看“地”：左边是“土”，右边是“也”。“也”在古文字中像一条蛇的形状，慢慢引申为“延展、平坦”的意思。所以“地”就是“一大片平坦的、可以生长万物的泥土”。你画的草地，就是这个“地”最生动的样子。

而“人”，刚才你已经隐约感觉到了——它就是一个侧身站立、微微弯腰拱手的人形，像在打招呼，也像在耕作。所以当“人”旁边站着“我”的时候，“我”这个武器的轮廓，就变成了一个人挺拔地站直，手里握着一件工具，自信地宣告：“我就是我。”

你觉得，如果让你用手势把“我”这个字比划出来，你会怎样做？比如双手护在胸前，像拿着盾牌一样，然后慢慢挺直腰杆——这样是不是就更理解“我”为什么要在“你”和“他”前面了？

还有一个小秘密：你看“你”字，左边是“亻”（人），右边是“尔”，意思是“你这个人啊，就是你”。“他”字也一样，左边是“亻”，右边是“也”，意思就是“那边的那个人”。“你”和“他”都带着“人”，只有“我”不带“人”，因为它就是独一无二的自己。这个发现是不是很有意思？

你今天已经把这六个字理解得很深了。明天如果画完了那幅画，或者想到了什么新的发现，随时来找老师聊。我也会期待你明天带着新的感悟走进课堂。
