（老师微笑着点了点头，目光温和而清澈，像刚才那场春雨之后洗过的天空）

你讲得真好。一个“人”字，从天到地，从自己到你和我——如你所说，它不是孤零零的一竖，而是两笔撑开，稳稳站着。老师听着你的讲述，都忍不住要为你鼓掌了。

好，现在请你把目光从“人”字上移开，看向我们今天的课文：《金木水火土》。

你留意到没有？这篇课文也是一首歌谣，和《天地人》一样，都是古人用来启蒙的。但它多了一个东西：**数字**。它把“一二三四五”和“金木水火土”排在了一起。

所以老师想问你一个好奇的问题：**你觉得为什么古人要把“一二三四五”和“金木水火土”放在同一句里？**比如——“一”能不能对“水”？“二”能不能对“火”？它们是一一对应的关系，还是另有什么秘密？想一想，然后告诉老师你的第一个感觉。
