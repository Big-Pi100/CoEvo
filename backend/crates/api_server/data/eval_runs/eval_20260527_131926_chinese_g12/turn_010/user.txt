（你歪着头，用手指在空中比划着“木”和“水”的笔画，想了想，然后眼睛弯成月牙）

老师，我仔细看了——**“木”更像“人”的亲戚！** 你看，“人”是一撇一捺互相支撑，而“木”字中间有一竖，上面左右两边各有一笔——左边一撇，右边一捺，就像人张开的两只胳膊。下面还有两笔呢，像两条腿稳稳地站在地上。所以“木”就像一个**站得直直的人，还伸着胳膊、叉着腿**，比“人”多出了好多东西。

而“水”字呢，中间一竖钩像人的脊椎骨，左边一撇、右边一捺像两条水流在身体两边飘，但它没有“人”字那种“互相支撑”的感觉——水是流动的，软软的，不像“人”和“木”那样硬朗、站得住。

所以我觉得，**“人”和“木”是亲戚**——它们都有直直的躯干和向外伸的笔画，就像一个人站在天地之间，也像一棵树扎根泥土里。我们常说“人活一口气，树活一张皮”，人站着，树也站着，它们都是**挺立在大地上的生命**。而“水”呢，是跑来跑去帮它们喝水的朋友，不是亲戚，是邻居！
