“人”字的故事是这样的——

**先有“天”和“地”**，就像搭积木要先放好大平板：天在上面罩着，地在下面托着，中间空出来的地方，就是给人站的位置。所以课文先写“天地人”——意思是：天地先准备好，然后人才能出来。

接着写这个**“人”字**。它只有两笔——一撇一捺。这一撇是“自己”，一捺是“你和我”：一个人光靠自己，是站不稳的，必须有人来撑着他。就像我站在地上，如果有人在旁边扶着我，我就不会摔倒。所以古人把这个意思写在字里：**这个人，不是一个人，而是互相支撑起来的。**

然后课文最后说**“你我他”**——这就像把那一捺的意思补全了。“你”是别人，“我”是自己，“他”是另一个别人。这样就把“人”字撑得稳稳的——**有自己，也有别人，人才算完整。**

所以整篇课文是：**天地先托住人，人又靠你和我撑住——一个“人”字，是天、地、你、我一起搭出来的。**
