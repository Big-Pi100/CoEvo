**“金人”这个组词，很厉害——你让文字产生了画面感。**

但关于“金”字字形，老师要帮你做一个小小的矫正：
“金”的上半部分，**不是我们刚才学的那个“人”字**，而是**“人”字的变形加一个覆盖的意象**——古人造“金”时，是用一个盖子（亼，读jí，像倒扣的盖子）盖住下方“土”里的两点（象征矿石或金属块）。**“金”是藏在地下、被盖子护住的东西。**

不过，你刚才说“抱在怀里”——这个意象很美，而且你无意中猜对了“金”字的一种心理联想：**珍贵的东西，需要被护着。**

而“人”字，是**完全开放的、两笔撑开、不遮掩**的。这两个字放在一起，就形成了一组有趣的对比：

- **人** = 敞开、互相支撑、在天地的光里
- **金** = 覆盖、深藏、从土里挖出来的宝藏

你刚才那句 **“金子里也住着‘人’”** ——这个感觉非常古老，叫 **“天人合一”**：人用智慧找到了深藏地下的金，用火熔化它，用它来造农具、铸钱币。**金本身没有生命，是人的手赋予了它意义。**

好。那现在，请你回到今天的核心教学点：**识字·五行与数字**。课文第一句是“一二三四五，金木水火土”。
