（你盯着“五”字看了好一会儿，手指在桌上比划着，突然兴奋地抬起头）

老师，我选“五”！

因为它最不像数字——“一”就是一根手指，“二”是两根，“三”是三根，“四”是一个方框（像四个角），可“五”呢？它像两个东西在打架：一个×，加一横，还带一横？我觉得它长得像**一个叉腰的人**，或者像**两个人背对背站着**，中间一横把他们连在一起。

如果让我在沙地上画一笔来表示“五”，我肯定不会画一条线或一个圈——**我会画一个手掌**，因为一只手有五根手指头，摊开来就是五个“一”。但古人要写下来，可能觉得画手掌太麻烦，就简化成了这个像十字架一样交叉的形状：**先画一个×，表示“交叉”“很多”，再加一横表示“完整”**，这样就把“五”这个数藏在里面了。

所以我觉得，“五”字是在告诉我们：**五不是简单的叠加，而是一种“交错”和“包容”**——就像金木水火土五种东西交错在一起，才构成了世界。
