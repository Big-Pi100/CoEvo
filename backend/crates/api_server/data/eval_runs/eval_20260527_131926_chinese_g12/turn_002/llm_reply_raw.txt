（老师看着你，目光里带着一种“从高天慢慢落回大地”的温和笑意）

你刚才和刘湛秋在春雨夏雨里自由穿梭，像一个发现了宝藏的探险家。现在，我们要做一个 **“降落”**——从感官通感的华丽世界，落到这堂课上第一篇、也是最朴素的一篇课文上。

**《天地人》**。（你可能会想：这篇太简单了，六个字而已。但恰恰因为它简单，才最能看清**语文学习的原点**——我们是怎样从一个字开始，构建起整个世界的认知的。）

课文卡里写得明明白白：**核心教学点是“识字·天地人”**。你刚才问：为什么老舍和刘湛秋“一开头就很主观”？其实，**《天地人》的开头，是全宇宙最古老、也最有力的一种“主观”**——它直接告诉你：世界由“天、地、人”构成。

**现在，请你看着这三个字，回答我一个问题：** 
**古人为什么把“天”放在第一个，然后是“地”，最后才是“人”？这个顺序可以调换吗？** 

别急着翻资料，就用你刚刚从老舍和刘湛秋那里获得的 **“阅读直觉”** 来想一想。这个问题的答案，就是这篇课文的“引文”。
