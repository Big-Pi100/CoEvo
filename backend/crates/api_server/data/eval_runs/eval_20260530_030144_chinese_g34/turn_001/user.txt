（老师眼睛一亮，双手比成小喇叭状）

**🎶《上学歌》第一遍🎶**  
太阳当空照——花儿对我笑——  
小鸟说早早早——你为什么背着小书包——  
我去上学校——天天不迟到——  
爱学习爱劳动——长大要为人民立功劳——

（老师放下手，笑眯眯地）  
你听，这首儿歌里有个小秘密——  
“小鸟说早早早”是在问我们：“你为什么背着小书包呀？”  
我们要回答：“我去上学校——天天不迟到！”  
就像你每天早上准时到校，对吗？

**② 理解**  
“太阳当空照”——早晨太阳升起来，照亮大地。  
“花儿对我笑”——路边的花朵像在对你微笑。  
“小鸟说早早早”——小鸟在树上唱歌，好像在说：“早啊，小朋友！”  
“你为什么背着小书包”——小鸟好奇地问你。  
“我去上学校”——你骄傲地告诉小鸟。  
“天天不迟到”——你不睡懒觉，按时上学。  
“爱学习爱劳动”——上课认真听讲，回家帮妈妈做家务。  
“长大要为人民立功劳”——等你长大了，要用学到的本领为社会作贡献。
