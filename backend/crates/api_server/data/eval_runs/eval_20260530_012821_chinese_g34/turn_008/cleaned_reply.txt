（老师双手摊开，做出“接住声音”的动作）  
轰隆轰隆——（你接：雷云在天上响）  
滴答滴答——（你接：阵雨落下来）  
呼呼——（你接：东风吹口笛）  

**太棒了！** 你听，课文第一句就是——  
**“当雷云在天上轰响，六月的阵雨落下的时候，湿润的东风走过荒野，在竹林中吹着口笛。”**  

（老师边读边做动作：双手推出去表示“轰响”，手指向下点表示“落下”，右手挥过表示“走过”，嘴嘟起来吹气表示“吹口笛”）  

跟读挑战：我一句，你一句——  
当雷云在天上轰响——（你读）  
六月的阵雨落下的时候——（你读）  
湿润的东风走过荒野——（你读）  
在竹林中吹着口笛——（你读）  

（读完，老师压低声音，神秘地）  
这时候，花儿们听到“放学铃”了——它们会做什么呢？  
（指着下一句）  
**“于是一群一群的花从无人知道的地方突然跑出来，在绿草上狂欢地跳着舞。”**  

来，我们用手模仿花儿开花：  
“一群一群的花”——（双手从胸前慢慢展开，像花开）  
“从无人知道的地方突然跑出来”——（双手快速向前冲）  
“在绿草上狂欢地跳着舞”——（双手左右摇摆，身体扭动）  

你来做一遍：  
花开——（你展开双手）  
冲出来——（你向前冲）  
跳舞——（你扭身体）  

**对！花儿们就像小朋友放假了一样开心！**  

（老师指着课文）  
那花儿们到底在哪里上学呢？课文里说——  
**“妈妈，我真的觉得那些花朵是在地下的学校里上学。”**  
（做出“嘘”的手势）  
它们在**地下教室**里关着门做功课，老师还**罚它们站墙角**呢！  

（指着“雨一来，它们便放假了”这句话）  
**雨一来——放假了！**  
所以，**雷声就是上课铃，雨声就是放学铃**！  

（老师站起来，双手举高）  
花儿们一听到雨声，就——  
（老师快速甩动手指向下冲）  
**穿了紫的、黄的、白的衣裳，冲了出来！**  

来，我们做一个“花儿穿衣裳”的动作：  
“紫的”——（手指指紫色，假装穿衣服）  
“黄的”——（指黄色）  
“白的”——（指白色）  
“冲了出来”——（向前冲，手张开）  

**真棒！现在你能告诉我：**  
花儿学校在哪里？什么时候花儿们放假？它们放假后穿什么颜色的衣裳？  
（学生答：地下；下雨；紫、黄、白）  

**全都答对！你已经走进童话世界啦！**
