老师，我用“眼睛、耳朵和手”来读“天、地、人”啦！

先说“天”：我**看到**的天是**蓝蓝的**，就像夏天中午的颜色，不过有时候也会是灰白的，或者像橘子汁一样的橙红。但我觉得“天”最像的颜色是**亮亮的蓝色**，因为老师说“天”是头顶上最高的地方，越高就越蓝。

再说“地”：我**听到**的地是**轻轻的“沙沙”声**。就像我踩在落叶上，或者用鞋子蹭了蹭泥土，会发出那种软软的、碎碎的声音。我觉得地不像雨那么响，它比较安静，像在听我们说话。

最后说“人”：我**感觉**到的“人”是**温温的**，就像老师您刚才说的“温雨”——不烫也不冰，刚好让手觉得舒服。因为“人”是站在天和地中间的，所以他的温度应该是刚刚好的，像妈妈的手拉着我的时候那样暖暖的。

老师，我觉得“天、地、人”好像是一个家：天是屋顶，地是地板，人是站在中间的小孩子。
