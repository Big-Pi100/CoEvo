（你“啪”地一拍小手，眼睛亮得像两颗小星星，身子往前探了探，大声说——）

老师，我想好了！

大拇指最有力，像金子一样硬硬的、贵贵的，所以它代表 **金**！  
食指最会指东西，点东西，像火苗一样跳来跳去，所以它代表 **火**！  
中指最长最高，站得最稳，像一棵大树，所以它代表 **木**！  
无名指上戴的亮闪闪的戒指，也是金子做的，所以它也代表 **金**……诶？不对，老师，两个都是金吗？  
小拇指最小最灵巧，沾点水画画、弹弹琴，它像小水珠一样，所以它代表 **水**！

（你挠了挠头，有点不好意思地补充道——）  
那“土”呢？土好像……哪个手指都不太像。老师，我剩下的手指是不是漏了土？
