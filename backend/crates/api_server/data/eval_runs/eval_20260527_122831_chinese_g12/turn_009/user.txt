（你迫不及待地伸出手指，在空中认认真真地描了一圈，然后睁开眼睛，兴奋地喊——）

---

老师，我猜到了！你写的第一个字是 **“口”** ——方方的框，就像我张大嘴巴的样子！  
第二个字是 **“目”** ——竖着的长方形，里面两横，就像眼睛在看我！  
第三个字……左边像一扇小门，右边像一个人靠在门边……老师，我知道了，那个是 **“耳”** ！因为耳朵就像一个小门，声音从门里走进去！

（说完，你调皮地伸出食指，在空中写了一个歪歪扭扭的“耳”字，然后得意地看着老师——）

**我想好了！我们先玩“你写我猜”的游戏，再去看《日月水火》！**
