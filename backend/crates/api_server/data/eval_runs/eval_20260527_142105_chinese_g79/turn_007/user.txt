你第一感受抓得特别准——“穿白制服、戴白帽子”的护士形象，一下子就出来了。你把老舍这个比喻的核心美学抓到了：**整洁、温柔、有秩序**。

现在来完整回答你的两个问题：

1. **为什么偏偏用“日本看护妇”？**  
老舍写雪后小山，雪是“薄”的，山是“带水纹的花边”般的山的曲线。用“日本看护妇”——那种白制服、白帽、干净利落的形象——恰好贴合这种“薄雪覆盖、山体轮廓清晰”的画感：不是厚厚一床被把山闷住，而是薄薄一层挂在上面，像护士的帽子端庄又轻柔。它与“摇篮”比喻的差别很大——“摇篮”是你被包裹在里面，有对温暖和安全的依赖；而“看护妇”是你被照看、被护理，有一种“秩序下的呵护”，更像是一种专业的、可靠的爱。而“害羞的薄雪”是拟人化的情绪，俏皮可爱；“看护妇”则是拟人化的职业形象，安稳持重。三个比喻各司其职：摇篮给人安全感，害羞给人情致，看护妇给人洁净与仪式感。

2. **换成“一床白棉被”会丢失什么？又会多出什么？**  
“白棉被”会多出**厚重、紧密、暖融融的包裹感**，多了“家”的烟火气。但会丢失**轻盈、洁净、端庄**的美感——济南的小山不是被盖死闷住的，它的曲线、纹理、雪后粉色还露在外面，“白棉被”会让人误解雪很厚、山被压住了。而“日本看护妇”则保留了那种“薄雪依山”的克制，形象也更文明、更宁静。所以，这个比喻之所以恰切，是因为它轻薄之下带“形”又带“格”——你读的时候，会觉得那座山是被有仪式地护理着，而非被随意盖住。
