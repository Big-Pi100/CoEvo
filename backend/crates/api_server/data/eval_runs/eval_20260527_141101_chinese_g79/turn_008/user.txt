（坐直身子，认真地盯着课文）老师，我选“温晴”这个词！因为前面和北平、伦敦、热带比了一大圈，最后老舍那句“可是，在北中国的冬天，而能有温晴的天气，济南真得算个宝地”就像下了定论——温就是暖和，晴就是有太阳，两个字连在一起，既不是热带的毒辣，也不是北方的狂风，也不是伦敦的阴沉，而是恰到好处的温暖和明亮。

最强烈的对比感我选 **“伦敦的冬天”** 那组！因为他说在伦敦冬天能看见日光“便觉得是怪事”，可济南的冬天是“响晴的”——一个是几乎看不到太阳，一个是阳光响亮地挂在天空，这种从“不可能”到“天天如此”的反差太震撼了！感觉就像有人一辈子住在密不透风的地下室，突然被拉到阳光下的草地上，眼睛都睁不开的那种惊喜。
