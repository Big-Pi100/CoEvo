**第一题：**  
“像牛毛，像花针，像细丝”这种修辞手法叫**博喻**，就是用好几个比喻一起来形容同一个东西。它和排比不一样：排比是句式相同、意思相关，但比喻是打比方。这里三个“像……”句式看起来像排比，但每个都是比喻，所以是博喻。

**第二题：**  
春风那段，作者用了**三种感官**：  
1. **触觉**——“像母亲的手抚摸着你”，让我们感觉风很温柔；  
2. **嗅觉**——“新翻的泥土的气息，混着青草味儿，还有各种花的香”，闻到了春天的味道；  
3. **听觉**——“鸟儿将窠巢安在繁花嫩叶当中，高兴起来了，呼朋引伴地卖弄清脆的喉咙，唱出宛转的曲子”，听到了鸟叫声。  
其实还有**视觉**，比如“轻悄悄”的风本身看不见，但通过“抚摸”和“风里带来些……的气息”让我们想象到。

**第三题：**  
这三个比喻的顺序**不能调换**。因为“刚落地的娃娃”代表刚出生，是春天刚开始；“小姑娘”代表长大一点，是春天百花齐放的时候；“健壮的青年”代表最有力量，是春天万物生机勃勃的高潮。它们是从小到大、从弱到强的过程，像人成长一样。作者想表达的主旨是：**春天象征着新的生命、美丽和力量，充满了希望，我们应该像春天一样朝气蓬勃地向前走！**
