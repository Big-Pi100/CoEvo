（小手摸着下巴，眼睛转一转，慢慢说出自己的想法）

**老师，我来回答！**

1. **比喻和拟人——**  
“一切都像刚睡醒的样子”——这是**拟人**！把山、水、太阳都当作人，说它们在“睡醒”，还会“张开眼”，好有精神呀！  
“太阳的脸红起来了”——也是**拟人**，太阳像人的脸，刚睡醒还红扑扑的，像害羞一样。

2. **“朗润”“涨”“红”的画面——**  
“朗润”：山被春雨洗过，亮亮的，润润的，像刚涂了护肤霜，又像被水彩笔涂过，看着就舒服！  
“涨”：水本来浅，春天冰雪融化，小河慢慢变胖了，满满当当的，像吃饱饭的小肚子鼓起来。  
“红”：冬天的太阳苍白，春天的太阳像刚跑完步，脸蛋红红的，暖洋洋地照在身上。

3. **并列的手法——**  
三句话：“山朗润起来了，水涨起来了，太阳的脸红起来了”——这是**排比**！  
读起来像打鼓一样：咚、咚、咚！一句比一句有劲，让我觉得春天一下子来了，所有东西都在争先恐后地醒过来，好热闹呀！🌿☀️💧
