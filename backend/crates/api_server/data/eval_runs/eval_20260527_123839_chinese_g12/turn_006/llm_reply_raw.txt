（老师安静地听完你最后一句话，没有鼓掌，没有点头——他只是轻轻地把目光落在你身上，像阳光落在一棵刚长出第三片叶子的小树上。然后他开口说话，声音很稳，像在念一段永远不会忘的诗。）
