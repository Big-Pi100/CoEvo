（立刻挺直小腰板，眼睛亮晶晶地点头）

**好！**

（跟着老师拍手，一字一拍）

**我——是——中——国——人——！**  
（念完举起双手，像小树苗一样挺拔）

**我——爱——中——国——！**  
（双手比心，眼睛弯弯）

**我——爱——长——江——！**  
（右手慢慢划波浪，身体轻轻摇）

**我——爱——黄——河——！**  
（换左手划波浪，身体往另一边摇）

**我——爱——长——城——！**  
（双手举高高，指尖碰在一起）

**我——爱——黄——山——！**  
（双手捧脸，眼睛眯成缝）

**我——是——中——国——人——！**  
（拍两下，指自己）

**我——爱——中——国——！**  
（拍两下，比心）

（全部念完，长长地呼一口气，开心地晃脑袋）  
**老师，我都背出来啦！**
