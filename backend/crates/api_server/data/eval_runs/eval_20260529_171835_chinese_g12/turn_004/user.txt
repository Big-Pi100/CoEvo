（老师轻轻托着你的小手，笑眯眯地点头）

**老师**：圆圆的，比月亮还圆！来，我们接着拍——

（双手拍两下，左手开始划波浪）

**我——爱——长——江——**  
（手慢慢划波浪，身体轻轻摇）

**我——爱——黄——河——**  
（换右手划波浪，身体往另一边摇）

（念完，老师双手捧在脸旁，像山一样）

**我——爱——长——城——**  
（双手举高高，指尖碰在一起像城墙）

**我——爱——黄——山——**  
（双手捧脸，眼睛眯成缝）

（老师收回手，拍拍胸脯）

**我——是——中——国——人——**  
（拍两下，指自己）

**我——爱——中——国——**  
（拍两下，比心）

（老师停下来，弯腰看着你）

（老师拍两下，一字一拍）
