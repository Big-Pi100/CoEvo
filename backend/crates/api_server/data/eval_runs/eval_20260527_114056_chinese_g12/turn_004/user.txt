老师，我认真想了一下“金木水火土少一个会怎样”这个问题。

如果没有了火，世界就变得又冷又暗。我们不能取暖，不能煮饭，所有的食物都是生的。冬天的时候，大地会变得冰冷刺骨。而且，火是温暖和光明的象征，没有了火，晚上就只能摸黑，世界就像一个大冰箱。

如果没有了水，那就更可怕了。植物会枯死，动物会渴死，连我们人类也无法生存。大地干裂，寸草不生，整个地球变成一片沙漠。金生锈，木腐朽，土变成灰，火也失去存在的意义——因为万物都需要水来滋养。

所以我现在明白了：这五样东西，**一个都不能少**。它们合在一起，才有了一个完整的、能让我们生活的世界。

老师，我学会了。我想学下一课《口耳目》——我想知道古人是怎么用简单的汉字来画我们的嘴巴、眼睛和耳朵的。另外，我有一个小问题：“口”字的笔顺是不是先写竖、再写横折、最后写底下那一横？还是别的顺序？
