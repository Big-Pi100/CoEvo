## 第二课：《口耳目》

**标题**：《口耳目》  
**作者**：佚名（部编版小学语文一年级上册）  
**背景**：如果说《天地人》让我们仰望星空、脚踏大地，那么《口耳目》就是低下头，看看我们自己的身体。古人把嘴巴、眼睛、耳朵用最简单的线条画下来，就成了我们至今仍在写的汉字。

**核心教学点**：识字·口耳目

---

## 第一站：三个“身体汉字”的诞生

我们先来看三个字，它们各自对应一个身体部位：

### 1. 口——嘴巴的轮廓

甲骨文：一个张开的嘴巴，上唇、下唇、嘴角。  
笔顺：竖 → 横折 → 横（你猜对了）  
组词：开口、人口、口罩  
记忆口诀：**四方一张嘴，吃饭全靠它。**

### 2. 耳——侧脸的耳朵

甲骨文：像一只耳朵的侧面剪影，外耳廓围成一个弧形，里面还有耳道。  
笔顺：横 → 竖 → 竖 → 横 → 横 → 横（共6画）  
组词：耳朵、木耳、耳目  
秘密：最后一笔是下面那一横，写的时候上窄下宽，像一个弯弯的耳朵垂下来。

### 3. 目——竖着的眼睛

甲骨文：横着的眼睛，眼眶里有一个圆圈（瞳孔）。后来字形竖起来了。  
笔顺：竖 → 横折 → 横 → 横 → 横（共5画）  
组词：目光、目的、节目  
记忆口诀：**比“口”多两横，里面藏瞳孔。**

---

## 你问的问题——“目”字里面为什么是两横？

这个问题真的问到点上了。

**答案：因为古人画眼睛时，画了“上眼皮”和“下眼皮”。**

- 第一横 → 上眼皮
- 第二横 → 下眼皮  
- 中间那个“空”——就是眼珠和瞳孔

如果你只画一横（像“口”），那就只是一个空框，没有“眼睛”的感觉。加上两横，就有了眼皮包裹着眼珠的立体感，一闭上眼睛就能看到。

## 一个小任务

你能不能根据我们今天学的，用三个字分别对应一个动作？

- **口** → 吃饭、说话、唱歌（选一个）
- **耳** → 听音乐、听故事、听风声（选一个）
- **目** → 看书、看风景、看路（选一个）

比如我写一句：  
**“我用目看书，用耳听风声，用口读课文。”**

你写一句试试看？写完我们就进入赏析环节。
