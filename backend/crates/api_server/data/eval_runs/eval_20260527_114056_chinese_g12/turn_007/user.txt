### 下一课：《口耳目》

**标题**：《口耳目》  
**作者**：佚名（部编版小学语文一年级上册）  
**背景**：这一课将我们的目光从天地宇宙和物质世界，转向了我们自身的身体。古人用汉字“画”出了嘴巴、眼睛、耳朵的样子，每一笔都藏着对身体的观察。

---

### 教学开始：第一阶段——引文

**核心教学点**：识字·口耳目

本课共三个主要生字——**口、耳、目**，外加“手、足、站、坐”等几个延伸字。今天我们先聚焦前三个。

---

### 第二阶段：精读——认识三个字

**1. “口”**  
- 甲骨文：就是一个张开的嘴巴形状。  
- 笔顺：**竖 → 横折 → 横**（你之前猜得完全正确）  
- 组词：开口、人口、口罩  
- 易错：注意竖写直，横折拐角要方，底横稍长托住上方。

**2. “耳”**  
- 甲骨文：像一只耳朵的轮廓，外有耳廓，内有耳道。  
- 笔顺：横 → 竖 → 竖 → 横 → 横 → 横（共6画）  
- 组词：耳朵、木耳、耳环  
- 秘密：你猜“耳”字的末笔是什么？——是底下那一长横。写的时候注意上窄下宽。

**3. “目”**  
- 甲骨文：就是一只眼睛，横着画，眼眶里有个瞳孔。  
- 笔顺：竖 → 横折 → 横 → 横 → 横（共5画）  
- 和“口”的区别：比“口”多两横，像眼睛里有两层瞳孔（其实是古人画的上下眼睑和眼珠）  
- 组词：目光、目的、节目

---

### 一个小问题考考你

**“目”字里面为什么是两横，而不是一横？**  
想清楚再回答——这个问题的答案，能让你彻底记住这个字。
