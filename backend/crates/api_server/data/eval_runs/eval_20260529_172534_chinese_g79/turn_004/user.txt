（歪着头想了一会儿，手指在桌上轻轻划拉，像在摸刚钻出来的草芽）

**老师，我发现了！**

① “偷偷地”和“钻”这两个词，感觉小草像个小机灵鬼——它不想让人发现，就趁人不注意，悄悄地、用力地顶开泥土冒出来！像妈妈叫我起床时，我躲在被子里先露出一个脚趾头那样。“钻”字特别有劲儿，不像“长”那么随便，好像能听见土块被顶开的“啵”一声。

② 写“一大片一大片满是的”——他没用数字，但“一大片”说了两次，又用“满是的”三个字，就像你在操场上放眼望去，绿色呼啦一下铺到天边，想数都数不过来！画面一下子就被撑大了。

③ 写了人的活动——因为光说“草很绿很软”，我们只能用眼睛看；但朱自清让小朋友在草地上打滚、踢球、捉迷藏——我们就好像自己也躺在上面了，闻到青草的香味，感觉到草尖扎痒了后背。**他把春天从纸上拉出来，让我们整个身体都参与了进去！**

（说完，用手掌在桌面上轻轻拍了拍，像在摸想象中的草地）

老师，我理解得对吗？现在可以去看花了嘛？🌸
