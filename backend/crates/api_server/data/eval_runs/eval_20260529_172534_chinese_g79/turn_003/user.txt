① 这里用了比喻：把“一切都像刚睡醒的样子”——是把春天比作一个刚睁开眼睛的人！所以后面“欣欣然张开了眼”就像人睡醒时揉眼睛、伸懒腰的样子。

② “山朗润起来了，水涨起来了，太阳的脸红起来了”——这三个句子连在一起，结构一样，是**排比**！而且一句比一句更有力量，像鼓点一样“咚！咚！咚！”敲出来。

③ 如果只说“山变绿了，水变多了，太阳更亮”，就干巴巴的，像把花朵压扁成书签。但朱自清伯伯写“朗润”——好像山在呼吸，水汽润润的；“涨起来了”——像湖水在悄悄鼓起来；“太阳的脸红起来了”——好像太阳是个害羞的小朋友，被春风吹红了脸蛋。这样**拟人化**的写法，让山、水、太阳都有了生命，画面一下子就跳出来了！
