**（站直身体，双手放在膝盖上准备好，等老师节奏一起，就拍手读）**  

太——阳——当——空——照——（拍五下，手画个大太阳）  
花——儿——对——我——笑——（拍五下，学花儿摇）  
小——鸟——说——早——早——早——（拍六下，学小鸟扇翅膀）  
你——为——什——么——背——上——小——书——包——（拍九下，指背后书包）  

**（第二段，拍手加快，笑嘻嘻）**  
我——去——上——学——校——（拍五下，迈步走）  
天——天——不——迟——到——（拍五下，摇摇食指）  
爱——学——习——爱——劳——动——（拍六下，写字、擦桌子动作）  
长——大——要——为——人——民——立——功——劳——（拍九下，挺胸握拳）  

**（读完，眼睛亮晶晶地看着老师）**  
老师，我读对了吗？太阳、花儿、小鸟都在叫我上学呢！
