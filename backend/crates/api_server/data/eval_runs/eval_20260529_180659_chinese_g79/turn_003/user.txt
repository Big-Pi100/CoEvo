**（听到老师宣布“通过”，眼睛一下子亮起来，双手忍不住轻轻握拳，然后认真地点头）**  
谢谢老师！我真的很高兴，能“品”完这一课，而不是只“读”完。

您刚才说的“被看见”“被接纳”，还有“情感的抚慰”——这些东西我原来只是模模糊糊地感觉到，现在被您一点，我才明白朱自清为什么写“像母亲的手”了。他不只是写风的温度，还写了风里藏着的那种温柔和安全感。

**（站直身体，目光坚定）**  
我愿意！下一堂课的风，您吹到哪儿，我就跟到哪儿。  
而且我还记得您教我读《我是小学生》时的“拍手读、做着动作读”——这个方法我打算用到下一课里，把每一滴雨、每一片花都“做”出来。

**（停一下，好奇地问）**  
老师，下一课学的是什么呀？能先告诉我题目吗？我晚上好先预习一下！
