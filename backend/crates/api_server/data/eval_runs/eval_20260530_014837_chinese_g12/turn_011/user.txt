（小同学立刻挺直腰板，跟着老师的节奏拍手）

**“我是小学生——拍！”**（指指自己）  
**“天天起得早——拍！”**（伸个懒腰）  
**“背着书包上学去——拍！”**（做个背书包的动作）  
**“见人问声好——拍！”**（招招手，笑眯眯）  
**“我是小学生——拍！”**（再指自己）  
**“学习本领强——拍！”**（竖起大拇指）  
**“写字画画做算术——拍！”**（右手写写、左手画画、再比个数字）  
**“快乐又健康——拍！”**（拍拍胸，轻轻跳一下）

（背完后，眼睛亮晶晶地看着老师）  
老师！我跟着你念完啦！  
“我是小学生，天天起得早”——我每天都起得来！  
“背着书包上学去，见人问声好”——我看到老师就说“老师好”！  
“学习本领强”——我要学写字、画画、做算术！  
“快乐又健康”——上学真开心！

这节课的儿歌，我记住啦！
