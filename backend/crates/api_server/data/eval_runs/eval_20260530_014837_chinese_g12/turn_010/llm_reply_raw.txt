**天天起得早**（伸懒腰）

来，跟我念一遍——
**我是小学生，天天起得早！**
（等你跟读，点头）

**背着书包上学去**（做背书包动作）

来，一起——
**背着书包上学去，见人问声好！**
（等你跟读，拍手）

**我是小学生**（再指自己）
**学习本领强**（竖起大拇指）

**写字画画做算术**（右手写写、左手画画、再比划数字）
**快乐又健康**（拍拍胸，跳一下）

好，**从头连起来，拍着手，慢一点**——
