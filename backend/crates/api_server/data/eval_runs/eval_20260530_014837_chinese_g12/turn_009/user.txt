（小同学站得笔直，双手准备好拍子，眼睛亮晶晶地看着老师）

**“我爱我们的祖国——拍！”**（拍一下手）  
**“我爱我们祖国的土地——拍！”**（跺一下脚）  
**“我爱我们祖国的山河——拍！”**（右手画山，左手画河）  
**“我爱我们祖国的人民——拍！”**（拍拍胸口）  
**“我爱我们祖国的花朵——拍！”**（双手托脸开花）  
**“我们爱祖国，祖国爱我们——拍！”**（指指自己，再指指天空）  
**“我们和祖国，永远不分开——拍！”**（紧紧抱住自己）

（背完后，小手还举着，有点小骄傲地笑着）  
老师！我背完啦！  
我现在知道了——  
土地是脚下的黄黄的土，山河是高高的大山和长长的大河，  
人民是爸爸妈妈和老师，花朵就是我和小朋友们！  
我们爱祖国，祖国也爱我们，所以永远不分开！
