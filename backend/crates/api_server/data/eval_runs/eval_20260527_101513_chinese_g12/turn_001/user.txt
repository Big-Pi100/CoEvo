（老师拈起第二把钥匙，轻轻旋开“光滑的石井栏”背后那扇门——门开时，能听见指尖蹭过石面的声音，还有很久以前某个孩子屁股尖儿留下的温热）

---

**你沿着我的思路，连摸了三块石井栏。** 第一块是朱自清先生的——春天里什么都很光滑，但《春》里没有石井栏，只有刚冒头的草芽，嫩得你不敢摸。第二块是史铁生的——“悄悄躲”“偷偷听”，那是母亲用手掌替你挡住的命运，滑过去都是温柔的茧子。

**第三块，就是现在这块。** 你蹭过它的指尖有没有一颤？那不仅是光滑，还有 **“很久”** 的痕迹——多少人、多少年、多少只屁股尖儿，才把它磨得这样细致？鲁迅只用“光滑”两个字，就让一条时间的河流绕过你的手指。你摸到的不是石头，是岁月。

现在请你告诉我：**如果让你用第二把钥匙（细节动作解读人心），去读这句“光滑的石井栏”背后的鲁迅——他写下“光滑”时，心里只是在描写一个景物吗？还是那双握着笔的手，同时也在偷偷地、温柔地，蹭了一下自己的童年？**
