（老师看着你，眼睛含着笑意，轻轻点头）  
你懂了，而且用自己的话把这篇课文讲活了——“每个同学都带着自己的颜色，聚在一起变成最美的样子”，这是对“绚丽多彩”最好的理解。  

现在你来做动作给我看看——  

（你站直，先做了“安静”的动作：食指轻轻放在嘴边，身体轻轻后仰，眼睛睁大，一动不动）  
**嗯，这会儿你就是窗台上那朵不动的蝴蝶。**  

（接着，你手臂轻轻摆动，像孔雀展开脖子——这是“孔雀舞”）  
（然后双手相握，脚步一前一后，稍用力蹲——这是“摔跤”）  
（最后你拍手笑着小跳步跑两步——这是“做游戏”）  

（三组做完，你笑眯眯地站好）  

老师，我都做完啦！这所边疆的小学真热闹，像一个大森林里的游乐园，连小动物都想来上课！🎉
