（你的手指在空中划出“水”字时，我轻轻扶住你的手肘，帮你把最后捺的力度控制好）  
“对！竖钩是水流，横撇是左边浪花，撇是第二朵浪花，捺是右边溅起的水花——你写出来的‘水’字，像三条波浪正在跳舞呢！”  

现在，**第二回合**：  
伸出左手（如果你不是左撇子），我们写**“火”**——  
**点**（头上火星）→ **撇**（左臂）→ **撇**（右臂）→ **捺**（腿和火焰尾巴）  
（你写时，我小声念：“火苗一点，左臂一撇，右臂一撇，最后撇出火焰尾巴。”）  

写完“火”字，你手指停在半空，忽然眨眨眼：  
“老师你看——‘火’的捺，就像我跳绳时绳子甩出去的尾巴！”  

我忍不住笑出来：“你的比喻比课文插图还生动！”  

**现在，终极挑战——写‘金’字**  
（我摊开手掌，让你把食指搭在我手心上）  
“跟着我的节奏：  
一撇（像屋顶）→ 一捺（像另一面屋顶）→ 横（屋顶的横梁）→ 横（第二根横梁）→ 竖（中间的柱子）→ 点（左边藏着的金粒）→ 撇（右边藏着的金粒）→ 横（最后的底座）——合起来就是闪闪发光的‘金’！”  

你写到一半，皱起眉头：“老师，‘金’字的笔画好多啊！”  
“没关系，记个口诀：**人字头，王字腰，两点挂两边，金光照。**”  

你跟着念一遍，再写一次——这次居然一笔都没错！  

**最后，我轻轻拍了拍你写字的右手**  
“今天你猜对了五个字，还亲手写出了‘水、火、金’三个最难的字宝宝。现在——（我翻开课本第一页的《金木水火土》）你用手指着这篇课文，大声读一遍，就当是给自己发一张‘识字勇士’奖状！”  

（你深吸一口气，手指划过每个字，声音像泉水叮咚：）  
“一二三四五，金木水火土。天地分上下，日月照今古。”  

“读完了！”你抬头看我，眼睛亮晶晶的。  

我朝你竖起大拇指：“从今天起，你不仅认识了六个字，还破解了五个字的秘密——你已经是个**识字小侦探**了。明天，我们继续去文字森林里探险，找到‘一二三四五’这五个数字宝宝，好不好？”
