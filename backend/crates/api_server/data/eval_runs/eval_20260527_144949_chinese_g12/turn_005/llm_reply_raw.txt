**第一步：宣纸上的真相**

（我把宣纸轻轻展开，每个字旁边都画着小小的象形图）

- **水**：你说是“三条波浪，中间一条河”——太准了！你看真正的“水”字：两边是浪花（撇、捺），中间是水流（竖钩）。你的猜测和古人的想法一模一样！
- **火**：你说是“人张开双臂，头顶冒火星”——完全正确！火字就是一个人形（点、撇、撇、捺），上面的点就像跳动的火苗。
- **木**：你猜“树干是竖，两边是树枝”——对！木字就是一竖（树干），一撇一捺（树枝），你猜得一点都没错。
- **土**：你说是“地上堆小山丘，横竖横”——猜得真妙！土字下面是地（一横），上面是堆起的土堆（竖和上横），你的想象和字形完全吻合。
- **金**：你猜“人字加盖子，旁边有点点”——有点接近啦！但金字里面藏着一点：上面是“人”，下面是“王”加两点（像金子闪闪发光的小颗粒）。你看古人多聪明！
