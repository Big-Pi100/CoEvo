好，我记得郑振铎的《猫》，三只猫的故事，最后一只最让人心疼。但今天我们要先完成一个“识字大闯关”——因为这是一年级第一课，我们要认识六个字宝宝：

**天、地、人、你、我、他**

你看，这六个字像六个小士兵：
- “天”是头顶高高的蓝天
- “地”是脚下厚厚的大地
- “人”就是我和你这样的“人”
- “你、我、他”是三个好朋友

现在我们来玩一个游戏——

**请你用手指在空中写一个“人”字**。对，就是这样，一撇一捺，像一个人张开双脚站着。写完了吗？好，现在告诉我：

**“天”字上面是什么？**（提示：一横代表“一”，再加一个“大”——我帮你拆开，天=一+大）

如果我说“地”，你会想到什么？是不是脚下踩着的土地？记住，“地”左边是“土”，右边是“也”——土+也=地。

现在，请你用手指在桌面上写一个“我”字，跟着我念：一撇，一个横，竖钩，提，斜钩，撇，横，撇，点——哇，你写出来了！
