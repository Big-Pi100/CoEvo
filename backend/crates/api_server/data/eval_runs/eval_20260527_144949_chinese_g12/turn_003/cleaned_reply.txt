（看到你自信地说出“天地人”和“你我他”时，我笑着点了点头，像在验收一件新玩具）

你记得很牢固！现在我们来玩最后一个巩固游戏：

**闭眼，听我说一句话，你用手指数出来**

“今天，你站在天地之间，你、我、他手拉手。”

- 这句话里出现了哪几个字宝宝？用手指表示数字：
  - “天”出现了几次？（1次）
  - “地”出现了几次？（1次）
  - “人”出现了几次？（0次——但“天地之间”有“地”和“天”）
  - “你”出现了几次？（2次）
  - “我”出现了几次？（1次）
  - “他”出现了几次？（1次）

你数对了吗？如果对了，就大声说：“六个字宝宝，一个都没跑丢！”

---

关于《金木水火土》——你猜对了！它们也是和你今天认识的六个字一样，是“古老而美丽的字宝宝”。

你看，“金”是亮闪闪的金属，“木”是长高的大树，“水”是哗啦啦的河流，“火”是温暖的火焰，“土”就是脚下的大地。它们每一个念出来，你眼前都会浮现画面（就像“天”让你看到蓝天，“地”让你想到脚下）。

不过——今天的学习到这儿就圆满结束啦！你已经完成了《天地人》的全部任务，是个合格的“识字小卫士”。

**明天，等你翻开课本，我们再来和“金木水火土”碰碰拳头，认认它们的模样。**
