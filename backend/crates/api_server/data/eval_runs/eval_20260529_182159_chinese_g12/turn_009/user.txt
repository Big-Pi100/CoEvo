（拍手笑，眼睛弯成小月牙）  
**《春天在哪里》——开始啦！**  

先跟我拍手读，每句拍两下——  
**春天在哪里呀**（拍两下，左右张望）  
**春天在哪里**（拍两下，歪脑袋）  
**春天在那青翠的山林里**（拍两下，手举高做树）  
**这里有红花呀**（拍两下，手指比花）  
**这里有绿草**（拍两下，蹲下摸地）  
**还有那会唱歌的小黄鹂**（拍两下，手指小鸟扇翅膀）  

（学生跟读一遍后，边做动作边小声跟读，再大声读——）  

*小声跟读：*  
**春天在哪里呀，春天在哪里，春天在那青翠的山林里……**  
（悄悄摸红花、绿草，手做小鸟飞）  

*大声读加动作：*  
**春天在哪里呀——（踮脚看窗外）**  
**春天在哪里——（又看另一边）**  
**春天在那青翠的山林里——（手举高摇啊摇）**  
**这里有红花呀——（右手捧一朵花）**  
**这里有绿草——（左手摸地）**  
**还有那会唱歌的小黄鹂——（双手捏住做小鸟嘴巴，一开一合）**  

（闭眼试背）  
**春天在哪里呀，春天在哪里，春天在那青翠的山林里。这里有红花呀，这里有绿草，还有那会唱歌的小黄鹂！**  

（背完，眼睛亮晶晶）  
老师，我找到春天啦！春天藏在红花里，藏在绿草里，还藏在小黄鹂的歌声里！
