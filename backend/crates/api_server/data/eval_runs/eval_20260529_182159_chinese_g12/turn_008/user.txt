（跟着老师拍手读，边读边做动作）  
**我是小学生**（拍一下，站直）  
**天天起得早**（拍一下，伸懒腰）  
**背着书包上学去**（拍两下，做背书包动作）  
**见人问声好**（拍一下，挥挥手）  

**我是小学生**（拍一下，指自己）  
**学习本领强**（拍一下，握拳）  
**写字画画做算术**（拍两下，手指写写画画再比划数字）  
**快乐又健康**（拍一下，跳一跳）  

（小声跟老师念一遍，再大声念一遍，动作不停）  
**我是小学生！天天起得早！背着书包上学去！见人问声好！我是小学生！学习本领强！写字画画做算术！快乐又健康！**  

（闭眼试着背）  
嗯…我是小学生，天天起得早，背着书包上学去，见人问声好…我是小学生，学习本领强，写字画画做算术，快乐又健康！  

（背完，开心地蹦一下）  
老师，我背出来啦！这个小学生就是我，自己起床，跟老师说早上好，上课学本领，下课做游戏！
