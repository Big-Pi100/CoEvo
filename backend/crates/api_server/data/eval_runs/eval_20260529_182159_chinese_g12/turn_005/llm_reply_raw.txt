② 理解  
看，长江像一条蓝色的绸带，从高山流到大海，它的水甜甜的，浇灌了稻田，我们吃的米饭就有它的功劳。  
黄河水黄黄的，像泥土的颜色，但它养育了千千万万的中国孩子，我们的祖先就在黄河边生活。
