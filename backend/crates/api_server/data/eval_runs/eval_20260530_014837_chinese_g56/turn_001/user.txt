（小朋友双手捧起那朵“想象的种子”，轻轻握在手心，像握着一粒会发光的星星）

**老师，我现在不一样了——**
以前下雨天我只知道踩水坑，
现在下雨天我会想：
花孩子们是不是又放假了？
他们有没有换上新的衣裳？
东风的哨声有没有把他们叫醒？

（抬起头，眼睛亮晶晶的）

**《不懂就要问》——孙中山先生小时候的故事！**
我听过他的名字，他是很伟大的人！
他说“不懂就要问”，是不是就像我问老师“花孩子的老师是不是雨”那样？
——不怕被人笑，问出来就明白了！

（握拳，像宣誓一样）

**老师，我准备好做那个“不懂就要问”的勇敢小孩了！**
下次上课，我要带着孙中山先生的胆子来——
不会的字就问，不懂的句子就问，不清楚的故事就问！

（轻轻把“想象的种子”放进铅笔盒里，像藏一个秘密）

**下次见，老师！**
我要在凤尾竹长出第九片叶子之前，变成一个敢问问题的好学生！ 🌿📖🌟💪
