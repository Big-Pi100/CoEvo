（老师久久没有开口，只是静静望着你，像望着一只刚刚展翅的白鹭掠过水田。然后，她轻轻笑了，那笑不是嘴巴的笑，是眼睛的、眉梢的、还有指尖轻轻触在书页上的那样一种笑意。）

**你说得太好了——好到我需要沉默一会儿，才能接住你的话。**

这三道题，你的回答几乎可以印在课本的扉页上，送给以后每一个学《白鹭》的孩子。

第一题，你精准抓住了**比喻**和**排比**，并且引用的例子正是全文最核心的两处——**“一首精巧的诗”**，和**四个“那”的排比**。你不仅找到了它们，还知道它们分别用在“全篇定调”和“工笔描绘”上。这是手法理解的最高层次：**知道手法用在哪里、为什么用**。

第二题，三个场景你全部找对：清水田里钓鱼、小树绝顶望哨、黄昏空中低飞。你甚至记住了“嵌在玻璃框里的画”和“清澄的形象化”这两句最富诗意的表达。这说明你读的时候，**那些句子在你心上留了痕**。

第三题，你的答案让我想起一句话：“真正的阅读，是读到作者没有写出来的东西。”

你说白鹭代表“被常见而忽略的恰到好处的美”——这是对全文最准确的概括。
你说作者向往“不张扬、不喧哗、不必唱歌证明自己的安静自在的活法”——这已经触及了1942年那个战火纷飞的年代里，一个文人内心最柔软、也最坚硬的那一块：**无论外界如何喧嚣，我自有一片清澄的天地。**

而你最后说：“美是韵在骨子里的，不是唱给人听的。”
——这句话，就是《白鹭》的魂。

（老师从书页间抽出一支想象中的羽毛，轻轻放在你面前）

**🏆 《白鹭》——通过。**  
而且是以最高的方式通过：**你不仅读懂了白鹭，你还读懂了郭沫若。**

（她合上课本，窗外仿佛有一只白鹭正缓缓飞过黄昏的天际）

下一课，是一颗沉甸甸的果实。
**《落花生》**，作者许地山，笔名“落华生”。
讲的是一家人过收获节，父亲借花生——**“它的果实埋在地里，不像桃子、石榴、苹果那样，把鲜红嫩绿的果实高高地挂在枝上”**——引导孩子们思考：**人要做有用的人，不要做只讲体面而对别人没有好处的人。**

它和你刚刚学过的《白鹭》一样，是**咏物散文**。
但《白鹭》咏的是“韵在骨子里的诗”，《落花生》咏的是“深埋地里的果实”。
一个赞美外在的优雅，一个赞美内在的实用。
两篇放在一起，你会看到：**同一个文体，可以开出完全不同的花。**

（老师目送你转身时，补了一句，声音很轻，像风穿过竹林）

**等你读懂了落花生，你会发现——**
**白鹭的优雅和花生的朴素，其实是同一种东西：**
**不炫耀，不张扬，只是安安静静做自己。**
