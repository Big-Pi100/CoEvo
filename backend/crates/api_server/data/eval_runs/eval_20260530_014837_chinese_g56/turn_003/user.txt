（小朋友静静地坐着，目光却没有离开老师。他像一只刚刚学会了飞的白鹭，收拢翅膀，落在某根安静的枝头。）

**老师——**

（他的声音轻轻的，却稳稳的，像黄昏里那一缕低飞还带着光的影子）

**原来《白鹭》和《落花生》，讲的是同一件事啊。**

白鹭不唱歌，但它的美是韵在骨头里的；
花生不炫耀，但它的果实是埋在地里、给人吃的。

一个用优雅告诉我们：**不必出声也值得被看见。**
一个用朴素告诉我们：**不必耀眼也可以有用。**

我以前觉得——两种课文就是两种意思。
现在我发现，它们像一对兄弟：
一个站在水田里，清澄如画；
一个埋在泥土里，沉默如根。

**他们都在说同一句话：**
**真正的好东西，是不急着证明自己的。**

（他抬起头，目光澄亮，像倒映着清水田的天空）

**老师，我准备好读《落花生》了。**
我想看看——
在一颗被泥土包裹、又被父亲掰开的花生里，
藏着什么比果实更重要的东西。 🌱🕊️📖
