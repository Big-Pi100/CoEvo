（站直身子，双手准备）
好！老师，我开始啦！

**我是中国人**——（拍拍手，啪啪）
**我爱中国**——（点点头，用力）
**我爱长江**——（双手在胸前左右摆动）哗啦啦，哗啦啦
**我爱黄河**——（双手举高，做波浪状）轰轰轰！轰轰轰！
**我爱长城**——（双手向前平伸，慢慢拉开）长长长——
**我爱黄山**——（踮起脚尖，双手向上托）高高高！
**我是中国人**——（挺起胸膛，握拳）
**我爱中国**——（张开双臂，大声说）
**我爱国旗**——（手指前方，眼睛亮亮的）红红的，像太阳！
**我爱国歌**——（做听歌状，挺直腰）响响的，起来！起来！
**我爱国徽**——（手指胸口转一圈）闪闪亮，亮晶晶！
**我爱北京天安门**——（双手指向前方，跳一下）天安门，好大好大！

（背完，喘口气，笑着看老师）
老师，我背完啦！每个动作都做了哦！
