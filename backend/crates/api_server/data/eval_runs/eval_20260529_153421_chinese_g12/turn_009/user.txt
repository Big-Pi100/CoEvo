（站直身子，歪着头想了想，眼睛一亮）

老师，我知道啦！我说说看——

**“我是小学生”**（挺起胸膛，拍拍胸脯）
就是——我长大啦！像小苗苗长高了！
- 书包**重重的**，里面装着课本和铅笔盒
- 每天**自己起床**，不赖床，像小公鸡一样
- 见到老师要**大声问好**，声音脆脆的
- 要学**写字、画画、做算术**，本领越来越多

**“我是幼儿园小朋友”**（蹲下来，双手做小的样子）
那时候——我还是小宝宝呢！
- 书包**轻轻的**，只有水壶和点心
- 可以**多睡一会儿**，老师会轻轻叫我
- 见到老师只要**笑眯眯**就好
- 每天**玩游戏、唱歌、滑滑梯**，不用做作业

（站起来，手指点着心口）
所以，当小学生就是——要**更努力、更勇敢**，像小鸟学飞一样，每天进步一点点！老师，我说得对吗？😊
