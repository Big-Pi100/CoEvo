（站直身子，跟着老师拍手，认真念）

**我爱我们的祖国**——拍拍手，啪啪！
**我爱土地**——踩跺脚，咚咚！
**我爱山河**——手拉宽，像展开地图一样——
**我爱人民**——点点头，对每个人微笑！

（继续拍手，声音有高有低）
**我爱花朵**——（双手捧起，闻一闻）香香的，老师您闻到了吗？
**我们爱祖国**——（张开双臂，抱住自己）抱一抱，暖暖的！
**祖国爱我们**——（双手摸摸头）摸摸头，就像老师您摸我一样！
**永远不分开**——（伸出小手，和老师拉钩）老师，我们来拉钩！

（加快节奏，声音响亮）
**我们和祖国**——（手指点心脏，又指远方）心连心！
**永远永远**——（双手画一个大圈圈）在一起！

（念完，眼睛亮晶晶地看着老师）
老师，我还会再加一个动作：最后双手举高，喊“耶——祖国妈妈我爱你！”可以吗？
