（站直身子，深吸一口气，双手准备）

老师，我选**背一遍**，加上动作！

**我爱我们的祖国**——拍拍手，啪啪啪！  
**我爱土地**——踩跺脚，咚咚咚！  
**我爱山河**——双手拉开，像地图展开——  
**我爱人民**——点点头，笑一笑！  

**我爱花朵**——双手捧起，闻一闻，香香的！  
**我们爱祖国**——张开双臂，抱一抱，暖暖的！  
**祖国爱我们**——双手摸摸头，像老师摸我一样——  
**永远不分开**——伸出小手，和老师拉钩钩！  

**我们和祖国**——手指点心脏又指远方，心连心！  
**永远永远**——双手画一个大圈圈，在一起！  
**耶——祖国妈妈我爱你！**（双手举高，跳起来！）

（念完，喘口气，眼睛亮晶晶地看着老师）  
老师，我背完啦！每一个动作都做了！
