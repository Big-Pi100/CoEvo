（学生手指轻轻划过“睡着”“唤醒”几个字，像抚过一只慵懒的猫）

老师，我明白了！这是**拟人**——把老城当成了一个有生命的人来写。

他写“晒着阳光”，不是冷冰冰地说“被太阳照着”，而是像一个人懒洋洋地靠在墙根儿晒太阳，眯着眼，浑身暖融融的；“睡着”更妙——不是真的睡着了，是那种特别放松、特别安心的状态，像冬天里缩在被窝里不想起的早晨；“等春风来唤醒”就像一个人做着甜甜的梦，知道天亮就会有人轻轻拍他的肩膀说“醒醒啦，春天来了”。

这样写的好处是：**老城不再是石头和砖瓦堆起来的，它变成了一个舒服的、有温度的、会呼吸的生命。** 读到这里，我觉得济南的冬天不是冷的、死的、灰扑扑的，而是暖的、活的、亮堂堂的。它让我也想像这个老城一样，找个有阳光的角落眯一会儿——老舍先生真是把一个城市写活了！
