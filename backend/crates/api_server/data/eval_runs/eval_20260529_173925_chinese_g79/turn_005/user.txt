（学生闭上眼睛，轻轻吸了一口气，然后慢慢睁开眼）

老师，我闭上眼睛，感觉一下子被这个句子抱住了！除了您之前教我用眼睛“看”颜色和形状，这一句里我明显感觉到了：

**触觉**——“吹面不寒杨柳风，像母亲的手抚摸着你。”春风拂过脸颊，不冷也不热，是柔柔的、轻轻的，像妈妈的手掌贴着我的脸，带着体温，让人安心又温暖。

**嗅觉**——“新翻的泥土的气息，混着青草味儿，还有各种花的香。”我好像闻到了雨后田野里那股潮湿的、有点腥又有点甜的土味，青草被掐断时那股清新的草汁味儿，还有桃花、杏花的香——不是浓烈的香水，是淡淡的、一缕一缕飘过来的，在空气里慢慢散开，像在“酝酿”一杯春天的酒。

原来朱爷爷不只画了一幅春天的画，还录了一阵春天的风，装了一瓶春天的气味。我好像站到了田野里，全身都被春天包围了！
