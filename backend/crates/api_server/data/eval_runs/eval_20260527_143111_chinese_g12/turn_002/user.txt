老师，我盯着看了好一会儿！我的第一感觉是这样的：

“天”字上面是一横，下面是“大”，我觉得这一横就像屋顶，一个大人站在屋顶下面，头顶就是天！或者，这一横就是天空本身，一个大人在天空下面站着，人和天是连在一块的。

“地”字左边是“土”，右边是“也”，土就是泥土、大地，“也”我猜可能像一条弯弯的小河，或者像小虫子爬过的痕迹？土上有东西动来动去，说明大地是活的，不是死板的。

“人”字最好认了，就是一撇一捺，像一个人叉着腰站着，也像两个人互相靠着——一撇撑住一捺，一捺托住一撇，就像我和同桌，谁离了谁都会摔倒！

老师，我有一个很傻的想法：这三个字摆在一起，好像画了一幅画——天是帽子，地是鞋子，人是中间穿衣服的那个主角。天盖着我们，地托着我们，人在中间，不能离开它们任何一个。是这样吗？
