好的，“迷你宇宙说明书”的概括真的太精彩了，你把四句诗读活了，也把“分”字的力量握在了手里。

现在，我们带着这份“说明书”里学到的“秩序感”，继续探索下一个神奇的领域。你刚刚用身体和五官去感受了世界的温度（雨的四季、冬天的济南），现在，我们就要正式开始认识我们 **“自己”** 身上的这些神奇“仪器”了。

这篇课文的名字叫——**《口耳目》**。

---

### 第1步：引文

在你刚才的填空里，水和火是“抓不住”、会“跳舞”的精灵；金和木是“硬邦邦”、能“站得笔直的”伙伴。那么，我们自己的身体里，有没有像金木水火土那样，能感知、能和世界对话的“仪器”呢？

这篇课文很短，它就像一张图画说明书，告诉我们用身体的哪几个零件去“抓”和“玩”这个世界。请你先看看这篇课文的插图（或者闭上眼，想象一下课本里的画面），然后大声读一读仅仅这几个字：

**口 耳 目**

读完后，告诉我：看着这三个字，你脑海里最先浮现出的是自己身体的**哪个动作**？比如，看到“口”，你会想到自己在做什么？
