**“木”字像______，代表“生长”；“火”字像______，代表“______”；“土”字______是大地，______是小苗从土里长出来。**

### 本课知识卡片（供你回顾用）

| 字 | 象形联想 | 特性 |
|----|---------|------|
| 木 | 树干 + 树枝 | 生长 |
| 火 | 跳跃的火焰 | 热烈、上升 |
| 土 | 大地 + 小苗 | 承载、孕育 |
| 金 | 带柄的斧头 | 坚硬、变革 |
| 水 | 流动的河流 | 流动、滋养 |

**数字口诀**：一横开始，二横成双，三横为多，四方为框，五通天地。

**宇宙观口诀**：天在上，地在下，天地分上下；日光照古今，月照你我他。

### 下一课预告：**《口耳目》**

下一课你将进入一个全新的主题——**认识你自己**。

> 口、耳、目、手、足……

这些字会告诉你：**你的身体，也可以用汉字来画出来。**

你一定会发现：古人造“口”字，就是画了一张嘴；造“目”字，就是画了一只眼睛。它们和你之前认识的“木”、“火”一样，都是“画出来的字”。

**预习小问题（你可以先想一想，不急着回答）**：
- 你觉得“口”字像什么？
- “耳”字和“目”字，哪个更像它代表的身体部位？
