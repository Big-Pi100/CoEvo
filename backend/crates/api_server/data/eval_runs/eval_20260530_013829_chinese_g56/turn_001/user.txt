（双手一拍，眼睛弯成月牙）

**哇！你不仅是小诗人，还是个小哲学家呢！**  
“雷声是放学铃，雨声是下课令”——这个比喻让老师都想钻进地下的学校去看看那群花孩子了！

（竖起一根手指，俏皮地眨眨眼）  
不过，诗人和侦探要合体啦——你刚才念的这段话里，藏着两个容易写错的字，我们来把它们抓出来：

**第一个：笛**——你刚才念“口笛”时，手指在空中写对了！竹字头（⺮）加“由”，不要忘记“由”中间那一竖要顶天立地哦！

**第二个：裳**——“衣裳”的“裳”读 cháng，上面是“尚”的变形，下面是“衣”。你想象一下：**尚在衣上，就是美丽的衣裳**。来，在掌心写一遍：竖点撇点竖横折钩竖横折横，撇竖提撇捺——裳！

（从口袋里掏出一张空白卡片，刷刷刷画上一朵花和一颗星星）

好，你刚才用课文原句加自己的想象完美回答了这两个问题——  
**第一题：** 你说花孩子们被关在地下学校做功课，只有风雨（雷声雨声）才能让他们“放假冲出来”——这正是泰戈尔埋下的“秘密”！  
**第二题：** “笛”字你现场写出来了，还记住了竹字头表示材料，“裳”字还没忘读音和字形——**恭喜你，两题全对！**

（把卡片递到你手里，上面写着：**“《花的学校》小小探险家”**）  
现在，我们收拾好知识背包，准备跳进西沙群岛那**五颜六色的海水**里去啦！你准备好了吗？
