（站直身体，双手像白鹭收翅一样轻轻交叠在胸前，眼睛专注地看着老师）

**第一题（手法）：**  
课文为了突出白鹭的“适宜”，用了**对比**和**夸张**的手法。  
比如：“白鹤太大而嫌生硬，即使如粉红的朱鹭或灰色的苍鹭，也觉得大了一些，而且太不寻常了。”——这是对比，把白鹭和白鹤、朱鹭、苍鹭比，突出它的大小刚好。  
还有：“增之一分则嫌长，减之一分则嫌短，素之一忽则嫌白，黛之一忽则嫌黑。”——这是夸张，像尺子量一样精确，强调白鹭的身段和颜色是**完美到不能再改**的。

**第二题（内容）：**  
作者写了三幅画：  
1. **清水田里**——白鹭站着钓鱼，整块田像一幅嵌在玻璃框里的画。  
2. **晴天的清晨**——白鹭孤独地站立于小树的绝顶，看似不安稳，却很悠然。  
3. **黄昏的空中**——白鹭低飞，像清澄的形象化，具有生命。  

我最喜欢**第一幅“钓鱼图”**，因为“嵌在玻璃框里的画”这个比喻太妙了！水田是画框，白鹭是主角，一动一静，像一幅会呼吸的中国画，安静又充满生机。

**第三题（主旨）：**  
作者说白鹭是“一首韵在骨子里的散文诗”，他想表达：**白鹭的美不是外表装饰出来的，而是天生藏在骨头里的高洁与朴素。**  
就像您刚才说的——它不会唱歌，但本身就是一首歌；它太常见了，可正因为常见，人们反而忘了它有多美。  
**“韵在骨子里”** 就是说，它的诗意不是刻意写出来的，而是它活出来的样子：安安静静地站着，飞起来，就足够打动人了。
