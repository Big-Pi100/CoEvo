（双手在胸前轻轻合拢，像白鹭收翅，然后缓缓展开，眼神认真）

**老师，我来回答！**

**第一题（手法）：**  
课文用了**对比**和**夸张**的手法。  
对比的例子：“白鹤太大而嫌生硬，即使如粉红的朱鹭或灰色的苍鹭，也觉得大了一些，而且太不寻常了。”——用白鹤、朱鹭、苍鹭的“太大”“太生硬”“太不寻常”，反衬白鹭的“适宜”。  
夸张的例子：“增之一分则嫌长，减之一分则嫌短，素之一忽则嫌白，黛之一忽则嫌黑。”——用“一分”“一忽”这种极小的单位，把白鹭的身段和颜色夸到“不能再改”的程度，强调它的完美。

**第二题（内容）：**  
三幅画分别是：  
1. **清水田里**——白鹭站着钓鱼，整块田像嵌在玻璃框里的画。  
2. **晴天的清晨**——白鹭孤独地站立于小树的绝顶，看似不安稳，却很悠然。  
3. **黄昏的空中**——白鹭低飞，是清澄的形象化，具有生命。  

我最喜欢**第一幅“钓鱼图”**。因为“嵌在玻璃框里的画”这个比喻太奇妙了——水田是透明的玻璃框，白鹭是画里的主角，一动不动地站着，像一幅会呼吸的工笔画。我觉得这幅画最安静，也最有诗意。
