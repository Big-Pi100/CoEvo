**我的小例子是这样的——**

上周数学课，老师讲分数乘法，我旁边的同学林小凡怎么都弄不明白“约分”那一步。他急得直戳橡皮，橡皮屑掉了一桌子。

我想起课文里的话——“人要做有用的人”。于是我把他的练习本转过来，在空白处画了一个小小的“约分”示意图，一步一步地讲给他听。

我说：“你看，这个2和这个8就像两个调皮的孩子，它们可以一起钻进‘约分’的滑梯里，从2那边滑下来变成1，从8那边滑下来变成4……”

他歪着头看了一会儿，突然喊了一声：“啊！我懂了！”然后他拿起笔，很快就把那道题算出来了——对了。

那一刻，我觉得自己像那颗花生：没被别人看见，也没站在讲台上领奖，但林小凡不再急得戳橡皮了。我觉得这就是——“有用的人”。
