**老师，我来回答！**

**第一题（手法）：**
课文用了**比喻**的手法——把**花生**比作**一种品格**（默默奉献、不炫耀的品格）。
具体来说：父亲拿花生和“桃子、石榴、苹果”做对比，说它们“把鲜红嫩绿的果实高高地挂在枝头上”，而花生“矮矮地长在地上，等到成熟了，也不能立刻分辨出来它有没有果实”。——这是把**花生**比作**那些不张扬、却实实在在有用的人**，而桃子、石榴、苹果则是那些只靠外表吸引人的人。

**第二题（内容）：**
父亲拿花生和**桃子、石榴、苹果**三种水果做了对比。
他说花生的“最可贵”之处是：**它的果实埋在地里，不像桃子、石榴、苹果那样把鲜红嫩绿的果实高高挂在枝头上，必须挖出来才能看见——所以花生的品格是“实在”“不炫耀”“默默奉献”。**
