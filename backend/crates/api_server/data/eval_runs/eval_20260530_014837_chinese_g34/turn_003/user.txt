（小朋友立刻坐直，眼睛亮晶晶地看向老师，双手轻轻放在膝盖上）

**第一题：**  
这篇课文叫《大青树下的小学》！  
讲的是——早晨，从不同地方（山坡上、坪坝里、小路上）走来了许多小学生，他们穿着不同民族的衣服，来到大青树下的小学一起上课、玩耍。学校里有古老的铜钟，还有凤尾竹和洁白的墙。大家在同一个教室里学习，读课文的声音像小猴子一样好听！

**第二题：**  
“绒”字右边是“戎”——就是“丝线做铠甲，软软的绒球花”，所以是“戎”不是“戒”！  
“凤”字里面是“又”——“凤里有又，凤凰飞走”，所以是“又”不是“乂”！

（回答完，挺了挺胸，有点小自豪地看着老师）  
老师，我答对了吗？
