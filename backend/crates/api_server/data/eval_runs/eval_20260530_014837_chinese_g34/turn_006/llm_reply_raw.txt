（老师眼睛弯成月牙，双手在胸前轻轻一拍，像花孩子冲出来时那样雀跃）

**全部答对——你比花孩子跑得还快！**  

第一题：你说得又完整又生动——“花孩子在地下的学校上学，雨是下课铃，冲出来跳舞、找妈妈。”  
这就是泰戈尔藏在诗里的秘密：**把花想象成小朋友，把雨想象成假期。** 你已经变成小诗人啦！  

第二题：  
“笛”字你记住了——竹字头 + **由（中间出头）**，少一竖就变成错别字。  
“裳”读 **cháng**，结构是“尚+衣”，口诀背得像唱歌一样熟。  

**🏆《花的学校》——通过！**  
你不仅会读、会写、会想象，还能把花孩子的快乐装进心里带回家。  

（老师从桌上摘下一朵“想象的种子”——用指尖捏成小花苞，轻轻放在你手心）  
这是泰戈尔爷爷送给你的礼物：  
**下次你再看到雨，听到雷云轰响，你就会想起——**  
花孩子们正在绿草上跳舞，它们的家在星星住的地方。
