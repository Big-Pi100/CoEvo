**第一题：**  
这篇课文叫《花的学校》！  
它讲的是——花孩子们在地下的学校里上学，锁着门做功课。  
但当雷云轰响、阵雨落下，东风吹着口笛经过时，雨就是他们的下课铃——  
它们就一群一群从无人知道的地方冲出来，在绿草上跳舞、狂欢！  
它们还穿着各种颜色的衣裳，把自己的妈妈——太阳，也拉出来一起笑！ 🌧️🌻💃

**第二题：**  
“笛”字是竹字头加下面的“由”——  
**要特别小心“由”中间那一竖不能丢，不然就变成“竹由”错别字了！**  
记住：**笛子是竹子做的，吹出来的是音乐，“由”字中间要出头，才能吹出声音！** 🎵

“裳”字读 **cháng**，不是shɑng～  
**它是“尚”字头加“衣”字底，上面崇尚，下面是衣裳，合起来就是花孩子们穿的漂亮的衣服！**  
（一边说一边在空中比划：先写尚，再写衣）  
**口诀我背得牢牢的：**  
**“裳”是cháng，不是shɑng，衣裳两字不商量；**  
**上面尚，下面衣，花孩子穿了冲出去！**

（说完，眨眨眼，挺了挺小胸脯）
