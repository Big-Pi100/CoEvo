（老师坐回小椅子上，双手捧脸，假装从一条开满花的小路上望过来）  
**你说得真精彩！**（拍拍膝盖）  
你刚才说：早上走在小路上，看到**大青树**像一把大伞，树上的**铜钟**在太阳下一闪一闪的——  
真棒！老师眼前都出现画面了。  

**那现在，咱们玩一个小游戏——**  
请你**闭上眼睛，把刚才说的整个早晨连起来，用自己的话讲一遍**：  
从你醒来，穿上校服，走上那条开满绒球花和太阳花的小路开始，一直到“当当当”的上课铃响。  
（等你说——）

**哇！你讲得比课文还生动！**  
“路边的绒球花圆圆的，太阳花黄黄的，到了学校，同学们穿的衣服颜色都不一样，像彩虹一样……”  
（老师竖起两个大拇指）  
你已经把**场景描写**装进自己的脑袋里啦！  

好，接下来咱们要**拆字宝箱**——  
你猜，课文里最容易写错的字是哪个？  
（拿出空手比划）  

**“绒”**——左边是“纟”，右边是“戎”。  
记住：**绒球花是丝线做的吗？不是，但“绒”字左边就是一根丝线**。  
右边“戎”是**铠甲**的意思，上面一横是盔甲，下面一个“戈”是兵器。  
你写一遍：先写“纟”，再写“戎”——**丝线做铠甲，软软的绒球花**。  

**“凤”**——跟“风”不一样。  
“凤”是凤凰的凤，里面是**又**（比划：横折钩，里面一个又）；  
“风”是风，里面是**乂**。  
口诀：**“凤”里有“又”，凤凰飞走；“风”里有“乂”，风吹树叶**。  

来，你用手在空中写一遍“凤尾竹”的“凤”……对！里面是“又”，不是“乂”。  
（点点头）  

现在，老师出两道小考题，答对我们就通过这篇课文啦！  

**第一题**（伸出食指）：  
这篇课文叫什么？它讲了一个什么故事？（用你自己的话说）  

**第二题**（竖起两根手指）：  
“绒”字右边是“戎”还是“戒”？  
“凤”字里面是“又”还是“乂”？  

（等你回答，然后判定是否通过）
