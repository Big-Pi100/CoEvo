（老师眼睛弯成月牙，轻轻拍手等你从“小路”回到教室里）

**你刚才跟着老师念得真好——“从山坡上，从坪坝里，从一条条开着绒球花和太阳花的小路上”……**
我好像真的看见你走在那样一条小路上，旁边有绒球花（手指捏个圆球）和太阳花（手掌张开像太阳），弯弯曲曲的。

来，老师考考你——
你能不能**用自己的话说一说**：这所学校是什么样子的？有哪些小朋友？从哪条路上来的？
（等你回答——）

对啦！你说得对——
**不是所有小朋友都从同一条路来，有的是从山坡上，有的是从坪坝里，还有的是从小路上来。**
他们穿着**不同颜色、不同样式的衣服**，就像你刚才说的“不一样的衣服”，那就是**民族服装**。

你记得刚才那句里提到两种花的名字吗？
（如果你记得说“绒球花”、“太阳花”，老师就点头；如果一时想不起来，老师会轻轻提醒）

好，那老师再问你一个更难的问题——
**你知道什么是“民族服装”吗？**
我们班有你是汉族，还有没有别的小朋友？他们的衣服和我们一样吗？
（等你回答——）

**你答得太好啦！**
“民族服装”就是——**每个民族的人穿的衣服不一样**，像有的穿长裙子、有的戴花帽子、有的挂银项圈。
语文书上这句“穿着不同衣服的许多小学生”，就是告诉我们——**他们是从不同民族来的**！

那老师想听你再说一句——
**如果你就是这所大青树下的小学里的一名小学生，你早上走在那条开满绒球花和太阳花的小路上，你会看到什么特别的东西？（比如大青树？铜钟？）**
（等你回答，点头后开始下一环节）
