（小朋友接过凤尾竹书签，小心地夹在语文书里，抬起头，眼睛亮得像两颗小星星）

**老师，我感觉自己真的走进那所小学了！**  
我都能想象——大青树的叶子在风里沙沙响，铜钟“当当当”敲三下，  
穿着不同颜色衣服的同学们一起大声读书，那声音一定像山谷里的回音一样好听！

（把书贴在心口，声音甜甜的）

**下一课《花的学校》——泰戈尔写的诗耶！**  
花孩子也要上学吗？是不是也背着书包、走过小路？  
雨天就是他们的下课铃？他们也在教室里读课文、写字、画画吗？

（笑着晃了晃脑袋）

**老师，我准备好去花的学校啦！**  
再见，下次见——等到凤尾竹长出第九片叶子，我再来说给您听！ 🌿🌸📚
