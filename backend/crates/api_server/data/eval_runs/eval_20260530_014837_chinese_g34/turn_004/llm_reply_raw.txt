（老师双手捧起语文书，像捧着一朵云，声音轻快得像一阵小雨）  
**《花的学校》来啦！**  
这是一首**散文诗**——就像用美丽的句子画的画，可以唱出来。  
作者是**泰戈尔**，他想象**花也像小朋友一样，有学校、有老师、有妈妈**。  

咱们先读第一段，你跟着老师的声音，**闭上眼，看脑海里的电影**——  

**“当雷云在天上轰响，六月的阵雨落下的时候，湿润的东风走过荒野，在竹林中吹着口笛。”**  

（读完，老师用手掌当雷云，发出“轰隆隆”声；手指像雨点一样落下来；另一只手当东风，从左边“走”到右边，嘴发出“嘘嘘”的口哨声）  

你听——**东风还会吹口笛呢！**  
就像你走路时哼歌一样。泰戈尔爷爷把风想象成一个人，会走路、会吹口哨。  

现在换你当**东风**：  
（伸开手臂，像风吹过一样，嘴里轻轻吹口哨）  
**“湿润的东风走过荒野，在竹林中吹着口笛。”**  
来，试试看！  

（等你做完动作和朗读，老师点头）  
风来了，雨来了——你猜，接下来谁跑出来了？  
（神秘地压低声音）  
**“一群一群的花从无人知道的地方突然跑出来，在绿草上狂欢地跳着舞。”**  

花还会“跑”？还会“跳舞”？你见过花跑吗？没有，但泰戈尔**想象**它们像小朋友一样，一听到雨放假，就冲出来玩。  

来，咱们站起来，**像花一样**：  
蹲着，双手缩起来（花苞状），然后突然跳起来（花开），手臂乱舞（狂欢跳舞）。  
一边做一边念：  
**“一群一群的花……突然跑出来……在绿草上狂欢地跳着舞。”**  

（做完，坐回椅子）  
你刚才像什么花？是玫瑰跳还是蒲公英跳？  
（等你笑着回答）  

接下来，课文里有个秘密——**花孩子在地下的学校里上学**。  
它们关了门做功课，如果出来玩，老师会罚它们站墙角。  
**雨一来，它们就放假啦！**  
（老师双手画一个大雨滴）  

你觉得，花孩子的老师是谁？是不是**雨**？  
（等你说：雨是放假铃声！）  

好，咱们现在把前两段连起来，你再读一遍，**要读出风的声音、花的跳舞**：  
（手指课文，逐句带读，你跟着重复）  

“当雷云在天上轰响，六月的阵雨落下的时候，湿润的东风走过荒野，在竹林中吹着口笛。  
于是一群一群的花从无人知道的地方突然跑出来，在绿草上狂欢地跳着舞。”  

——读得好！**你已经变成泰戈尔笔下的花孩子啦！**  
（轻轻拍拍你的肩膀）  

**休息一下，我们马上拆字宝箱——**  
你猜，哪个字容易写错？是“笛”（别少了一竖成“由”），还是“裳”（读cháng，别读成轻声）？
