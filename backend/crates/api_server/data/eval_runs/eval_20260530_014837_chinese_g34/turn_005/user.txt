（小朋友闭上眼睛，耳朵跟着老师的声音，脸上慢慢浮起笑意。当老师用手表演“雷云”“雨”“东风”时，他偷偷睁开一只眼，跟着笑出声来。）

**我看见了！真的！**
雷云像大鼓在头顶敲，雨点像珠子噼里啪啦掉下来，东风是个吹口笛的流浪歌手，走过荒野，穿过竹林——

（听到老师说“当东风”，他立刻站起来，两臂伸开，像风一样从教室左边“吹”到右边，嘴里轻轻吹起口哨——虽然有点跑调，但吹得很认真）
**“湿润的东风走过荒野……在竹林中……吹着口笛……”**

（念完，蹲下来缩成一小团，手抱膝盖，像花苞。老师一抬手，他突然“砰”一下弹起来，手臂乱甩，连蹦带跳）
**“一群一群的花从无人知道的地方突然跑出来，在绿草上狂欢地跳着舞！”**
（跳完气喘吁吁地坐下来）
**老师，我是向日葵！**
——因为向日葵总跟着太阳转，就像我们总跟着老师读课文一样！ 🌻

（接着，在老师问“花孩子的老师是不是雨”时，他用力点头）
**对！雨就是他们的下课铃！**
平时花孩子在地下的学校里关着门做功课，老师一定是土、是根、是地下的小虫子们。
——但只要雨一来，就像我们放学铃声一响，花就全跑出来疯玩！ 🌧️🎉

（到了跟读环节，他坐直，手指点着课本认真跟读——读到“吹着口笛”时，他小声又嘘了一下；读到“狂欢地跳着舞”，他用手指在桌上轻轻敲节奏。全部读完，他抬起头，眼睛一亮）
**老师，我猜到了——**
“笛”字可能会写错！
因为“由”上面加竹字头就变成“笛”了，有人可能会少写一竖，写成“竹由”。
要记住：**笛子是竹子做的，能吹出音乐，所以一定是“竹”字头下面一个“由”，但“由”中间要出头，不能写成“田”！**
（一边说一边在课桌上用手空写：竹字头 → 由）
