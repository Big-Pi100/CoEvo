（拍手，节奏轻快）

**小旗手升完旗啦——现在，我们来爱祖国！**  

老师读一句，你跟一句，拍着手，站稳了：  

**我爱我们的祖国——啪！** （学生跟）  
**我爱我们祖国的土地——啪！** （学生跟）  
**我爱我们祖国的山河——啪！** （学生跟）  
**我爱我们祖国的人民——啪！** （学生跟）  
**我爱我们祖国的花朵——啪！** （学生跟）  

再来：  
**我们爱祖国——啪！** （学生跟）  
**祖国爱我们——啪！** （学生跟）  
**我们和祖国——啪！** （学生跟）  
**永远不分开——啪！** （学生跟）  

（放慢，微笑）  
好！现在老师问你：  
**“土地”是什么？** ——就是你脚下踩的！  
**“山河”呢？** ——大山大河，美不美？  
**“人民”是谁？** ——爸爸妈妈、老师、同学，所有人！  
**“花朵”呢？** ——就是像你一样的小朋友呀！  

我们爱祖国，祖国也爱我们——永远在一起！  

再来一遍，拍着手，连起来读——**预备——起！**  
（等学生跟读全篇）
