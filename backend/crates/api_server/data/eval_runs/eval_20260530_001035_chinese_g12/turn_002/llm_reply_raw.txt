（拍手，节奏轻快）

哎呀，背得真有劲儿！不过呀，咱们学的《我是中国人》是另一首——  
来，跟老师一起，拍手读正确的：  

**“我是中国人——啪！  
我爱中国——啪！  
我爱长江——啪！  
我爱黄河——啪！”**  

（放慢速度，拍两下读一句）  
先读前半首，手拍稳，跟上来！  

预备——起：  
**我是中国人。** （学生跟）  
**我爱中国。** （学生跟）  
**我爱长江，** （学生跟）  
**我爱黄河。** （学生跟）  
**我爱长城，** （学生跟）  
**我爱黄山。** （学生跟）  
**我是中国人。** （学生跟）  
**我爱中国。** （学生跟）  

好！再读后半首——  
**我爱国旗，我爱国歌。**  
**我爱国徽，我爱北京。**  
**我是中国人。**  
**我爱中国。**  

（拍手停）  
漂亮！现在你记住原文了。  
老师再问一次：  
**你能试着把《我是中国人》完整背一遍吗？**  
（拍手，等学生背）
