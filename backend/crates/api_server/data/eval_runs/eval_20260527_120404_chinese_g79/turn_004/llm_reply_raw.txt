## ⑤ 巩固（易错/常考）

考前速记清单：

**1. 博喻 vs 排比**（你已掌握，再做一次确认）  
“像牛毛，像花针，像细丝”——**博喻**。如果改成“春雨像密密的牛毛，春雨像闪亮的花针，春雨像柔长的细丝”，则既是博喻又带排比句式。判断基准：**多喻体修饰同一对象=博喻；句式结构重复=排比。**

**2. 结尾三段比喻的顺序逻辑**  
娃娃 → 小姑娘 → 青年。对应春的 **新生 → 繁盛 → 成熟**，不可颠倒。考试常以“能否调换顺序”设问。

**3. 拟人叠词的召唤效果**  
“小草偷偷地从土里钻出来，嫩嫩的，绿绿的”。这里的“偷偷地”“嫩嫩的”“绿绿的”都是叠词，赋予动作拟人化（偷偷=有意识、怕人发现），同时叠词放缓节奏，像抚摸小草时的轻柔手感。

**4. 多感官描写的考法**  
问“选段写了哪些感官”或“这样写有什么效果”。答案要扣住：**触觉**（抚摸般春风）、**嗅觉**（泥土气息花香）、**听觉**（鸟儿婉转）、**视觉**（春花、春雨）。效果：让读者身临其境，立体感受春天。
