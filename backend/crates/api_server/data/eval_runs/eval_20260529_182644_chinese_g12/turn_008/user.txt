（拍手，每句两拍，声音像小闹钟一样响亮）

**① 唱读（跟老师一起拍手）**  
我是小学生——（拍两下）  
天天起得早——（做起床伸懒腰动作）  
背着书包上学去——（做背书包动作）  
见人问声好——（挥手打招呼）  
我是小学生——（拍两下）  
学习本领强——（举起拳头）  
写字画画做算术——（做写字、画画、数数动作）  
快乐又健康——（双手比一个圆圆的快乐脸）

（跟读两遍）

---

**② 理解（用动作和表情讲）**  
老师，我听懂啦！  
“我是小学生”——我就是小学生呀！好神气！  
“天天起得早”——早上闹钟响了，我就爬起来，不睡懒觉。  
“背着书包上学去”——背上小书包，高高兴兴去学校。  
“见人问声好”——看见老师和同学，会说“早上好！”  
“学到本领强”——在学校学写字、画画、做算术，本领越来越厉害。  
“快乐又健康”——身体棒棒的，心里也乐开花！  

---

**③ 输出（拍手背一背）**  
我是小学生，天天起得早，  
背着书包上学去，见人问声好。  
我是小学生，学习本领强，  
写字画画做算术，快乐又健康！

（拍两遍，加动作）
