**② 理解（用动作和表情讲）**  
老师，我听懂啦！  
下雨了，小猫咪没有伞，它就跑到小花伞下面。  
小花狗也来了，它们挤一挤，谁也没推谁，像好朋友一样。  
要是小兔子和小老鼠也来，大家就一起挤，虽然伞小，但挤在一起很暖和！  
这就是互相帮助，就像我和同学一起玩玩具，一起分享饼干一样！😊
