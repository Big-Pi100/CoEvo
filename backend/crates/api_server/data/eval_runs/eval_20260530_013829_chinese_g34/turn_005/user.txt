（眼睛发亮，跟着老师的动作边念边做）  

**“大家穿戴不同，来到学校，都成了好朋友——”**  
（双手在胸前摊开，像介绍一群朋友）  

**“那鲜艳的服装，把学校打扮得绚丽多彩——”**  
（两手画了一个彩虹，脸上露出高兴的表情）  

**“同学们向在校园里欢唱的小鸟打招呼——”**  
（笑着朝旁边挥手，像在跟小鸟说“你好”）  

**“向敬爱的老师问好——”**  
（身体微微前倾，做鞠躬的动作）  

**“向高高飘扬的国旗敬礼——”**  
（右手举过头顶，像升国旗时那样，站得笔直）  

（念完后，放下手，睁大眼睛看着老师）  

老师！我念完啦！我觉得这句写得好美呀——  
小朋友们刚到学校，先跟小鸟打招呼，再向老师问好，最后朝国旗敬礼……  
感觉他们在说：**“我爱学校，我爱老师，我更爱我们的祖国！”**
