第一题：这篇课文《大青树下的小学》主要讲了——  
在云南边疆的一所小学，有一棵特别大的青树，每天早晨，不同民族的小学生从山坡、坪坝和开满花的小路上走来。他们穿着五颜六色的衣服，先跟小鸟打招呼，再向老师问好，最后向国旗敬礼。上课时，大家一起朗读课文，声音好听得让树枝不摇、鸟儿不叫、蝴蝶停在花朵上，连小猴子都好奇地跑来听。下课了，大家在大青树下跳孔雀舞、摔跤、做游戏，小鸟和松鼠也来看热闹。这真是一所可爱的小学！

第二题：“绒花”的“绒”读作 róng（第二声），右边是一个“戎”字，上面是“十”，下面是“戈”，合起来就是“戎”。我记得您说过不是少一撇的“戎”，就是标准的“戎”字，十加戈，对吗？
