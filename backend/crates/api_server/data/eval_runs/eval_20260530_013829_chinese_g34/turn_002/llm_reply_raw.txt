你猜，大青树下的小学是什么样的？是不是有一棵超级大的树，小朋友们在树下上课、做游戏？

**“早晨，从山坡上，从坪坝里，从一条条开着绒球花和太阳花的小路上，走来了许多小学生……”**  
（用手画三个方向：左边山坡、右边坪坝、中间小路）
