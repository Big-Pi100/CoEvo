（精神抖擞，双手举高做太阳，然后一步一步做动作）

**太阳当空照——**
（双手托腮，笑眯眯）
**花儿对我笑——**
（学小鸟扇翅膀）
**小鸟说早早早——**
（手指前方，好奇地问）
**你为什么背上小书包——**

（指指自己，骄傲地挺胸）
**我去上学校——**
（摇头晃脑）
**天天不迟到——**
（做写字和擦桌子动作）
**爱学习爱劳动——**
（张开双臂，声音响亮）
**长大要为人民立功劳——**

（背完了，呼一口气，眼睛亮晶晶地看着老师）
老师！我全部背出来啦！上学歌真好玩！
太阳公公叫我起床，花儿姐姐对我笑，小鸟弟弟问我为什么背书包——
我说：我要去学本领，长大了帮大家做好事！
