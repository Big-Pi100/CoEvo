（站直身体，双手像花朵从地下探出头一样慢慢举起，然后“哗”地展开双臂）

**第一题：**  
花朵们在 **下雨** 的时候放假！课文里说——“雨一来，它们便放假了。”  
它们冲出来是因为：**“树枝在林中互相碰触着，绿叶在狂风里萧萧地响，雷云拍着大手——”**  
（双手猛地一拍，“啪”的一声）  
我觉得雷云拍手就像打放学铃，告诉花孩子们：“下课啦！快点出去玩儿！”  
于是它们就 **“穿了紫的、黄的、白的衣裳，冲了出来”** ，在草地上跳舞、狂欢！

**第二题：**  
“口笛”的 **“笛”** 字——  
（用手指在掌心一笔一画写）  
上面是 **竹字头**（⺮），下面是 **“由”**（不是“由”少一竖哦！），合起来就是 **“笛”**！  
我记得您说过，笛子是竹子做的，所以上面是竹字头，下面是“由”的发音帮助记字！

（忽然想到什么，眼睛一亮）  
老师！我还记住了 **“裳”** 字——上面是“尚”的变形，下面是“衣”，读 **cháng**，不是轻声！  
“衣裳”就是穿在身上的漂亮衣服，对吗？
