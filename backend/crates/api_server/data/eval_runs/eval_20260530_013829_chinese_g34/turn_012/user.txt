（双手在胸前比了一个圆圈，像抱住一个无形的气泡）  
**“妈妈，我真的觉得那些花朵是在地下的学校里上学——”**  
（等你念，然后手像关门一样合拢）  
**“它们关了门做功课——”**  

（等你念完，突然双手叉腰，装出严肃的表情）  
**“如果它们想在放学以前出来游戏，它们的老师是要罚它们站墙角的——”**  

（然后猛地张开双手，像放出一群小鸟）  
**“雨一来，它们便放假了！”**  

（念完，眼睛亮晶晶地眨一眨）  
老师！我明白了——泰戈尔爷爷把花朵比作小孩子，他们上学被关在地下（泥土里），要轰隆隆的雷声和哗啦啦的雨声才能“开门”放假。就像我们下雨天不用出去做操，可以在走廊上玩一样！对不对？
