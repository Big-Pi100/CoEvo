（举手回答）老师，我找到了！济南的水“不但不结冰，倒反在绿萍上冒着点热气”，这里藏着两个层次的对比：

1. **与一般北方冬天的水对比**：大多数地方冬天一冷，河水就结冰了，水是冷冰冰、硬邦邦的。但济南的水不仅不结冰，还冒出热气，说明这里的水是**温热的**，像温泉一样。这和开头说的冬天“温晴”完全呼应——不是寒冷，而是温暖。

2. **与“结冰”这个常识对比**：老舍故意说“不但不结冰，倒反……”这个“倒反”就带出了反差感——我们本以为冬天水会结冰，可济南的水偏偏不结冰，还冒着热气。这种对比突出了济南冬天的**独特**和**反常的温暖**。

另外，后文写“水藻真绿，把终年贮蓄的绿色全拿出来了”，这里的“绿”和冬天的枯黄形成对比——水藻在温暖的水里长得生机勃勃，而且“拿出来”用了拟人，写水藻像人一样慷慨，更突出了水的温暖让植物像春天一样鲜活。还有“空中，半空中，天上，自上而下全是那么清亮，那么蓝汪汪的，整个的是块空灵的蓝水晶”，这里用“蓝水晶”比喻天空和水的清亮，也跟冬天常有的晦暗天气形成对比。

所以老舍写水，也是用对比+拟人，一步一步把济南冬天的“温晴”推到极致——从天气到山，再到水，整个济南就像被温暖搂在怀里。我这样分析对吗？
