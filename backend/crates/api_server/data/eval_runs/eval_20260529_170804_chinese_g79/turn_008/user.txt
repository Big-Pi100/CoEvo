**题1 · 手法**  
（1）课文把济南的冬天和**北平、伦敦、热带**这三个地方做了对比。  
（2）这些对比要突出的共同效果是：强调济南冬天**“温晴”**的特点——既不像北平那样寒冷刮风，也不像伦敦那样阴沉无光，更没有热带的毒辣日光，而是舒适、温暖、晴朗。

**题2 · 内容**  
我最深刻的印象是**雪后小山的场景**。老舍写“那点薄雪好像忽然害了羞，微微露出点粉色”——明明是在写雪、阳光和风，但全句没有出现一个“风”字，却让我感觉寒风轻轻吹过来了。而且“害羞”这个词特别神奇，本来雪是冰冷的，但一“害羞”就变可爱了、变温暖了。这就是老舍语言 **“有温度”** 的地方：不用大词，却能让读者心里暖起来。

**题3 · 主旨**  
作者通过整篇文章想传达的核心情感是：**赞美济南冬天特有的“温晴”与“慈善”，表达对济南这座城市的深深喜爱与眷恋。**
