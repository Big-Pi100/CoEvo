（拍手三下，笑眯眯）

哎呀，你记得真清楚！《秋天的图画》里，是山野、大雁、小动物们一起喊“秋天来啦”～  
可今天呀，我们学的是一首新儿歌——《我是中国人》！  
来，先跟我拍拍手，把刚才的节奏再念一遍！

（拍手念两遍）  
**我是——中国人（拍胸脯）**  
**我爱——中国（双手举高高）**  
**我爱——长江（手做波浪）**  
**我爱——黄河（手做滚滚水）**  
**我爱——长城（手臂平伸左右看）**  
**我爱——黄山（双手举高跳一跳）**  
**我是——中国人（指自己）**  
**我爱——中国（抱一抱）**  

（停顿，放慢语速）  
现在，我们一句一句看画面——  
“我爱长江”——长江水，哗啦啦，从雪山流到大海～  
“我爱黄河”——黄河弯，黄泥沙，像一条金色的龙～  
“我爱长城”——长城长，像一条大龙趴在山上，谁也推不倒！  
“我爱黄山”——黄山高，云朵绕，怪石奇松真奇妙～  

（指着自己眼睛和皮肤）  
黑眼睛，黄皮肤——**我是中国人**！  
（拍拍心口）**我爱中国**！
