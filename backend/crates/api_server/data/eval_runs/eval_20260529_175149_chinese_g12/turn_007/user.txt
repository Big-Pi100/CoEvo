（拍手三下，弯腰笑着看学生）

呀！你这想象力比长城还长，比黄河还宽呢！  
花朵就是秋天画的小精灵——秋天轻轻一吹，花朵就开放，果子就变甜，小朋友就穿上花衣裳～  

现在，好，我们先把新儿歌的“骨架”搭好：  
（拍手念两遍）  
**我们是——祖国的花朵**  
**阳光下——尽情开着**  
**我们是——祖国的小苗**  
**春风里——快快长高**  
**我们爱——祖国妈妈**  
**祖国妈妈——也爱我们**  

（逐句慢速带动作，等学生跟着做）  

好，短句接龙开始——  
“我们是花朵”  
“我们爱妈妈”  
“阳光下开着”  
“春风里长高”  
“妈妈也爱我”  
“我也爱妈妈”  

（全部接完，拍拍学生肩膀）  
现在，闭一下眼睛，想一想：你是一朵小花朵，阳光下慢慢开……好，睁开眼，**背一遍**！从“我们是祖国的花朵”开始，声音带着花香～
