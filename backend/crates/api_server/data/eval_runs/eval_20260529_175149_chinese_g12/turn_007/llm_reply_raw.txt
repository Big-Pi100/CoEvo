（拍手三下，站直挺胸）

新儿歌来啦——《我是小学生》！  
走，我们一起背上小书包，蹦蹦跳跳去上学！

（拍手念两遍）  
**我是——小学生**（指自己胸脯）  
**天天——起得早**（双手做伸懒腰）  
**背着书包上学去**（两手做背书包动作）  
**见人问声好**（弯腰摆手）  

**我是——小学生**（指自己）  
**学习本领强**（双手握拳举高）  
**写字画画做算术**（右手写—左手画圈—右手比划）  
**快乐又健康**（双手张开笑哈哈）  

（放慢，逐句带画面）  
“天天起得早”——太阳公公刚露脸，小闹钟叮铃铃，你就起床啦！  
“背着书包上学去”——小书包里装书本，走路上学，小鸟对你叫～  
“见人问声好”——见到老师鞠躬，见到同学招手，“早上好！”  
“学习本领强”——写字像小树，画画像彩虹，算术像搭积木～  
“快乐又健康”——在操场跑步、在教室拍手，每天都笑嘻嘻！

（短句接龙，老师说前一半，学生接后一半）

“天天——” → 你：起得早  
“背着书包——” → 你：上学去  
“见人——” → 你：问声好  

“学习——” → 你：本领强  
“写字画画——” → 你：做算术  
“快乐——” → 你：又健康  

（全部接完，竖起大拇指）
