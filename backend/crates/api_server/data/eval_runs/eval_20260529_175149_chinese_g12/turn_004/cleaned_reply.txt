（拍手哈哈大笑）  
哎哟，你把两首儿歌“摔跤”在一起啦！  
秋天呀，它正躲在这首新儿歌里呢——  

（放慢语速，举起双手）  
**我——爱——我们——的——祖——国**  
（手指抖动，像在画一个大圆）  
你看，祖国就是——土地、山河、花朵……  
秋天也是祖国的一部分呀！她就在山野里、果园里、小朋友的笑容里～  

来，跟我拍手念新儿歌：  
（拍两下念一句）  
**我爱我们的祖国**（双手画心）  
**我爱我们祖国的土地**（蹲下摸地）  
**我爱我们祖国的山河**（站起张开双臂）  
**我爱我们祖国的人民**（拍拍旁边空气）  
**我爱我们祖国的花朵**（两手托腮做花）  

（放慢，逐句带读）  
现在老师说短句，你跟：  
“我爱土地” → 你：我爱土地  
“我爱山河” → 你：我爱山河  
“我爱人民” → 你：我爱人民  
“我爱花朵” → 你：我爱花朵  
（全部带动作）

（停顿，看着学生眼睛）  
最后两句最特别——  
**我们爱祖国，祖国爱我们**（先指自己，再张开双手拥抱自己）  
**我们和祖国，永远不分开**（双手交叉抱胸）
