（你静静地听完老师的话，像一棵刚刚被春雨洗过的树苗，微微挺直了脊背。你低下头，看着桌上那枚花生形状的书签，又抬头望向窗外被风吹动的树影——仿佛整个世界都在轻轻呼吸。）

**老师，我刚才听你说那句“每一种手法，都是从不同方向走到同一个地方”的时候，忽然觉得心里有什么东西被轻轻拨动了。**

我本来以为，读课文就是为了学会“比喻”“对比”“借物抒情”这些名字——像集邮一样，集齐了就算完成任务。
但现在我明白了：
**这些名字不是终点，它们是工具。**
工具是用来做事的。

就像——
**借物抒情**，是把心里说不出口的眼泪，藏进一朵桂花里，等别人闻到了，就懂了。
**借物喻人**，是把一个做人的道理，种进一颗花生里，等别人挖出来了，就记住了。
**托物言志**，是把一个自己想去的地方，写进一只白鹭的翅膀里，等别人抬头看见了，就有了方向。

（你伸出手，轻轻把那枚白鹭书签和花生书签放在一起，它们一高一低，像两个站在同一片天空下的朋友。）

**所以我在想——**
**我现在手里握着的不只是“五种手法”，而是五盏灯。**
每一盏灯都可以照亮前路的一小段。
但没有一盏灯能照亮整条路。

**走出路来的，只能是我自己。**
用我自己的脚。

（你抬起头，目光里有一种少年人特有的、安静的决心）

**“先长根，再结果”——这句话我现在懂了。**
它不是让我安静地等待，什么都不做。
**它是让我在看不见的地方，默默地努力——**
读书、思考、感受、练习——
像花生在土里吸收养分一样，不着急被人看见。

**等到哪天我真的有什么可以“挖出来”给世界看的时候——**
我希望那是一颗配得上曾经埋下它的泥土的心。

（你收好所有书签，将它们轻轻放进书包的内层，然后抬起头，望向老师，笑了——像一个准备出发的旅人，在告别前最后一次回头确认方向）

**老师，谢谢你。**
**我已经准备好了。**
**随时可以翻开下一页。**
