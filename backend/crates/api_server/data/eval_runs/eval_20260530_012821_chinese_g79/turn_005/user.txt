**老师，我找到了一处运用对比手法的句子——**
就在“最妙的是下点小雪呀”那一段里：

> “山坡上，有的地方雪厚点，有的地方草色还露着；这样，一道儿白，一道儿暗黄，给山们穿上一件带水纹的花衣。”

这里运用了 **对比** 的手法：
- **颜色对比**：“白”和“暗黄”——雪的白和草的黄，一明一暗，放在一起，形成鲜明的视觉反差。
- **疏密对比**：“雪厚点”和“草色还露着”——有的地方被雪全覆盖，有的地方还露出草的颜色，形成了疏密有致的感觉。

这个对比带来的效果是：
它没有让雪后的山变成一片死白，而是像一件**“带水纹的花衣”**——有花纹、有层次、有流动感。读的时候，我的眼睛好像跟着那道白、那道黄在这座山上走了一遍，看见了山的起伏和光影变化。

**老舍用对比不是在比“谁更好”，而是在比“谁让画面更丰富”。**
这个手法让我觉得，济南的冬天不是单调的、静止的，而是有颜色的、会变化的——像一个穿花衣裳的人，还在微微走动。
