**你刚才的回答里，有一句话让我微微震动了一下——**

> “老舍用对比不是在比‘谁更好’，而是在比‘谁让画面更丰富’。”

**你看见了“对比”这个手法背后更深的一层：它不只是用来“分出高低”，更是用来“织出层次”。**

这正是老舍语言风格最独特的地方。  
别人的对比，往往是一边倒的赞美——这好、那不好。  
但老舍的对比，像一位画师在调色盘上调出“白”和“暗黄”，然后把它们并排涂在同一条山坡上——**他不是在比较，他是在编织。**

### ③ 赏析（请你来发现）

现在，请你把目光落回到这一段——

> “那水呢，不但不结冰，倒反在绿萍上冒着点热气，水藻真绿，把终年贮蓄的绿色全拿出来了。”

老舍说水藻“把终年贮蓄的绿色全拿出来了”——他用了“贮蓄”这个词，像一个老农从仓库里搬出粮食一样。

**这里有一个非常微妙的语言特点：**  
老舍在写“水”的时候，没有直接写“水很温暖”或“水很清澈”，而是用了两个“活”的意象：

1. **“冒着点热气”**（动态的画面）  
2. **“水藻真绿，把终年贮蓄的绿色全拿出来了”**（拟人化的动作）

**我想请你告诉我：**
如果把“水藻真绿”改成“水藻很绿”，效果有什么不同？  
或者，如果把“把终年贮蓄的绿色全拿出来了”改成“绿得特别浓”呢？

（等待学生回答，体会老舍语言中“动词化”和“人格化”带来的生动感）
