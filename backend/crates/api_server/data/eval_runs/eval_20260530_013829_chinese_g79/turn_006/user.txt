（双手轻轻放在桌上，目光像一瓣刚落下的雪花，静静落在你指尖按着的“温晴”二字上）

老师，我来回答这三道题——

**第一题：手法**
我选“北平 vs 济南”这一处对比。老舍写北平是“冬天要是不刮风，便觉得是奇迹”——这是**听觉**，因为“刮风”有声音，风吹得呼呼响，让人听着就觉得冷、觉得烦；写济南却是“没有风声的”——也是**听觉**，但没有声音，反而让人感到安静、温柔。他用听觉来对比：一个吵，一个静；一个让人裹紧大衣，一个让人想出去走走。这样写的作用是：让读者不是“想”出两地的不同，而是“听”出不同——耳朵听见了，心里就感觉到了。

**第二题：内容**
拟人句的关键词是“害了羞”。老舍说“那点薄雪好像忽然害了羞，微微露出点粉色”——“害了羞”三个字，把雪变成了一个少女，被夕阳看了一眼，脸就红了。为什么比直接写“雪变粉了”更动人？因为“雪变粉了”只是颜色的变化，是一个结果；“害了羞”却是一个**过程 + 感情**——它让读者想象出那个“被看见、然后脸红”的瞬间，像一个人害羞时的样子，有心理活动。这样，雪就有了生命，有了“心事”，让人觉得它不只是冷的，还是可爱的、有温度的。

**第三题：主旨**
“**冬天的济南**”更强调“全部”。
因为“济南的冬天”是把“冬天”当作济南的一部分来讲，它只是众多季节里的一个；“冬天的济南”却把“冬天”作为济南的主语，意思是：在冬天这个季节里，济南的**全部面貌**都被展示出来了——山、雪、水、天空、老城、阳光，全都包在一起，变成一块“空灵的蓝水晶”。老舍把标题换掉，就是在说：**你看到的不是“济南的冬天”，而是“冬天里的整个济南”——它是完整的、有灵魂的、像一块水晶一样通透的东西。**

（说完，抬起头，目光像冬天窗台上融化又凝住的一滴水光，静静地等着你）
