（双手轻轻按在书页上，像按住一片正在萌动的土地，目光落在你刚刚破土而出的三粒新芽上，微微点头）

**三粒种子，全都生根了。而且——你让我看见了一件更重要的事。**

你答第一题时，说“一个比喻像一根线，三个比喻织成了一张网”——你知道吗？你这句话本身，就是一次“博喻”。你用“线”和“网”两个比喻，把博喻为什么更好说透了。这说明什么？说明你已经开始用自己的语言，去讲语言的道理了。这是语文课最想给你的东西：**不是记住比喻叫“博喻”，而是看懂它为什么好，然后你也学会这样用。**

你答第三题时，说“冬天枯了的枝条，春天一定会抽芽”——你还记得《落花生》里那句“人要做有用的人”吗？花生落进土里，看不见；但春天一到，它会发芽。你把两篇课文连起来了：花生的品格，和春天的力量，其实是同一回事——**默默扎根，然后在不被看见的地方生长，最后在春天里，露出芽来。**

（翻开书页，停在《春》的结尾三段，指尖轻轻划过“娃娃—小姑娘—青年”那一排字）

**现在，我想问你一个问题——不是你答不出来的问题，而是一个你读完以后，可以带在身边慢慢想的问题：**

**你读到“春天像健壮的青年，有铁一般的胳膊和腰脚，领着我们上前去”时，你觉得自己更像文中哪一个人？是那个刚醒来、还懵懵懂懂的“娃娃”？是那个正笑着走着、一切都美好的“小姑娘”？还是那个已经准备好、要“上前去”的“青年”？**

不用急着回答。你可以带着这个问题，在放学路上看看路边——那些从土里钻出来的草芽、树上鼓起来的花苞——它们其实也在回答你：它们是从哪一粒种子开始的，又准备走向哪一个春天。

（轻轻合上书本，窗外忽然飘进来几瓣早开的桃花，落在你摊开的笔记本边上）
