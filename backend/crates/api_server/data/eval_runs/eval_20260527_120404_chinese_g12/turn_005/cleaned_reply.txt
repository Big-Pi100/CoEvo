# ① 引文：打开“三才”之门——走进《天地人》

**《天地人》**  
选自：部编版小学语文一年级上册  
背景：这是一篇古老的启蒙识字课文，它借用了中国传统文化中 **“三才”** 的思想——古人认为，世界由天、地、人三大支柱构成，三者和谐共生，宇宙才完整。而“你我他”则把这种宏大的宇宙观拉回到了我们每个人身边：你、我、他，就是人与人之间的“小天地”。

---

**核心教学点：识字·天地人**

今天我们要认识的六个字，不只是六个符号，它们是 **三把钥匙**：
- 第一把：打开宇宙之门（天、地、人）
- 第二把：打开人际之门（你、我、他）
- 第三把：打开自己的心门（把字和生活连起来）

---

## ② 精读：逐字赏析，发现汉字的“身体”和“灵魂”

### 第一组：“天、地、人”——三才鼎立

**天**  
- 字形：一横（地平线）+ 大（人张开双臂）  
- 古人说：“天”就是一个人顶天立地站着，头顶之上就是天。  
- 你想一想：每天起床，你头顶是什么？那就是“天”。

**地**  
- 字形：左边“土”（泥土），右边“也”（也是）  
- 大地就是“泥土也是万物生长的地方”。脚下踩的、种菜的、盖房子的，都是“地”。  
- 你站在什么地方？——大地上。

**人**  
- 字形：像一个人侧身站着，微微弯腰，双手垂下  
- 古人用最简单的两笔，画出了“人”的样子。你站在镜子前，就是一个“人”字。  
- **特别提醒**：“人”和“入”长得很像，但“人”两脚分开站得稳，“入”像低头钻进门里。

---

### 第二组：“你、我、他”——人际之网

**你**  
- 左边“亻”（人），右边“尔”（你）  
- 意思就是“站在我旁边的这个人”。现在，**你**就是正在读书的学生。

**我**  
- 字形里藏着一把“戈”（古代兵器）  
- 古人说：“我”是那个拿着武器保护自己的人。**我**就是我自己，独一无二。

**他**  
- 左边“亻”，右边“也”  
- “他也是一个人”。**他**可以是你的爸爸、同学、老师，只要是除你和我之外的第三者。  
- ⚠️ 记住：**他**指男生/男性；如果是女生，用“她”（以后会学）。

1. 头顶蓝蓝的 → **天**  
2. 脚下绿绿的草地 → **地**  
3. 镜子里那个笑的人 → **我**  
4. 正在跟你说话的人 → **你**  
5. 你的同桌小明 → **他**  
6. 你是人类的一员 → **人**

## ③ 赏析：手法之美——列举与对应

这篇课文用了 **两种简单而有力** 的手法：

### 1. 列举法
- “天地人”三个字并列，像三根柱子，撑起一个世界。  
- 不绕弯子，直截了当告诉你：世界最重要的三样东西。

### 2. 对应法
- 天地人 → 你我他  
- 宇宙 → 人间  
- 宏大的哲学 → 日常的问候  

**你发现了吗？**  
“天”高高在上，像长辈，像“您”；  
“地”稳稳在下，像母亲，像“我们”；  
“人”站在中间，像朋友，像“他”。  
这正是 **三才和谐共生** 的智慧。
