### ✅ 《天地人》复习收尾（一分钟速过）

1. **六个字**：天、地、人、你、我、他  
2. **两对对应**：天/地/人（宇宙三才）——你/我/他（人际三要素）  
3. **易错提醒**：  
   - “人”别写成“入”（人站得开，入低头钻）  
   - “他”和“她”区别以后学，现在记住“他”是男生  
4. **一个核心思想**：世界是由天、地、人组成的，我们和身边的人（你、我、他）一起生活，互相关心。
