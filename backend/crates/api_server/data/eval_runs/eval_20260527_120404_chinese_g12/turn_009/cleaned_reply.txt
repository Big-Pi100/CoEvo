# ① 引文：天地之间，人立其中——走进《天地人》

小朋友，欢迎来到汉字王国！今天我们要认识的六个字，不是普通的符号，而是 **三把金钥匙**，能打开认识世界的第一扇门。

## 这篇课文是谁写的？说的是什么？

**《天地人》** 来自部编版小学语文一年级上册。它只有六个字，却藏着中国人几千年的大智慧。古人的课本里，第一课常常讲 **“三才”**——他们认为，整个宇宙由三样最重要的东西支撑着：  
- **天**（在上，覆盖万物）  
- **地**（在下，承载万物）  
- **人**（在中间，连接天地）

而有了“天地人”这个大世界，还有 **你、我、他** 这个小世界。古人用这种巧妙的对应，告诉我们：**人不仅属于天地，也属于彼此**。

## ② 精读：逐字认识六个汉字宝宝

### 第一组：天、地、人

**【天】**  
- 📝 字形：一横 + “大”，像一个大人张开双臂，撑起天空  
- 🏠 生活中：抬头看见的就是“天”——蓝天、白天、今天  
- ✋ 小动作：双手向上举，像撑起天空，这就是“天”

**【地】**  
- 📝 字形：左边“土”（泥土），右边“也”（也是）——泥土也是大地  
- 🏠 生活中：脚下踩的是“地”——土地、草地、大地  
- ⚠️ 注意：写“地”时，右边的“也”有一笔长长的 **竖弯钩**，**不能少写**！

**【人】**  
- 📝 字形：像一个人侧身站着，两笔画出轮廓——一撇一捺  
- 🏠 生活中：你就是一个人，你的爸爸妈妈、老师同学都是人  
- ⚠️ 易混字：**“人”和“入”**  
  - 人：两脚分开（撇高捺低，站得稳）  
  - 入：像低头钻进门（撇低捺高，要钻进去）

---

### 第二组：你、我、他

**【你】**  
- 📝 字形：左边“亻”（人），右边“尔”（你）  
- 💬 意思：正在和我说话的那个人，就是 **你**  
- 例句：**你**是我的好朋友。

**【我】**  
- 📝 字形：里面藏着一把“戈”（古代兵器）——自己保护自己的人  
- 💬 意思：**我**就是我自己，独一无二  
- 例句：**我**是一年级的小学生。

**【他】**  
- 📝 字形：左边“亻”，右边“也”——他也是一个人  
- 💬 意思：除你和我之外的 **男性**（叔叔、爸爸、男同学）  
- 例句：**他**是我的爸爸。  
- 💡 记住：如果是女生，以后会学到“她”

## ③ 赏析：六个字，搭起两座桥

这篇课文最厉害的地方，是它只用六个字就搭起了 **两座看不见的桥**：

### 第一座桥：宇宙之桥（天地人）
- 天在上 → 地在下 → 人在中间  
- 就像三根柱子，撑起一个完整的世界  
- 这叫 **“三才”** 思想——三者缺一不可

### 第二座桥：人际之桥（你我他）
- 你在那边 → 我在这边 → 他在旁边  
- 三个人称，教会我们怎么称呼别人  
- 这叫 **“三称”** ——人和人之间最基本的联系

### 最妙的是——两座桥连在一起！
> 天空和大地之间站着一个人，  
> 就像你和他的中间站着“我”。  
> 所以，**认识世界，就是从认识这些人开始的**。
