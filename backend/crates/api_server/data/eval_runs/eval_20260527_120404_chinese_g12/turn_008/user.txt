**【引文回顾】**  
《金木水火土》是《天地人》的“搭档”课。古人把世界分成天、地、人三部分，又用金、木、水、火、土五种基本物质来解释万物材料。数字“一二三四五”教我们按顺序认识事物。整首诗只有20个字，却讲清了世界的组成、空间和时间的关系。

你还记得那五个字吗？我们来玩个游戏：  
**我说提示，你说汉字**（你可以在心里默念或说出来）：

1. “闪闪发亮，做首饰用的” → **金**  
2. “一棵树，可以做桌子” → **木**  
3. “哗啦啦，能喝能洗” → **水**  
4. “红红的，会燃烧” → **火**  
5. “踩在脚下，种菜用” → **土**

数字“一二三四五”你肯定也会了。现在请你用一句话告诉我：  
**《金木水火土》和《天地人》有什么联系？**  
（比如：它们都讲了______，但是《金木水火土》还多了______。）
