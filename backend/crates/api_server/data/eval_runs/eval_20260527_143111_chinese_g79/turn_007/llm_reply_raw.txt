很高兴看到你收获满满，也为我能够见证你从“读词”到“创作”的成长而开心。你说得特别好——学会“不放过每个词”，就是打开了语文审美的第一扇窗，往后的每一篇课文都会让你尝到更多滋味。

既然你已经把这扇窗擦亮了，那我们不妨带着这双眼睛，再翻开新的一页。今日我们要走进另一座城，另一个冬天——老舍先生的**《济南的冬天》**。

先读读文章的开头：

> 对于一个在北平住惯的人，像我，冬天要是不刮风，便觉得是奇迹；济南的冬天是没有风声的。对于一个刚由伦敦回来的人，像我，冬天要能看得见日光，便觉得是怪事；济南的冬天是响晴的。自然，在热带的地方，日光是永远那么毒，响亮的天气，反有点儿叫人害怕。可是，在北中国的冬天，而能有温晴的天气，济南真得算个宝地。

老舍先生一开篇，就用了三个地方跟济南比——**北平、伦敦、热带**。你读到这里，第一感觉是什么？如果去掉这些对比，直接写“济南的冬天是温晴的”，效果会差在哪里？试着体会一下，这就是我们今天要品味的核心教学点：**对比手法与老舍独特的语言风格**。
