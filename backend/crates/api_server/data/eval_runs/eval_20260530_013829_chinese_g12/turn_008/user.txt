（挺直小身板，小手拍得啪啪响）

**我——是——小——学——生——**
（学老师的样子拍拍肚子，又拍拍脑袋）
**天——天——起——得——早——**

（挥挥手，笑眯眯）
**背——着——书——包——上——学——去——**
**见——人——问——声——好——**

（竖起大拇指，很自豪）
**我——是——小——学——生——**
**学——习——本——领——强——**

（做写字、画画、数数的动作）
**写——字——画——画——做——算——术——**
**快——乐——又——健——康——**

（念完了，高兴地跳了一下）
老师！我记住啦！  
“我是小学生，天天起得早”——我每天都是第一个到教室的！  
“见人问声好”——我早上看见门卫爷爷都说“爷爷早上好”！  
老师，我这样对不对呀？
