### ③ 赏析：陆定一的“四个镜头”

这篇文章读起来像一部**微型纪录片**，陆定一用了四种“镜头”让你亲自爬一遍老山界：

1. **远景镜头**（写山势）  
   “之”字形火把连到天上——用比喻写高度，用形状写路线。

2. **特写镜头**（写险路）  
   “九十度的垂直石梯”“只有一尺多宽”——用数字让危险现形。

3. **动作镜头**（写翻越）  
   “肚子贴到石壁”“一步一步地走”——用身体姿势写出艰难。

4. **对比镜头**（写牺牲）  
   “马从崖上跌下来，脚骨都断了”——用马的伤亡反衬人的信念。

现在你可以选一个镜头说说：你觉得哪一种“镜头”最能让你感受到翻越老山界的艰难？
