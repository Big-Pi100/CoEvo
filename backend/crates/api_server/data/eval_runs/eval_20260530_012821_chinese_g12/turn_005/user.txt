（跟着老师做动作，认真学）  
我爱我们的祖国——（拍手，双手比心）  
我爱我们祖国的土地——（弯腰轻轻摸地面）  
我爱我们祖国的山河——（一手画高山，一手画波浪）  
我爱我们祖国的人民——（张开手臂，像抱很多人）  
我爱我们祖国的花朵——（双手托腮，眯眼笑）  

我们爱祖国——（抱抱自己）  
祖国爱我们——（双手慢慢张开再轻轻抱住自己）  
我们和祖国——（原地转一小圈）  
永远不分开——（双手合十，放在胸口）  

（看着老师）  
老师，我记住了！  
“土地”就是脚下的泥土，“山河”是大山和河流，“人民”是爸爸妈妈、老师还有同学们，“花朵”就是我们小朋友。  
最后说“我们和祖国永远不分开”，就像小鱼离不开水，小鸟离不开天空一样，对吗？
