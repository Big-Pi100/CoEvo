（拍手笑，眼睛亮亮的）  
**读对啦！一字不差！**  
小鸟问完你，答案来啦——  

（老师继续拍，节奏加快）  
我去上学校——（踏步走）  
天天不迟到——（摇摇手指）  
爱学习，爱劳动——（指指脑袋，搓搓手）  
长大要为人民立功劳——（握拳举高）
