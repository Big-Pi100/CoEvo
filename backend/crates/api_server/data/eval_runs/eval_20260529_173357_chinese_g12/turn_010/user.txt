（小朋友站得直直的，先拍拍小手，然后深吸一口气，开始一边背一边做动作）

**“我爱我们的祖国”**  
（双手画一个大大的心形）

**“我爱我们祖国的土地”**  
（双手向下摊开，像摸大地）

**“我爱我们祖国的山河”**  
（左手划山，右手划河）

**“我爱我们祖国的人民”**  
（张开双臂，像拥抱大家）

**“我爱我们祖国的花朵”**  
（双手捧起，像捧着花）

**“我们爱祖国，”**  
（手指自己，再指向前方）

**“祖国爱我们。”**  
（双手收回，抱抱自己）

**“我们和祖国，”**  
（两根食指并在一起）

**“永远不分开。”**  
（双手交叉握紧，摇一摇）

（背完后，眼睛亮晶晶地看向老师）  
老师，我背完啦！
