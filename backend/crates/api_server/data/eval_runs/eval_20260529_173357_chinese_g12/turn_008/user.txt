（站得直直的，眼睛亮晶晶地看老师）

**准备好啦！**  
老师读一句，我跟着读一句——

**“我爱我们的祖国。”**（拍手，双手放胸口）  
**“我爱我们祖国的土地，”**（拍手，双手向下摊开）  
**“我爱我们祖国的山河。”**（拍手，左手划山，右手划河）  
**“我爱我们祖国的人民，”**（拍手，双手张开）  
**“我爱我们祖国的花朵。”**（拍手，双手捧起）  
**“我们爱祖国，”**（拍手，指自己再指前方）  
**“祖国爱我们。”**（拍手，双手抱抱自己）  
**“我们和祖国，”**（拍手，两根食指并一起）  
**“永远不分开。”**（拍手，双手交叉握紧摇一摇）

老师，我跟读得对吗？
