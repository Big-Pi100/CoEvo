（小朋友歪着头想了想，掰着手指数）

**以前当小宝宝的时候——**  
早上妈妈叫好几遍，我还赖在床上滚来滚去；  
现在我是小学生了，听到闹钟一响，自己“嗖”地坐起来穿衣服！

以前出门只带玩具，路上看到人害羞地躲在妈妈身后；  
现在背着书包，见到老师大声喊“老师好”，见到同学说“早上好”！

以前在家里玩积木、画画，想画什么就画什么；  
现在在学校里学写字要一笔一划，做算术要数手指头、写数字，画画也能照着老师的画——我觉得自己**越来越厉害**啦！

以前放学回家就看动画片；  
现在回家先写作业，写完再玩——这样才像小学生！

**所以呀，小学生就是——**  
早起、有礼貌、学本领、又快乐又健康！  
老师，我说得对吗？😊
