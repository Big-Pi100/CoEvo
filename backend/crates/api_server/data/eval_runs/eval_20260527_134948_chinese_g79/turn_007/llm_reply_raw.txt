你刚才对《春》的总结，已经是一个非常成熟的赏析成果了。现在我们把目光转向《济南的冬天》，你会发现老舍的写作手法和朱自清既有相似之处，又呈现出独特的风格。

正如教学点提示的，这篇文章的核心手法是**对比**，而语言风格则带上了老舍特有的**亲切、朴实、幽默**。

请你先读课文开头这一段，注意老舍是怎么处理“对比”的：

> 对于一个在北平住惯的人，像我，冬天要是不刮风，便觉得是奇迹；济南的冬天是没有风声的。对于一个刚由伦敦回来的人，像我，冬天要能看得见日光，便觉得是怪事；济南的冬天是响晴的。自然，在热带的地方，日光是永远那么毒，响亮的天气反有点儿叫人害怕。可是，在北中国的冬天，而能有温晴的天气，济南真得算个宝地。

你有没有发现，老舍写济南的冬天，没有直接说“济南暖和”，而是先搬出了**北平、伦敦、热带**三个地方来做对比。

我的问题是：**老舍明明要赞美济南的冬天，为什么开头偏要先写别的地方？** 用了这三组对比之后，济南的冬天在你心里留下了什么印象？试着用你的语言说出来——不是“温晴”这两个字，而是你感受到的那种**气氛**。
