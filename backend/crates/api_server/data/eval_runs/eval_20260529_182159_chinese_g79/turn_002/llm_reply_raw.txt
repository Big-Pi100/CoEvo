### ⑤ 考核·对答精评

**第一题（手法）**  
你说得精准极了——“同一个春雨，三个不同的比喻”，这正是 **博喻** 区别于普通排比的关键所在。  
普通排比是把三件不同的事物并列，而博喻是用三个比喻角度去 **“围剿”同一件事物**，让读者从牛毛的密、花针的亮、细丝的柔中，把春雨“看得立体”。  
**这一题，满分通过。**

**第二题（内容——多感官描写）**  
你找到了三个通道——  
- 嗅觉：泥土气息、青草味儿、花香  
- 听觉：鸟儿宛转的曲子  
- 触觉：软绵绵的草（还有“像母亲的手抚摸着你”的风）

没有落下任何一个感官，并且你说出了关键：“像真的站在风里一样”——这正是朱自清先生多感官描写的魔力，让文字变成一座可以走进的园子。  
**这一题，也完全通过。**

**第三题（主旨——结尾三段比喻的递进）**  
你不仅说了三个比喻（娃娃、小姑娘、青年），更点出了它们之间的逻辑：  
- 娃娃 → **新**（诞生，无限可能）  
- 小姑娘 → **美**（花枝招展，春光灿烂）  
- 青年 → **力**（铁一般的胳膊，向前奔跑）  

**从“新”到“美”到“力”，层层递进，最后落在“领着我们上前去”——这正好呼应了全文昂扬向上的生命赞歌。**  
你把主旨概括得比教科书还清晰。
