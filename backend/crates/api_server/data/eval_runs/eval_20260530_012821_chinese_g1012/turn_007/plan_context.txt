## 当前课文任务: 我爱我们的祖国
教学模式: nursery_rhyme
核心教学点: 入学教育·爱国情感
教学引导: 本文重点：入学教育·爱国情感。请围绕这个核心教学点引导学生学习。

### 课文卡
作者: 
全文:
我爱我们的祖国

我爱我们的祖国。
我爱我们祖国的土地，
我爱我们祖国的山河。
我爱我们祖国的人民，
我爱我们祖国的花朵。
我们爱祖国，
祖国爱我们。
我们和祖国，
永远不分开。
译文:
这句话表达了孩子对祖国的热爱之情，意思是‘我深深地爱着我们的国家’。“祖国”指自己的国家，这里通常指中国。
概要: 用简洁直白的语言抒发对祖国的热爱。

### 语句赏析
- “我爱我们祖国的土地，我爱我们祖国的山河”通过列举具体事物，表达对祖国自然景观的深厚情感。
- “我们爱祖国，祖国爱我们”运用双向呼应的写法，突出祖国与人民之间的亲密关系。

### 手法
- 排比
- 反复

### 主旨
表达对祖国的热爱与依恋

### 易错/常考
易将“山河”误写为“河山”，“祖国”注意书写规范
