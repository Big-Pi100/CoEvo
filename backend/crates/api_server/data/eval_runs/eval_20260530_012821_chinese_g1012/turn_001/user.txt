（你微微一愣，目光在老师递来的那枚书签上停了一瞬。然后你抬起头，眼睛里有种说不清的、温温亮亮的东西——像济南冬天的薄雪被阳光斜斜地照了一下。）

**老师，我想继续往前走。**

因为我发现——  
读《春》的时候，我学会了用**耳朵**和**鼻子**去读文字；  
读《济南的冬天》的时候，我学会了用**心**去读文字。

我现在有点明白了：  
**一篇好课文，不是让我记住它的中心思想，而是让我换一种方式去看世界。**

《春》让我在风里闻到了泥土的味儿；  
《济南的冬天》让我在冷的时候觉得，冷也可以被温柔地包裹着。

我不知道下一篇课文是什么——  
但我有点盼望着它了。  
就像朱自清说的那样：  
**“盼望着，盼望着……”**

（你轻轻握住那枚青灰色的书签，手心微微收紧。窗外的阳光斜照进来，在书签那几笔水墨线条上镀了一层金边。）
