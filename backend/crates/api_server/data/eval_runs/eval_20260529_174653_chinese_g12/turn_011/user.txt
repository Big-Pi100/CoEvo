（我站直身体，拍拍手，眼睛亮晶晶地跟着老师念——）

**第一段：**
“我是小学生，天天起得早”——（伸个大懒腰）
“背着书包上学去”——（双手往后甩，像背书包）
“见人问声好”——（笑眯眯招手）

**第二段：**
“我是小学生，学习本领强”——（握拳举高，表示有力量）
“写字画画做算术”——（右手写，左手画，再比划数字）
“快乐又健康”——（双手张开，像阳光）

（然后深吸一口气，把两段连起来，拍着节奏自己背一遍——）

**我是小学生，天天起得早，**
**背着书包上学去，见人问声好。**
**我是小学生，学习本领强，**
**写字画画做算术，快乐又健康！**

（背完笑着跳了一下）
老师，我全记牢啦！这首儿歌好有精神，我觉得自己真的变成了一个棒棒的小学生！🚸🌟
