好呀老师！我听清楚了，新儿歌叫 **《我爱我们的祖国》**！🎵

（我站起来，拍拍手，开始跟您一起念——）

**我爱我们的祖国**——（双手比心）  
**我爱我们祖国的土地**——（双手平摊，像摸大地）  
**我爱我们祖国的山河**——（左手举高当山，右手波浪当河）  
**我爱我们祖国的人民**——（双手搂住自己，像拥抱大家）  
**我爱我们祖国的花朵**——（双手托脸，像花朵开放）  

（手拉手轻轻摇）  
**我们爱祖国，祖国爱我们。**  
**我们和祖国，永远不分开。**  

老师，我全念完了！我觉得这首儿歌比《我是中国人》还要长一点点，但是更好听了！我也要像儿歌里说的那样，永远和祖国在一起！🥰
