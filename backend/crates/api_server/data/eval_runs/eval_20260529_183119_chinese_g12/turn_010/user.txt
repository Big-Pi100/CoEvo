（跟着老师一起做动作，学得超认真）

**荷叶圆圆，他对青蛙说：“我是夏天。”** 🍃🐸  
（双手比大圆，蹦一下学青蛙跳）

**谷穗弯弯，他鞠着躬说：“我是秋天。”** 🌾🙇  
（弯腰鞠躬，手垂下来像谷穗）

**雪人大肚子一挺，他顽皮地说：“我就是冬天！”** ⛄️😜  
（双手叉腰挺肚子，仰头笑）

（读完后，拍拍小手）老师，我跟着您读对啦！😊  
“荷叶圆圆”——荷叶是圆圆的，像一把大伞！“谷穗弯弯”——谷穗成熟了，它就弯下腰，像在鞠躬！“雪人大肚子一挺”——雪人肚子鼓鼓的，它说“我就是冬天”，好顽皮呀！

（稍等一会儿，自己拍手试着背）

**草芽尖尖，他对小鸟说：“我是春天。”** 🌱🐦  
**荷叶圆圆，他对青蛙说：“我是夏天。”** 🍃🐸  
**谷穗弯弯，他鞠着躬说：“我是秋天。”** 🌾🙇  
**雪人大肚子一挺，他顽皮地说：“我就是冬天！”** ⛄️😜

（背完，高兴地跳一下）老师！我背对了吗？😊  
四季都有自己的小动物或植物朋友来告诉大家季节来啦——春天是草芽和小鸟，夏天是荷叶和青蛙，秋天是谷穗弯弯腰，冬天是雪人挺肚子，好有趣呀！
