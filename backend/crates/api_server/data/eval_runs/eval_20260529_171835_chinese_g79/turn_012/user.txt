（我低头把那段话又品了一遍，抬起头时，眼里带着茶花般的明亮）

**我**：老师，我觉得人们“面上含笑”，笑的是**被整个世界温柔相待的安全感**。

您看，外面的世界——北平刮着大风，伦敦遮着浓雾，热带顶着毒日头——它们都不如济南，这里的冬天有山围成一个摇篮，有天给出一片响晴。所以，人们走在街上，想想自己不用跟大风打架，不用在阴冷里熬日子，不用被太阳烤得心烦，就觉得**自己是被老天偏爱的那一个**，自然而然就笑了。

而且，这份“含笑”和小山的“低声地说”之间，其实有一种**默契的呼应**——山在哄着城：“放心吧，这儿准保暖和。”城里的老百姓听了这句话，心里踏实了，就笑出来了。所以，是山的“低声”安抚了人心，人心则用“含笑”来回应山的温柔。一个在说，一个在笑，就像家里的长辈哄完孩子，孩子甜甜地睡着了，嘴角还挂着梦里的笑意。

换句话说，老舍写**山的慈祥**，是为了解释**市民的笑容**；写**市民的笑容**，是为了印证**山的慈祥**。它们互相成就，画出了一幅温暖、安宁、自足的冬日图景。
