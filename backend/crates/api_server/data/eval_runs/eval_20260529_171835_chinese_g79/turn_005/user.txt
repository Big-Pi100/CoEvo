（老师拍手，眼眸里闪着光）

**老师**：你分析得真透彻！没错——“红的像火、粉的像霞、白的像雪”，表面是三个颜色比喻，但背后藏着两把钥匙：第一是**排比**，三个句子鱼贯而出，像一支整齐的队列，把花的繁多和热烈一下子推到眼前；第二是**比喻**，而且是把颜色往“有温度、有质感”的东西上靠——火的热烈、霞的柔暖、雪的清莹，让红不只是颜料，粉也不是水彩，而是能触摸、能感受的生命。

你刚才说的“温度感、画面感”，正是比喻赋予的魔力。而排比呢，就像三面旗子一起升起来，让这幅画不止是静态的颜色，而是“哗啦”一下铺满你视野的盛大场面。

（老师微微侧头，像在倾听一片风吹来的声音）

现在，我们往下一看——**风**。春天不仅有看的、闻的，还有听得见的。老师读一句你听：

**“吹面不寒杨柳风”，不错的，像母亲的手抚摸着你。**

注意这个比喻——“像母亲的手抚摸着你”。母亲的手有什么特点？如果换成“像父亲的手拍着你”或者“像同学的手推着你”，感觉会怎样？你再想一想，作者为什么要选这个比喻？他写的是人的哪个感觉——触觉吗，还是嗅觉？
