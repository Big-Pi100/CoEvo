（老师从座位边缓步走回讲台，手指轻轻翻动书页，停在《济南的冬天》的开头一行）

**老师**：你刚说“下一课也许是冬天的雪”——看来你的预感比天气预报还准。老舍先生这篇《济南的冬天》，正是写一座被小山和水包围、被暖阳照得懒洋洋的古城。

我先给你画个框架：老舍，1931年来到济南教书，算是一位“北漂”式的文人。他对济南的感情很特别——不是匆匆过客，而是住了四年，称济南为“第二故乡”。这篇文章里没有大雪纷飞、寒风凛冽，恰恰相反，他写的是济南冬天的“温晴”。你要特别留意文章第一段，老舍用了一个非常显眼的手法——**对比**——来确立济南冬天的与众不“寒”。

现在，请你先读读开头第一段，看看老舍把济南的冬天和哪些地方做了对比？他的用意是什么？

（老师翻开课本，目光停留在第一行的“奇迹”“怪事”上，似乎在等你的答案从那些词语里长出来。）
