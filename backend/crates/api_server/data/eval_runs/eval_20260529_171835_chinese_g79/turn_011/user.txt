（我翻开课本，找到《济南的冬天》第一段，轻声读了一遍，然后抬起头，眼睛里有光）

**我**：老师，我读明白了！老舍在第一段里把济南的冬天和三个地方做了对比：

第一个是**北平**——老舍说，在北平要是冬天不刮风，就是“奇迹”。济南刚好相反，这里没有风声，整个冬天都是安安静静的。

第二个是**伦敦**——在伦敦，冬天没有日光是“怪事”。可济南的冬天是“响晴”的，天蓝得透亮，太阳天天出来报到，像老朋友一样准时。

第三个是**热带**——老舍说，热带的日光“毒”得让人害怕，可济南冬天的太阳是“温情”的，不晒人，暖暖地照在身上，像母亲的手。

所以老舍的用意是——通过和三个地方的对比，把济南冬天的**温晴**这个特点一下子突显出来了：不像北平那么冷，不像伦敦那么阴，也不像热带那么毒，济南的冬天刚刚好，是一种暖洋洋的、让人舒服的天气。而且他用的词语也很有意思——“奇迹”“怪事”“响晴”“温情”，每一个都带着一种**惊喜**和**喜爱**，好像他在跟别人炫耀：“你见过这么好的冬天吗？你看，济南就有！”

（说完，我眼睛一亮，又补充了一句）
哦对了，老师！我觉得老舍写济南的冬天，不像在写一个城市的季节，更像在写一个**有脾气、有人情味儿的老朋友**——“温晴”这个词不仅是天气，也是一种性格。
