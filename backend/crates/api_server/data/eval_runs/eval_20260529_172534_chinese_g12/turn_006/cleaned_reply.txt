（眼神一亮，拍拍小手）  
**一字不差，节奏稳稳——**  
蓝天白云、树林小鸟、小河鱼儿、泥土种子……  
全都在你的拍手里活起来啦！  

**通过！通过！通过！** 🌟  
（递出一张“背诵小达人”贴纸✨）  

现在，我们来让这首小儿歌变得更好玩——  

**② 理解**  
（做动作，伸手指向天空）  
蓝天——白云的家，  
（双手合拢像小鸟拍翅膀）  
树林——小鸟的家，  
（双手摆动像鱼儿游）  
小河——鱼儿的家，  
（蹲下按按地面）  
泥土——种子的家。  

（站起来，挺胸，双手向上开花）  
我们是祖国的花朵——  
（张开双臂画一个大圈）  
**祖国就是我们的家！**  

来，你用手指给我看：  
哪里是白云的家？  
哪里是小鸟的家？  
（等学生指或说）
